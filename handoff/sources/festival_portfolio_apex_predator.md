# Strategic Festival Portfolio "Apex Predator" (사용자 제공 source)

> 영화제를 **전략적 기능(S1–S4)**으로 묶은 포트폴리오. 권위(prestige tier T1–T4)와 *직교하는 축*. 총점의 희소성/발굴 보너스 근거.

## S1 — 권위의 정점 (Apex / 안전자산·리스크 헤징)
- **Cannes**: Competition / Un Certain Regard / **Directors' Fortnight(핵심)** / Critics' Week
- **Venice**: Competition / Orizzonti
- **Berlin**: Competition / Encounters / **Forum(핵심, 아방가르드·에세이)** ← 레지스트리 신규
- **NYFF**: Main Slate / Currents ← 섹션 신규(비경쟁 큐레이션)

## S2 — 전위대·성장주 (Vanguard / 차별화·노력이론)
- **Locarno**: Concorso Internazionale / Cineasti del presente
- **IFFR(Rotterdam)**: Tiger Competition
- **Sundance**: World Cinema Dramatic / NEXT
- **TIFF**: **Wavelengths(핵심, 실험)** / Platform ← 섹션 신규

## S3 — 글로벌 프론티어 (Frontier / 발굴자본·희소성 ↑)
- **Busan(BIFF)**: New Currents / Jiseok
- **BAFICI** (아르헨티나) ← 신규
- **FESPACO** (부르키나파소, 격년) ← 신규. 접근성 어려움 = 최고 희소성. (보완: Marrakech / Carthage)

## S4 — 전문가 영역 (Specialists / 블라인드스팟·완결성, 별도 트랙)
- 다큐: **IDFA** (네덜란드, 전통권위) / **CPH:DOX** (덴마크, 실험 하이브리드) ← 신규
- 복원: **Il Cinema Ritrovato** (이탈리아, Recovered & Restored) ← 신규
- 애니: **Annecy** (Feature / Contrechamp) ← 신규

## 처리 메모
- 기존 레지스트리에 있는 것(칸·베니스·베를린·로카르노·IFFR·선댄스·TIFF·부산·NYFF 본체): `strategic_tier` 값만 부여.
- 신규(Forum, NYFF 섹션, TIFF Wavelengths/Platform, Locarno/Sundance 하위섹션, BAFICI, FESPACO, IDFA, CPH:DOX, Il Cinema Ritrovato, Annecy, Jiseok): 레지스트리 행 추가(+QID).
- 원문의 '전략(taste capital/imposter)' 프레이밍은 *수사*. 채점에는 방어 가능한 핵심(authority × rarity × result)만 추출.
