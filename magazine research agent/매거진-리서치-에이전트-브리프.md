# 위임 브리프 — 영화 비평 매거진 사전등록 조사 (목표 ~200, 품질 우선)

> 대상: 리서치 AI 에이전트(또는 리서처). 산출물을 아래 두 템플릿 형식 **그대로** 채워 제출:
> - `magazine-allowlist-template.csv` — 매체(outlet) 테이블
> - `magazine-contacts-template.csv` — 연락처(인물/이메일) 테이블
> 맥락: Metatake ASK(Grounded RAG)의 외부 소스 레인(W8a). 사전 등록한 비평지에서만 **짧은 인용 + 링크아웃**으로 답변을 보강하고, 향후 **제휴 아웃리치**를 위함. 이 조사는 **메타데이터·공개 연락처 수집만** 한다.

---

## 0. 절대 준수 (법적 안전)
- **기사 본문을 크롤·다운로드·저장하지 말 것.** 이 태스크는 *매체 메타데이터 + 공개 비즈니스 연락처* 조사다. 방문 허용 범위: 홈페이지, `robots.txt`, `sitemap.xml`, About/Contact/Masthead/Terms/Copyright 페이지, 위키피디아·언론기사 등 2차 출처.
- 페이월을 우회하지 말 것(유형만 기록).
- **연락처는 공개적으로 게시된 비즈니스 주소만.** 역할 기반 주소(partnerships@, press@ 등) 우선. 개인 사생활 이메일 추정·생성 금지. 모든 연락처에 `source_url` 필수.
- 모든 사실 항목엔 **근거 URL**(`evidence_urls`/`source_url`). 추정·불명은 `unknown`, 빈칸 금지.
- (수집은 합법이나) 향후 아웃리치는 한국 정보통신망법·GDPR·CAN-SPAM 등 영리성 이메일 규정을 따른다 — 이는 발송 단계 이슈이며 본 조사 범위 밖.

## 1. 목표(수량 정책)
영화 비평 권위 매체를 **최대 ~200곳** 정리한다. **숫자를 채우려 억지로 늘리지 말 것.** 선정 기준·필수필드를 충족하는 매체만 제출한다(질 낮은 200보다 알찬 120이 낫다). 목적: (a) 신뢰 가능한 인용 출처 풀, (b) 각 매체 수집방식·법적상태 사전판단, (c) **제휴 아웃리치용 연락처 DB**, (d) 제휴 우선순위.

## 2. 선정 기준
**포함:** 진지한 영화 비평/에세이/인터뷰/리뷰 매체.
- 레거시·정전급: Sight and Sound, Film Comment, Cahiers du Cinéma, Cineaste, Film Quarterly, Senses of Cinema, Reverse Shot, MUBI Notebook, Artforum(영화), Screen 등.
- 현대·온라인 독립 비평 매체, 비평 섹션 강한 문화지.
- **비영어 포함**(다국어 목표): 프·일·스·독어권 주요 비평지.
- **한국 매체 포함 검토**: 씨네21, KINO(아카이브), 필로 등 — 에디토리얼 검수용 표기.
- 영화학 학술 저널 포함 가능, `content_types`에 academic 표기.

**제외:** 순수 뉴스 통신·박스오피스 집계, SEO 리스티클/어그리게이터, 스튜디오 PR, 팬덤 위키.

**분포 가이드.** trust_tier 1 ≥ 20, 비영어 ≥ 15, 발행사/도메인 중복 제거.

## 3-A. 매체 테이블 스키마 — `magazine-allowlist-template.csv`
> ★ = 크롤봇 입력 계약상 **필수**(빈칸 금지, 불명이면 `unknown`).

| 열 | 설명 | 허용값/형식 |
|---|---|---|
| `id` ★ | 일련번호(연락처 테이블의 FK) | 1,2,3… |
| `name` ★ | 매체명 | 텍스트 |
| `publisher` | 발행 주체 | 텍스트/unknown |
| `country` | 본사 국가 | 국가명 |
| `language` | 주 언어 | en, fr, ko, ja, es, de … |
| `homepage_url` ★ | 홈페이지 | URL |
| `archive_url` | 기사 아카이브 | URL/unknown |
| `rss_url` | RSS/Atom 피드 | URL/none |
| `sitemap_url` ★ | sitemap.xml 위치(크롤러 기사 열거 핵심) | URL/none/unknown |
| `article_url_pattern` | 기사 URL 패턴(스코프용) | 예 `/reviews/{slug}`/unknown |
| `render_mode` ★ | 정적 vs JS 렌더(크롤러 설정 좌우) | static/js-required/unknown |
| `content_types` | 콘텐츠 유형 | reviews;essays;interviews;news;video-essays;academic |
| `cadence` | 발행 주기 | daily/weekly/monthly/quarterly/irregular |
| `est_archive_size` | 대략 기사 수 | 숫자/unknown |
| `paywall` | 페이월 유형 | none/metered/hard/print-only/unknown |
| `robots_url` ★ | 확인한 robots.txt | URL |
| `robots_ai_stance` ★ | robots+AI/TDM 옵트아웃+ToS 종합 | allows/partial/disallows/unknown |
| `robots_crawl_delay` | robots의 Crawl-delay(초) | 숫자/none/unknown |
| `api_available` | 공개 API 여부 | none/RSS-only/official-API(이름) |
| `license_terms_url` | 약관·저작권 페이지 | URL/unknown |
| `trust_tier` ★ | 편집 권위(루브릭) | 1/2/3 |
| `ingest_recommendation` ★ | 권장 수집 방식 | API/RSS-incremental/permission-needed/avoid |
| `editorial_note` | 1~2줄: 왜 중요·대표 비평가/초점 | 텍스트 |
| `evidence_urls` ★ | 검증 출처들 | URL(`;` 구분) |

### trust_tier 루브릭
- **1** 국제적 정전·기관급 권위 · **2** 확립된 신뢰 매체 · **3** 유망·니치(품질 좋으나 규모 작음).

### ingest_recommendation 가이드
- `API` 공식 API → 최우선 · `RSS-incremental` RSS+robots allows/partial → 신규분 증분(스니펫+링크) · `permission-needed` 가치 높으나 disallows/hard 페이월/약관 모호 → 제휴 선행 · `avoid` 옵트아웃 명시/리스크 큼.

## 3-B. 연락처 테이블 스키마 — `magazine-contacts-template.csv`
> 매체당 **가능한 한 많은** 관련 연락처를 행으로. 인물(이름·직함·프로필)까지 별도 관리.

| 열 | 설명 | 허용값/형식 |
|---|---|---|
| `contact_id` | 연락처 일련번호 | 1,2,3… |
| `outlet_id` | 매체 테이블 `id` 참조(FK) | 숫자 |
| `outlet_name` | 매체명(편의용 비정규화) | 텍스트 |
| `contact_type` | 부서/용도 | partnerships/licensing/editorial/marketing/press/syndication/general/unknown |
| `is_role_address` | 역할기반 주소 여부 | yes/no |
| `person_name` | 담당자 이름 | 텍스트/unknown(역할주소면) |
| `person_title` | 직함 | 예 `Partnerships Manager`/unknown |
| `email` | 이메일 | 주소 |
| `phone` | 전화(있으면) | 번호/unknown |
| `profile_url` | LinkedIn/프로필 등 "이 사람이 누구인지" | URL/unknown |
| `source_url` | 이메일/인물 발견 출처(필수) | URL |
| `last_verified` | 확인일 | YYYY-MM-DD |
| `notes` | 비고 | 텍스트 |

## 4. 제출물
1. `magazine-allowlist-template.csv`(최대 ~200행, 필수★ 빈칸 0, 통제어휘 준수).
2. `magazine-contacts-template.csv`(매체당 다수 행, 모든 행 `source_url`).
3. 요약 한 단락: 언어·tier 분포, **제휴 우선 추천 10곳**(가치 높은데 `permission-needed`), 연락처 확보율(이메일 있는 매체 비율).
4. 불확실/판단보류 목록.

## 5. ★ 파일럿 게이트 (후작업 0 보장 — 먼저 5행)
전수 200을 채우기 전, **먼저 5개 매체만 두 테이블 모두 완전히 채워 제출.** 발주자가 이 5행을 크롤봇 입력에 맞춰 1회 검증 → 스키마 확정 → 나머지 전수 진행. (포맷 불일치로 인한 후작업 방지의 핵심 단계.)

## 6. 제출 전 자기검증
- [ ] 1단계로 **파일럿 5행** 먼저 제출했는가.
- [ ] 모든 매체 행에 필수★ 필드 채움(불명은 `unknown`, 빈칸 0).
- [ ] `robots_ai_stance`·`robots_crawl_delay`는 실제 robots.txt를 열어 확인, `robots_url` 기재.
- [ ] `sitemap_url`·`render_mode` 확인(크롤러 필수).
- [ ] 모든 연락처 행에 `source_url`, 공개 비즈니스 주소만, 역할주소 우선.
- [ ] 통제 어휘 외 값 없음, 발행사/도메인 중복 제거.
- [ ] tier 1 ≥ 20, 비영어 ≥ 15.
- [ ] 기사 본문 저장·인용 일절 없음(메타데이터·공개 연락처만).
