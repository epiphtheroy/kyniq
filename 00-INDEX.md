## What Is This?

FilmCurio is a **film Q&A platform** — deep, essay-style interpretations of cinema. Users read thoughtful questions and answers about films (symbolism, character choices, directorial intent). Content is generated by an AI pipeline and curated editorially.

## Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | Next.js 16 (App Router, TypeScript), React 19, SSR/ISR |
| **Styling** | Vanilla CSS (`app/globals.css`) — NO Tailwind in production |
| **Database** | Supabase (PostgreSQL) with RLS |
| **Auth** | Supabase Auth |
| **Media** | TMDB API (film data, posters, backdrops) |
| **Video** | YouTube Data API (embedded via facade) |
| **Hosting** | Vercel (auto-deploy from `main` branch) |
| **Worker** | Separate Node.js process (`worker/`) for content generation |

## Database Schema (Key Tables)

| Table | Purpose |
|---|---|
| `films` | Film metadata (title, year, director, slug, TMDB IDs, poster_path) |
| `questions` | Questions about films (title, slug, status, film_id) |
| `canonical_answers` | One definitive answer per question (body, status) |
| `contributions` | User-submitted answers/interpretations |
| `media` | YouTube videos + TMDB stills attached to questions |
| `profiles` | User profiles (username, display_name, role) |
| `jobs` | Pipeline job queue (film processing status) |
| `content_events` | Audit log for content lifecycle |
| `agent_activity` | Worker heartbeat/health |

## Content Pipeline

1. **Admin uploads film list** → creates `jobs` rows
2. **Worker (generator)** picks jobs → generates Q&A via AI (multi-stage: question→answer→verify)
3. **Generated content** saved as `draft` → verified → `approved`
4. **Publisher loop** drip-publishes `approved` → `published` on jittered schedule
5. **Curiobot** attaches YouTube videos + TMDB media to published questions
6. **Only `status='published'` rows** are visible to anonymous users (RLS enforced)

## Design System

- **CSS file:** `app/globals.css` (single source of truth)
- **Font:** Reddit Sans (400/500/600/700)
- **Colors (light):** bg `#FAFAF7`, ink `#1C1C1E`, accent `#D4850E` (amber), teal `#1A7A6D`
- **Colors (dark):** bg `#121212`, ink `#E8E6E3`, accent `#E9A033`
- **Feed:** Infinite scroll, Q&A-dominant cards, film chips with integrated poster

## Key Invariants

1. A question belongs to **exactly one film**
2. **Upvote-only** — no downvote anywhere
3. Only `status='published'` rows are public
4. AI content is attributed to "FilmCurio Editorial"
5. No sockpuppets, no fake engagement
6. Images from TMDB only (no user uploads, no web scraping)

## Running Locally

```bash
npm install
cd worker && npm install && cd ..

# Start dev server
npm run dev          # → http://localhost:3000

# Start worker (separate terminal)
cd worker && node --import tsx/esm launch.mjs
```
