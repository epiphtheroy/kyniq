# PLAN — AI 컨텍스트 팩 (파일 제공형 데이터 상품)

*2026-07-03 작성. `docs/PLAN-api-service.md`(API 사업 기획)의 자매 문서 — 같은 자산을 API가 아닌 **파일/복사 방식**으로 제공하는 설계. 근거 조사는 API 기획과 공유(4개 병렬 리서치, 법률 검증 포함).*

---

## 0. 판단 (TL;DR)

1. **API보다 이 방식이 이 프로젝트에 더 잘 맞는다.** 운영 부담이 0에 수렴하고(업타임·미터링·SLA 없음), 기존 파이프라인 기술(배치 생성 → 정적 파일)과 정확히 일치하며, 2026년 실사용 패턴(자기 AI에 컨텍스트 주입해 글쓰기)에 직접 꽂힌다. API 기획의 P50 매출($200–800 MRR)과 같은 자릿수를 훨씬 낮은 비용으로 노린다.
2. **용어 교정: "학습용"이 아니라 "컨텍스트 팩".** 개인 사용자는 파인튜닝하지 않는다 — Claude Projects / Custom GPT / NotebookLM / Gemini Gems에 파일을 넣고 그 위에서 자기 글을 쓴다. 상품명·포맷·마케팅 전부 이 워크플로에 맞춘다. (진짜 파인튜닝용 JSONL은 파워유저용 부속 포맷으로만.)
3. **무료/유료 경계는 '깊이'가 아니라 '규모'에 긋는다.** 봇 걱정에 대한 답: 콘텐츠는 이미 웹에 공개돼 있어 봇은 지금도 가져갈 수 있다. 영화 1편짜리 무료 복사 버튼으로 잃을 것은 없고(오히려 출처 라인이 퍼지는 마케팅), 봇/무단수집이 실제로 원하는 **벌크**만 로그인+결제 뒤에 둔다.
4. **법적 현실을 그대로 수용한 모델이다.** AI 생성물은 저작권이 없으므로(Thaler 확정) 어차피 "복제 금지"로는 못 지킨다. 파는 것은 텍스트가 아니라 **패키징(구조·완결성·정제) + 편의(원클릭) + 이용 허락(상업 라이선스 계약) + 신선도(업데이트)**다. 이것이 저작권 없는 자산의 정석 수익화다.

**한 줄:** "필요한 사람 가져가라"를 그대로 제품화하되 — 1편은 무료로 퍼뜨리고, 뭉치는 돈 받고, 모든 파일에 출처와 지문을 심는다.

## 1. 왜 파일 방식이 API보다 유리한가 (이 프로젝트 한정)

| 축 | API | 컨텍스트 팩 |
|---|---|---|
| 구축 | 키/미터링/과금 인프라 2–4일 + 게이트웨이 | RPC 1개 + 버튼 + Stripe/Polar 링크, ~2일 |
| 운영 | 주 1–3h (업타임·지원·쿼터 분쟁) | ~0 (정적 파일, 다운로드 링크) |
| 실패 비용 | 인프라 유지 or 철거 | 없음 (버튼과 파일은 사이트 기능으로 잔존) |
| 타깃 | 개발자 (코드 필요) | **비개발자 크리에이터** — 유튜버·블로거·뉴스레터·학생 (지불 의사 검증이 더 쉬운 대중 시장) |
| 수요 신호 | 가입 전엔 안 보임 | **무료 복사 버튼 클릭수 = 공짜 시장조사** → API를 만들지 말지 이 데이터로 결정 |

API 기획을 폐기하는 게 아니라 **순서를 바꾼다**: 팩 먼저 → 복사/다운로드 수요가 입증되면 그때 API·MCP.

## 2. 상품 라인 (4단)

### L0 — 무료: "Copy for AI" 버튼 (모든 영화 페이지)
- 클립보드에 **트림판 마크다운** 복사 (~8–15KB): 영화 식별 최소 사실 + TakeScore 요약 + 대표 take 8–12개(프레임워크 다양성 강제 샘플링) + 트로프 목록 + canon 요약.
- 맨 앞뒤에 고정 라인: `Source: Metatake — metatake.net/film/{slug} · CC BY-NC 4.0 · full pack: metatake.net/data`
- 목적: 배포·브랜딩·수요 측정. 붙여넣기 한 번마다 출처가 사용자의 AI 대화와 결과물에 스며든다.

### L1 — 유료 개인: Film Pack (편당) / Creator Pass (구독)
- **Film Pack**: 그 영화의 전체 자산 — takes 전부(프레임워크·이론가·컨셉 메타 포함), figures, 트로프 허브 에세이, TakeScore 13차원, 정전가, lineage, 촬영지(nominatim), 유사 영화 리스트. `.md` + `.json` 동봉, 30–150KB.
- **Creator Pass $9/월 or $49/년**: 전 영화 Film Pack 무제한 다운로드 + 상업 이용(소규모, <$100k 매출) 허락. *단품 결제($1–3)는 결제 마찰이 이익을 잡아먹으므로 만들지 않는다 — 단품 수요는 무료 트림판이 흡수.*

### L2 — 유료 번들: 주제 팩
- 감독 팩(전작 통합), 프레임워크 팩("정신분석 렌즈 전체 654 takes"), 트로프 팩, canon 팩("Sight&Sound급 정전 100편 통합 팩"), 국가/무브먼트 팩. **$19–79/개.**
- 이것이 실질 주력이다: "내 유튜브 채널은 히치콕 전문" 같은 크리에이터는 번들을 산다.

### L3 — 유료 기관/전체: Corpus License
- 분기 버전드 전체 덤프(Parquet + JSONL + MD 아카이브). 개인/스타트업 **$299/년**, 기업·기관 **$999–협상/년** (내부 RAG·제품 이용 허락 명시).
- 파인튜닝용 JSONL(instruction–output 쌍: "이 형상을 X 프레임워크로 읽어라" → take)은 이 티어에만 포함 — 우리 파이프라인의 부산물이라 생성 비용 0.

## 3. 팩 포맷 설계 (핵심 제품 결정)

원칙: **사람이 읽어도 좋고 LLM이 먹어도 좋은 마크다운 단일 파일**이 기본. JSON은 보조.

```markdown
---
title: "In the Mood for Love"
year: 2000, director: "Wong Kar-wai"
ids: {imdb: tt0118694, wikidata: Q223299, metatake: in-the-mood-for-love}
takescore: {V: 88.2, C: 41.0, R: 18.5, subscores: {...13차원}}
standing: {prestige: 94, discovery: 12}
canon: ["Sight & Sound 2022 #5", "BFI Top 100", ...]
license: "Metatake Creator License — commercial use per metatake.net/data/license"
pack_id: "a7f3..."   # 구매자별 지문 (아래 §5)
---
# In the Mood for Love — Metatake Context Pack

## How to use this file
Claude Projects / Custom GPT / NotebookLM에 첨부하고, 자신의 관점으로 쓰라고 지시하세요.
이 팩은 '정답'이 아니라 14개 비평 프레임워크의 '강한 오독' 모음입니다.

## Figures & Readings (by framework)
### PSYCHOANALYTIC — "The Cheongsam As Armor of Repression" (theorist: Lacan, concept: ...)
[rationale 전문]
...

## Tropes  ## Filming Locations (lat/lng, scene role)  ## Kindred Films
```

- **frontmatter = 기계용, 본문 = LLM·인간 겸용.** "How to use" 섹션이 제품 온보딩을 파일 안에서 해결.
- 스포일러 가드 태그 유지(기존 컨벤션 재사용).
- 제외 필드(법적 게이트, API 기획 §4와 동일): TMDB overview/포스터, OMDb 평점, watch providers, verbatim 인용. **팩 생성 RPC에서 화이트리스트로 강제.**

## 4. 가격·결제

| 상품 | 가격 | 결제 |
|---|---|---|
| L0 복사 | 무료 (CC BY-NC + 출처) | — |
| Creator Pass | $9/월 · $49/년 | Polar.sh (MoR — VAT/JCT 대행, 라이선스 키 기능 내장) 권장. Stripe payment link도 가능 |
| 번들 | $19–79 단건 | 〃 + Gumroad 병행 가능 (~10% 수수료, 발견 채널) |
| Corpus | $299–999+/년 | Polar/Stripe + 간단한 PDF 계약 |

- **선불·단건 중심** — 미터링 없음, 환불 분쟁 표면적 최소.
- Hugging Face gated dataset은 **무료 샘플 팩 20편**만 올려 발견 채널로 (HF에는 결제 레일이 없음 — 전체는 자사 판매로 유도).

## 5. 봇·무단재배포 대응 (유저의 우려에 대한 직접 답)

1. **경계 재정의**: 무료로 새는 것은 이미 공개된 것의 재포장뿐. 지킬 것은 벌크이고, 벌크는 로그인+결제+다운로드 캡(예: Pass는 일 50팩) 뒤에 있다.
2. **구매자별 지문(canary)**: 모든 유료 파일에 구매자 고유 `pack_id` + 본문 내 비가시 변주(문장 순서·유의어 시드) 삽입 → 유출 파일이 돌아다니면 누구 것인지 추적 가능. 저작권이 없어도 **계약 위반 청구의 증거**가 된다.
3. **AI 크롤러 과금 병행**: 사이트 자체에는 Cloudflare pay-per-crawl / TollBit 등록(공짜 옵션) — 크롤러에게도 "정식 팩을 사라"는 가격 신호.
4. **robots/llms.txt 정비**: llms.txt(이미 보유)에 팩 스토어 명시 — AI 검색이 상품 페이지를 인용하게.

## 6. 구현 (기존 스택 위, 총 ~3–5일)

1. **RPC `film_context_pack(slug, tier)`** — 화이트리스트 필드만 조립해 마크다운/JSON 반환. 트림판(L0)과 풀판(L1) 분기. *기존 SECURITY DEFINER RPC 패턴 그대로.*
2. **생성 시점**: 실시간 RPC로 시작(트래픽 낮음), 부하 생기면 발행 파이프라인에서 Supabase Storage로 사전 생성 + 서명 URL(만료 1h).
3. **UI**: 영화 페이지 히어로에 `Copy for AI` 버튼(L0, 무인증) + `Full pack ↓`(L1, 로그인→결제 확인). `/data` 스토어 페이지 신설(번들·코퍼스·라이선스 문구).
4. **권한**: `pack_entitlements` 테이블(user_id, tier, expires) + Polar/Stripe webhook. 다운로드 로그 테이블(수요 데이터 = 차기 기획 입력).
5. **문서**: `/data/license` — Creator License 전문(허용: 자기 콘텐츠 제작·상업 이용 / 금지: 재배포·재판매·경쟁 데이터셋·대량 LLM 학습).

## 7. 수익·비용 추정

- **비용**: 증분 인프라 ~$0 (Storage 몇 GB, 기존 Pro 플랜 내). 구축 3–5일. 운영 ~0 (분쟁 시 건당 대응).
- **수익 (현 트래픽 주 ~140뷰 기준 정직 추정)**: 초기 수개월 0–소액. 이 상품은 **트래픽 종속형**이므로 SEO 개선(PLAN-고유가치)·아웃리치와 커플링해야 의미가 생긴다. 트래픽 10k뷰/월 도달 시 시나리오: 복사 버튼 CTR 3–5% → Pass 전환 1–2% → **$50–300 MRR** + 번들 산발 + Corpus 0–2건/년($300–2k).
- **진짜 단기 수익은 여기서도 기관 딜**: 번들·Corpus는 관광청/교육 피칭(API 기획 §6 Phase 3)의 **견적 단위**로 쓰인다 — "촬영지 팩 + 커스텀 레이어 연 $X".

## 8. 로드맵

- **W1**: 법적 게이트(화이트리스트 RPC) + L0 복사 버튼 전 영화 배포 + 클릭 로깅. ← *여기까지만 해도 수요 데이터가 쌓이기 시작*
- **W2**: `/data` 스토어 + Creator Pass 결제(Polar) + Film Pack 풀판.
- **W3–4**: 번들 5종(감독 2, 프레임워크 1, canon 1, 촬영지 1) + HF 샘플 + llms.txt 갱신 + 런치(Substack/아웃리치 리스트, r/TrueFilm, 영화 유튜버 커뮤니티).
- **분기별**: Corpus 덤프 버전 발행.
- **판정 기준**: 90일 복사 버튼 사용률과 Pass 전환으로 ① 이 라인 지속 ② API 승격 ③ 무료 SEO 기능으로 강등을 결정.

## 9. 리스크

1. **트래픽 병목이 그대로 적용** — 버튼은 방문자가 있어야 눌린다. SEO 플랜과 동시 진행이 전제.
2. **1회 구매 후 이탈** — 팩은 정적이므로 재구매 동인이 약함. 대응: Pass를 기본 상품으로(신작 영화·업데이트 계속 유입), 팩에 버전 스탬프.
3. **품질 노출** — 팩은 코퍼스를 '알몸으로' 보여준다. 저품질 take가 섞이면 환불·평판 문제 → 발행분만 포함 + confidence 하위 컷.
4. **"AI 생성물을 돈 받고 판다" 비판** — 정면 돌파: 팩 표지에 생성 방법·검수 체계 명시(PLAN-고유가치의 프로비넌스 원칙과 동일). 숨기면 스캔들, 밝히면 방법론.
