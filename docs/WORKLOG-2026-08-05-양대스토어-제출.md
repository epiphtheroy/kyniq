## 5. 오늘 발견한 함정 (재발 방지)

- **스토어 콘솔 이미지 업로드**: 파인더 드래그가 브라우저 파일탭으로 새기 쉬움(창을 덮침) → **애셋 추가 클릭→패널→Add from Drive**(오너 Drive "메타테이크 이미지" 폴더)가 확실. `file_upload` 도구는 10MB 한도+세션 공유 경로만이라 .aab(61MB)에 못 씀 — 첫 .aab는 오너 드래그가 정답이었음
- **아이폰 캡처는 Play에 못 올림**: 1284×2778≈9:19.5는 Play 규격(16:9/9:16) 위반으로 업로드 자체가 거부됨. Play용은 반드시 `shots-android/`(1080×1920)
- **form_input 도구가 ASC/Play 커스텀 위젯에서 헛돎**(체크했다고 응답하고 실제 미반영) → **find로 ref 얻어 실클릭**이 정답. 긴 텍스트는 form_input 대신 클릭→cmd+A→type
- **ASC 메모 4,000자 한도**: REVIEW-NOTES.md 전문은 4,613자라 안 들어감 → 축약본 사용(이번에 만든 3,691자 판이 입력돼 있음)
- **Play 광고 ID 선언**: Android 13+ 타겟이면 미선언 시 검토 전송이 통째로 막힘. 앱 콘텐츠 목록에도 안 보이고 전송 시점에야 드러남
- **IARC 설문**: 모든 섹션 답해도 '다음'이 안 눌림 → **저장 먼저** 누르면 다음이 활성화됨
- **콘솔 작업 중 오너가 창 크기를 바꾸면 좌표가 전부 어긋남** → 중요한 클릭은 직전에 좌표 재측정 or ref 클릭. (이 실수로 ASC에서 '사전 주문'이 잘못 선택됐다 정정한 사례 있음)
- **드래프트 유실 주의**: Play 스토어 등록정보 텍스트는 저장 전 탭이 죽으면 날아감 → 입력 직후 **임시보관함에 저장** 습관
