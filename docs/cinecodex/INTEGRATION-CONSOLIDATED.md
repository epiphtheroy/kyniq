# Cinecodex × my_room — 통합 검토 총합 의견 (CONSOLIDATED)

> 5개 병렬 렌즈(개념·데이터·추천·UX·원칙)의 검토를 취합·총합한 *메인의 통합 의견*. 출처: `docs/cinecodex/01~05-*.md`. **아직 아무것도 반영 안 함 — 컨펌 후 문서 업데이트.** 작성 2026-06-30.

---

## 0. 한 문단 결론

**Cinecodex는 my_room에 *깨끗이 ADD-only로* 들어간다 — 구조적 장애 없음.** 정체는 **두 번째 객관 점수**다: 정전가(②)가 *시장가*(세상이 인정했나)라면, Cinecodex는 *펀더멘털 애널리스트 등급*(영화 자체가 무엇을 돌려주고[V] 얼마나 위험한가[R]). 이건 "Bloomberg for cinema" 메타포를 *완성*한다(가격 + 등급 + 위험). 그리고 결정적으로 — **현재 WWI/추천에는 위험 항이 전혀 없어** "야심차지만 실망스러운 영화(바빌론형)"를 못 거르는데, Cinecodex의 미션(실망작 거르기)이 *바로 그 빈칸*이다. 사용자가 직전에 물은 "배트맨 낮게·밀양 높게·망작 거르기"의 진짜 정답도 정전가+평단블렌드가 아니라 **Cinecodex R/U**다. 다만 ⓐ 점수가 *아직 생성 안 됨*(6,701편 채점 ~$11, 외부 환경 필요), ⓑ 어휘·색·DB키·표시원칙 정합이 필요 → **2단계 소화**(지금=문서·원칙 정합 / 나중=점수 생성 후 UI).

## 1. 다섯 렌즈가 수렴한 5가지 (높은 합의)

1. **신규 엔진 ⑨ 「내재가치(Intrinsic Value)」** — 정전가를 *대체 않고* 나란히 서는 두 번째 객관축. (개념·원칙 렌즈 합의)
2. **WWI의 빈 위험 슬롯을 채움** — taste=fit은 ①, 품질·위험은 Cinecodex, 인정은 정전가. WWI의 최대 결함(위험 항 부재)을 정확히 메움. (추천·개념 렌즈)
3. **비섞임 = 단방향 경계** — Cinecodex *산출*은 순수(외부·정전가 입력 금지), 상위 엔진(WWI·NAV)은 그 *출력만 소비*. 역류만 금지하면 충돌 아님. (원칙·추천·데이터 렌즈 만장일치)
4. **어휘·색 충돌은 개명으로 해소** — "10 Levels"≠"레벨 밴드", U≠NAV, risk red≠conquer red. 이름·스코프 분리면 끝. (원칙·UX 렌즈)
5. **ADD-only·uuid 조인·점수 미생성** — 기존 `films`(uuid) 재사용, `cinecodex_*`/`cc_*` 신규, `film_ratings` 단일소스. 카탈로그가 이미 코퍼스. UI는 점수 생성 후. (데이터·UX 렌즈)

## 2. 권고 통합 모델 (총합)

### 2.1 두 객관 기둥 + 단방향 데이터플로우
```
주관(개인)          객관(만인 공통)
  ① 취향벡터    ┌── ② 정전가(Standing)   = 시장가 (외부 인정 집계)
     (fit)      └── ⑨ Cinecodex          = 펀더멘털 등급 (내재 분석)
                      V 획득가치 · C 진입비용 · R 위험 · U=V−λR · S 샤프

데이터플로우(단방향, 비섞임 정본):
  13차원 ─(순수)→ V/C/R/U/S          ← 외부지표·정전가 입력 절대 금지
  V/C/R/U/S ─(출력 소비)→ ⑤WWI · ⑧NAV · 가치뱃지   ← 여기서만 블렌드
  역류(WWI/NAV/정전가 → Cinecodex 입력) = 금지
```

### 2.2 WWI × Cinecodex (추천 렌즈 권고)
```
WWI(f) = (취향·계보·공백·정전 블렌드) × risk_mult(f)
  V → 품질 prior (콜드스타트 시 정전가 시간편향 보완)   ※ U 아닌 V 사용 — 아래 결정②
  R → risk_mult = clamp(1 − ρ·R, floor, 1)   위험이 적합도를 깎되 floor로 고위험 안 죽임
  U → 후보 풀 *품질 게이트*(만인 공통 바닥) + 콜드스타트 폴백
  S → asset-desk 위험조정 정렬
  λ → 사용자 위험회피 다이얼(보수↔모험)
정렬: U-게이트 → WWI(개인 재정렬) → S(선택)
```
핵심: **위험은 합산 아닌 곱셈/게이트** — 6이유 블렌드에 7번째로 안 넣음(비섞임 보존). 위험은 *경고 배지*로 표시.

### 2.3 어휘 정본 (원칙 렌즈 권고)
| 충돌 | 권고 |
|---|---|
| 10 Levels vs 레벨 밴드 | Cinecodex = **「미적 단계」(Aesthetic Tier)**, "레벨"은 *사용자 등급* 전용 |
| U 순가치 vs NAV | U = **「영화 순가치」**(영화 카드), NAV = **「내 NAV」**(헤더 총량) — 스코프 분리 |
| C 진입비용 vs 난이도/커버리지 | C = 난이도 *단일 소스*(점수 가산 아님). "C=준비 필요" ≠ "커버리지=이미 봄" |
| S 샤프 vs P&L/적중률 | S = 후보 효율(매수 전), P&L = 운용 회고(보유 후) — 스코프 분리 |
| POLAR 분열성 | 정본 채택 + **「분열적 ≠ 파산적」** 규칙을 가치뱃지에 상속(분열적 야심을 '고평가 실망'으로 오판 금지) |

### 2.4 DB (데이터 렌즈 권고)
- 기존 `public.films`(uuid) **재사용** — Cinecodex의 `films`(bigserial) 미채택.
- 신규: `cinecodex_scores`(13 median + V/C/R + 신뢰도, film_id uuid FK) · 운영계 `cc_scoring_runs`/`cc_prompt_versions`/`cc_review_queue`/`cc_drift_runs`/`cc_human_audit`.
- 외부지표 = **`film_ratings` 단일 소스**(Cinecodex의 imdb/rt/meta 컬럼 미사용). **주의: 기존 RT는 `rt_tomatometer` 단일** — Cinecodex 문서의 rt_critic/audience 2분할 없음.
- U/S 미저장(λ 가변 → 뷰 `cinecodex_ranked`).
- 조인 뷰 `film_objective_panel`: 정전가·미학·외부지표를 *나란히*(비섞임 표시).
- 생성: Sonnet Batch + 캐싱 ~$11(티어드), median 집계, 드리프트 게이트 → **이 샌드박스 egress 차단이라 외부 환경에서 실행.**

### 2.5 UX (UX 렌즈 권고)
- **신규 「Cinecodex 평가 카드」**(영화별) = 기존 인스펙터 어휘 *재조합*(신규 컴포넌트 최소). (A) 풀 페이지 + (B) 인스펙터 요약 카드. 3축 도넛 + U/S → 미적 단계 → 13 서브점수(접이) → **나란히 3분할**(우리/외부/정전 — 안 섞음) → 신뢰도 카드(접이).
- **μ–σ 평면**(V 세로 × R 가로): 영화 위치 + 내 포트폴리오 분포(분석 페이지).
- watchlist: **위험 배지 + U/R 컬럼 + 위험 필터**(최고 가치). collection: 자산/미학 뷰 토글. command-center: U/R 경량 요약.
- 신규 표시 표준 **S11**(나란히·신뢰도·재현성 카드 + `--risk` 색 토큰[red=conquer와 충돌 회피] + 저신뢰 흐림 — 단 *분열적≠불신뢰* 주의).
- **「Cinecodex 미평가」 빈 상태** 필수(점수 생성 전).

## 3. 소화 순서 (총합 — 2단계)

**STEP A — 지금(점수 없이도 가능, 문서·원칙 정합):**
1. `MASTER-INDEX §4` — 단방향 비섞임 원칙 + Cinecodex 9개 용어를 스코프 라벨로 등록 (정본 단일소스, *최우선*).
2. `SHARED-STANDARD` — **S11 표시 표준**(나란히/신뢰도/재현성/`--risk` 색) + S5 용어집 확장.
3. `INTUITION-ORDER` — 숨김(계산) vs 투명(근거·신뢰도) 경계 + **Contract K**(신뢰도·재현성 표시).
4. 신규 **엔진 ⑨ 명세** `docs/logic/09-intrinsic-cinecodex.md` + `00-INDEX` 8→9 엔진.
5. `phase2-taste §7` — WWI가 Cinecodex V(prior)·R(필터)·λ 소비하는 경계 명세(역류 금지).

**STEP B — 점수 생성 후(외부 환경 ~$11):**
6. `cinecodex_*`/`cc_*` 스키마 적용(승인 후) + 파이프라인 실행 + 드리프트/신뢰도.
7. UI: 평가 카드 + μ–σ + watchlist 위험 + 빈 상태 → 다크 셸 일관.
8. 검증: 정전가↔Cinecodex 상관 1개(prestige v2 기준), 인간 감사 α, 공개.

**의존 잠금:** STEP A.1(MASTER-INDEX)가 모든 것에 선행(아니면 비섞임이 역류). S11↔phase2는 같이(표시·계산 양쪽이 같은 비섞임 강제). 어휘 개명은 A.1에서 잠근 뒤 산개 치환.

## 4. 사용자 결정 필요 (컨펌 항목 — 각 메인 권고 포함)

1. **엔진 ⑨ 정식 승격** — Cinecodex를 9번째 코어 엔진으로? → **권고: 예**(정전가와 대등한 객관축).
2. **WWI 품질 prior = U vs V** — U는 이미 R을 뺀 값이라, WWI가 R을 또 곱하면 *위험 이중계산*. → **권고: V를 prior로, R은 별도 필터**(이중계산 회피).
3. **λ 위험회피 다이얼 노출** — 사용자에게 보수↔모험 다이얼을 줄까? → **권고: 예, 단 "선호 다이얼"로**(내부 로직 노출 아님 — INTUITION 위배 아님).
4. **가치뱃지 축** — 1축(별점 vs 정전가) 유지 vs 2축(+별점 vs V) → **권고: 2축, 단 V축은 2차 상세**(과부하 방지).
5. **통합 타이밍** — 지금 STEP A(문서·원칙)만, UI는 점수 생성 후? → **권고: 예**(점수 없이 UI 무의미).
6. **채점 파이프라인 실행** — ~$11, 외부 환경 필요. 지금 돌릴지/대상(visible 1,935 vs 전체 6,701)? → **권고: STEP A 후 별도 결정**.
7. **메인의 이전 "평단-블렌드" 제안** — 폐기? → **권고: 폐기/재배치**(정전가=시장가 순수 유지, 내재·망작은 Cinecodex가 담당).

## 5. 충돌 요약 (consolidated `[⚠COORD]`)
- **비섞임 단방향** = 전 렌즈 공통 1순위 원칙(역류 금지).
- **테이블명/키**: `film_scores` 충돌 → `cinecodex_scores`; bigserial→**uuid** 재정의.
- **색**: risk red ↔ conquer red(S2) 충돌 → `--risk` 신토큰.
- **레벨 개명**: 미적 단계 ≠ 사용자 레벨 밴드. (+기존 SEEDLING vs Novice 내부 불일치도 같이 정리.)
- **공개 프로필**: 13서브·신뢰도·prompt_sha는 비공개(다크 셸 전용).
- **이중계산**: WWI prior에 U vs V(결정②).
- **RT 2분할 부재**: 표시는 tomatometer 단일.
