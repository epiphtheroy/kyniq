## 1. 우리가 하려는 것 (처음 듣는 사람을 위해)

**한 문장:** 영화사·비평·시상이 그어 놓은 *모든 계보 라인*에 대해 — "이 라인 전체 중 내가 몇 편을 봤나"를 라인별로 세어, **커버리지 매트릭스·게이지·도장깨기 진척의 원시 토대**를 만드는 엔진.

왜 필요한가. 자산 비유에서 영화 한 편은 자산이고, 본 영화 전체는 **포트폴리오**이며, 유한한 관람생애는 **자본**이다. 그런데 포트폴리오를 운용하려면 먼저 *"내가 시장의 어느 구역을 얼마나 보유했나"* 를 알아야 한다. 칸 황금종려 77편 중 21편, TSPDT 1000 중 188편, 봉준호 대표작 6편 중 5편 — 이 **"관람/전체" 분수**가 이 엔진의 단위 산출물이다. 그 위에서 비로소 "어디가 비었나(공백·엔진④)", "무엇을 완성하면 도장을 깨나(엔진⑤ conquer)", "내 자산 총량은 얼마인가(엔진⑧ NAV)"가 계산된다.

**엔진③(관련성)과의 결정적 구분 — 같은 `film_lineage`를 읽지만 정반대 질문을 던진다.**
- **엔진③ 리니지 관련성** = *"어느 계보가 **나에게 맞나**"* 의 **랭킹**. 취향 벡터(엔진①)와 라인을 교차해 "당신이 다음에 정복할 만한 계보"를 *주관적으로 정렬*한다. 출력은 순서가 있는 추천 리스트.
- **엔진⑦ 커버리지** = *"그 계보를 **몇 % 봤나**"* 의 **측정**. 취향과 무관하게, 라인 전체를 분모로 *기계적으로 집계*한다. 출력은 라인별 분수(`seen/total`)와 그 집계.

→ ③은 "**내 것**"(친연), ⑦은 "**원시 진척**"(사실). ⑦은 ③의 *입력 재료*가 되지만(관련성 랭킹은 "낮은 커버리지 × 높은 친연"을 노린다), ⑦ 자체는 사용자 취향을 1g도 섞지 않는다. **이 무취향성이 커버리지를 신뢰 가능한 사실 레이어로 만든다** — 정전가(엔진②)가 객관인 것과 같은 이유다. 차이는, 정전가는 *영화 1편의* 객관값이고 커버리지는 *나의 관람사 × 라인*의 객관값(사용자별이되 취향 무관)이라는 점이다.

**핵심 차별점.** Letterboxd의 "you've watched 38 of the IMDb Top 250"는 *한 리스트의 단순 카운트*다. MetaTake는 **115개+ 라인을 위계·등급·축으로 구조화한 커버리지 시스템**이다. 라인마다 권위가 다르고(T1 황금종려 vs T3 실버콘도르), 분모의 성격이 다르고(77편 vs 1000편), 축이 다르다(연대·국가·사조). 그래서 우리는 *"몇 % 봤나"를 그냥 세는 게 아니라, 그 %들을 권위로 가중해 단일 KPI로 압축*하고, *축별로 세계 정전 분포 위에 투영*한다. 그게 "가중 정전 커버리지 23.4%"와 "1960년 이전 노출 얕음"이라는, 단순 카운트가 줄 수 없는 진단이다.

## 2. 목표 산출물 (사용자 경험 중심)

커버리지는 **숫자 그대로** 노출된다(취향 벡터처럼 숨기지 않는다 — 정전가와 같은 부류의 "사실"). 다만 4개 면이 각각 다른 입자도로 소비한다.

| 사용자가 보는 것 | 어디서 (목업) | 무엇 |
|---|---|---|
| **계보 커버리지 매트릭스** — `Palme d'Or 21/77 (27%)`, `TSPDT 188/1000 (19%)`, `KOFA 52/100 (52%)` … 등급순 그룹(FESTIVAL/AWARD·CANON·NATIONAL) | `command-center` 현황 | **라인별 커버리지의 1차 산출** (§5의 직접 출력) |
| **"가중 커버리지 23.4%" KPI** (▲1.1) | `command-center` 헤더 KPI | **가중 정전 커버리지** = tier·authority 가중 단일 숫자(§4b·§5) |
| **연대 커버리지** — 관람 막대 vs 정전 유니버스 막대, "1960년 이전 노출 얕음" | `command-center`·`analysis-v2` | **연대축 커버리지**(§4d) |
| **국가 커버리지** — 국가별 관람 분포, "국가 정전 노출" | `analysis-v2` | **국가축 커버리지**(§4d) |
| **감독 정복 G1–G5** — `G1 18/26 정복률 69%`, "근접 정복: 브레송 5/6 · 하네케 6/7" | `command-center`·`asset-desk` | **감독 filmography 완성**(§4e) → 엔진⑤ conquer |
| **리니지 완파 보드** — "브레송 1편 남음 5/6", "거의 다 깸" 알림 | `asset-desk` 운용 | **completion 진척**(§4e) → 엔진⑤ |
| **프로필 리니지 바** — `칸 황금종려 27%`, `S&S 2022 41%`, `KOFA 52%` | `profile` 공개 | 커버리지의 *공개용 셀렉션*(라인 4–5개) |
| **정전 38/250** 통계·뱃지("정전 38/250 커버리지") | `profile` 스탯/뱃지 | **요약 커버리지**(대표 분모 1개) |

**저장(사용자 단위, `user_coverage`):**
```
user_id,
line_coverage jsonb,    -- 라인별 {list_id: {seen, total, pct, tier, authority}} (1차 산출, 매트릭스·바·완파의 토대)
weighted_coverage,      -- 가중 정전 커버리지 % (현황 KPI, 단일 숫자)
axis_coverage jsonb,    -- {decade:[...], country:[...], movement:[...]} 축별 커버리지
director_completion jsonb, -- {auteur_id: {seen_rep, total_rep, pct, near_complete}}
data_completeness,      -- 0–1, film_lineage 적재율(§4f, 가짜 낮음 방지)
model_version, computed_at
```

**경험 품질의 기준:** "21/77"을 클릭하면 *어느 21편을 봤고 56편이 비었는지*가 즉시 나와야 한다(설명가능성·`07` 원칙). "거의 다 깸"이 "정확히 1편 남았고 그게 〈L'Argent〉"로 분해되지 않으면 실패. 가중 23.4%가 *어느 라인이 끌어올리고 어느 라인이 끌어내렸는지* 분해되지 않으면 블랙박스 = 금지.

## 3. 활용 가능한 데이터

커버리지는 **두 집합의 교집합 카운트**다: *내가 본 영화*(사용자) × *라인의 전체 멤버*(객관). 취향·평점·해석은 **들어가지 않는다**(무취향성이 사실성의 정의).

| 데이터 | 위치 | 역할 |
|---|---|---|
| **내가 본 영화** | `user_films (status=watched)` | 분자(seen)의 원천. **평점 무관**(본 것은 본 것). |
| **영화-라인 멤버십** | `film_lineage` (10,238행, handoff `mappings/`) | 분모(total)와 교집합. `result`·`rank` 보존하나 커버리지는 *멤버 여부*만 본다(won이든 listed든 "그 라인에 속함"). |
| **라인 어휘·크기·등급** | `lineage_lists` (239개) — `tier`(T1–T4), `authority_weight`(0–1), `facet`(8종), `film_count`(파생), `selectivity`(IDF), `parent_id` | 분모 정의·가중·위계·축 분류. **커버리지의 두 번째 1차 재료.** |
| **에디션·순위폭** | `lineage_editions` (24개) — `rank_max` | 분모 확정(TSPDT는 rank_max=1000). S&S 여러 에디션의 합집합 처리. |
| **감독 대표작** | `film_auteur` (407행, `rep_type` defining/recent/both) | 감독 completion 분모(대표작 N편 중 몇). |
| **감독 등급** | `auteurs.group`(G1–G5) | 감독 정복의 등급 그룹화(G1 거장 우선). |
| **영화 메타(축)** | `films`(year·country) + 라인 `country`·movement facet | 연대·국가·사조 축의 분자/분모. |
| **적재 상태** | `films.in_seed_catalog`, `film_lineage.computed_at`, 라인 적재율 | **데이터 완전성**(§4f) — 가짜 낮은 커버리지 방지. |

**핵심 분포(handoff 실측):** 라인 facet = movement 67 · award 56 · national 47 · section 18 · festival 18 · canon 18 · style 15. 이 중 **커버리지에 쓰는 facet = award·canon·national·section·auteur·festival**(품질·진척 라인). **movement·style은 커버리지 "진척" 매트릭스에서 제외**하고 *별도 사조 축*(§4d, 닮음 측정)으로만 다룬다 — 엔진②가 movement/style을 정전가에서 빼는 것과 같은 경계.

**주의(엔진①과 동형):** 분모의 풍부함은 라인마다 극단적으로 다르다. 칸 팔메는 77편(완전 열거 가능), TSPDT는 1000편(부분 정복만 현실적). 이 비대칭이 §4a의 본질 문제다.

## 4. 본질적 문제 · 설계 주의점 · 방향성

여기가 설계의 심장이다. 6개 결정 지점(과제가 명시한 a–f), 각각 *문제 → 권장 방향*.

### (a) ★분모 문제 — 커버리지 %의 의미가 라인마다 다르다
〈칸 팔메〉는 **77편**(매년 1편, 완전 열거). 21편 봤으면 27% — 그리고 *원리적으로 100% 정복 가능*하다. 〈TSPDT 1000〉은 **1000편**. 188편 봤으면 19% — 그리고 *한 사람이 100% 정복하는 건 비현실적*이다. 두 19%·27%를 같은 자에 놓으면 거짓말을 한다: 팔메 27%는 "꽤 봤다", TSPDT 19%는 "사실 깊이 팠다"일 수 있다. **분모가 작은 라인의 %는 "완성도", 분모가 큰 라인의 %는 "탐사 깊이"** 라는, 본질적으로 다른 양이다.

- **방향 — 분모를 그대로 두되, 의미를 *라인 유형으로 분류*해 표시한다.** %를 라인 크기로 정규화하지 *않는다*(정규화는 27%를 거짓으로 부풀린다). 대신:
  - **완파형(finite, total ≲ 100)** — 팔메·황금사자·국가 작품상·감독 filmography. "21/77"을 *완성 게이지*로 본다. 100% 도달이 "도장깨기"의 의미 있는 목표(엔진⑤). 매트릭스·완파 보드의 1급 시민.
  - **탐사형(deep, total ≳ 300)** — TSPDT 1000·NFR 925·1001 Movies. "188/1000"을 *깊이 지표*로 본다. 100%는 비현실 → 목표는 백분위("상위 X%의 탐사 깊이")나 절대 카운트("188편")로 표시. 도장깨기 대상 아님.
  - **표시 규칙:** 매트릭스는 **항상 `분수 + %` 둘 다**(`188/1000 · 19%`) 노출해 분모를 숨기지 않는다(목업 그대로). 탐사형은 % 막대 옆에 분모 크기를 시각적으로 (회색 배경 길이로) 암시한다. **단일 가중 KPI(§b)가 이 비대칭을 흡수**한다 — 라인을 평평히 평균내지 않고 권위·크기로 가중하므로.
  - 분모 자체의 신뢰: `total`은 `lineage_lists.film_count`(적재 후 재계산) 또는 `editions.rank_max`(TSPDT=1000)에서 온다. **적재 미완이면 분모가 가짜로 작다** → §f.

### (b) ★가중 커버리지 — 단일 "가중 정전 커버리지 %" KPI
115개 라인의 %를 사용자에게 다 보여줄 순 없다. 현황 헤더엔 *한 숫자*("가중 커버리지 23.4%")가 필요하다. 그런데 단순 평균은 틀렸다: **권위 높은 라인 1편이 약한 라인 1편보다 가치 있다.** 황금종려 1편을 본 것과 실버콘도르(아르헨, T3) 1편을 본 것이 같은 무게면 KPI가 거짓말한다.

- **방향 — tier·authority 가중 분수 합.** 라인 i의 (seen_i, total_i)에 **라인 가중 W_i**를 매겨 *가중된 분자 합 / 가중된 분모 합*:
  ```
  weighted_coverage = Σ_i [ W_i · seen_i ] / Σ_i [ W_i · total_i ]
  W_i = authority_weight(line_i) · size_damp(total_i)
  ```
  - `authority_weight`(0–1, T1≈.90–1.0 / T2≈.70–.88 / T3≈.50–.68 / T4≈.30–.45)가 *권위 1편의 값*을 정한다. 황금종려 1편 ≈ 실버콘도르 약 1.8편의 가치.
  - **`size_damp`** = 거대 분모가 KPI를 지배하지 않게 하는 댐핑(§a 분모 문제의 KPI측 해소). 순진하게 가중분모를 합치면 TSPDT 1000이 분모를 삼켜 KPI가 "TSPDT 커버리지"로 환원된다. `size_damp(total) = 1 / log(total + e)` 또는 분모 캡(예: total을 min(total, 150)으로 잘라 탐사형의 표 비중을 제한). **가설:** 캡 방식이 더 설명가능(가설). 이로써 KPI는 *완파형 라인이 주도하고 탐사형이 보조*하는, 직관과 맞는 단일 숫자가 된다.
  - **분해 보존(필수):** `components`에 *각 라인의 W_i·seen_i 기여*를 저장 → "23.4%를 어느 라인이 끌어올렸나"가 한 줄로 납득(KOFA 52%가 +X, 베를린 7%가 −Y). 블랙박스 금지.
  - 이 KPI는 *현황의 단일 진척 지표*이지 NAV가 아니다. NAV(엔진⑧)는 *내가 보유한 자산의 가치 총합*(정전가 가중), weighted_coverage는 *시장 정전의 몇 %를 점유했나*(시장 대비 커버). 둘은 보완.

### (c) ★위계 중복 제거 — festival→section→award, canon 교집합
한 영화가 여러 라인에 동시 속하는 건 **정상이고 풍부함의 표시**다: 〈기생충〉은 칸 경쟁(section) ∈ 칸 팔메(award) ∈ 칸(festival) + 오스카 작품 + TSPDT + S&S에 동시 등재. 문제는 **커버리지를 합산할 때**다.

- **방향 — 라인은 독립 단위로 집계하되, 위계 컨테이너의 중복 카운트만 막는다.**
  - **라인 간 멤버십은 합산하지 않는다.** "칸 팔메 21/77"과 "오스카 28/97"은 *각각 독립적으로* 센다. 〈기생충〉이 둘 다에 들어 양쪽 분자를 +1 하는 건 **정상** — 두 라인은 서로 다른 질문("팔메를 몇 봤나" vs "오스카를 몇 봤나")이다. 이건 중복이 아니라 다축 사실.
  - **위계 컨테이너(festival 부모노드)는 커버리지 매트릭스에서 제외.** `facet=festival`(칸·베니스 등 18개)은 컨테이너이지 라인이 아니다(handoff: 직접 멤버 불필요). 커버리지는 *그 아래 section·award*에서만 센다. `parent_id`로 컨테이너를 식별해 제외.
  - **section ⊂ award 흡수(선택).** 칸 경쟁(selected) 멤버십과 칸 팔메(won)는 다른 라인이므로 각각 셈이 원칙. 단 *"칸 커버리지"를 하나로 롤업해 보여줄 때*는 합집합(distinct films in any 칸 라인)으로 중복 제거. 매트릭스는 라인별(독립), 롤업 KPI는 합집합 — **층위에 따라 다른 규칙.** 1차안: 매트릭스=독립, KPI는 §b 가중합(중복 영화가 여러 라인에 기여하는 건 허용 — 권위 높은 영화가 더 세지는 건 의도된 신호).
  - **canon 교집합:** S&S 2022·TSPDT·1001 Movies는 영화가 대거 겹친다. 각 라인 커버리지는 독립이되, **"정전 38/250" 같은 요약 분모(profile)는 *합집합 정전 유니버스*로 정의**(중복 제거된 distinct canon films). 이 요약 분모(250)는 라인들의 단순 합(100+100+1000…)이 아니라 *큐레이트된 코어 정전 합집합*이어야 의미 있다(§8 미정).

### (d) ★축별 커버리지 — 연대·국가·사조
매트릭스가 "라인별"이라면, 분석면은 **축별**이다: 내 관람사를 *시간·공간·사조*에 투영해 "1960년 이전이 비었다", "라틴아메리카 4%"를 진단한다. 각 축은 **자기만의 분모(세계 정전 분포)** 가 필요하다.

- **방향 — 축마다 분모를 "세계 정전 유니버스"로 잡고, 내 관람을 그 위에 겹친다.**
  - **연대축:** 분모 = 정전 유니버스의 연대 분포(`films` × 정전 라인 멤버십의 decade 히스토그램, 목업의 "6,733편" 회색 막대). 분자 = 내 관람의 decade 히스토그램(빨강 막대). 커버리지 = 빨강/회색. "1960년 이전 노출 얕음"은 *그 구간의 분자/분모가 낮다*는 뜻 — **절대 관람 수가 아니라 정전 분포 대비**여야 정직(옛 영화는 정전 유니버스도 작으므로).
  - **국가축:** 분모 = 국가별 정전 라인 멤버 수(각국 national 정전·국가상 크기). 분자 = 내가 본 그 나라 영화 중 정전 멤버. "라틴아메리카 정전 4%"는 Ariel·Abraccine·Condor 등 라틴 라인들의 *가중 평균 커버리지*(§b를 대륙 부분집합에 적용).
  - **사조축(movement):** ★주의 — 사조는 **품질·진척이 아니라 닮음**(엔진①/⑥의 SimilarityVector 영역, 엔진②가 정전가에서 빼는 것). 그래서 *진척 매트릭스엔 안 넣지만*, 분석면의 "사조 마스터리"(목업 command-center)는 **별도 닮음 커버리지**로 표시 — "이탈리아 네오리얼리즘 75 · Cinema Novo 0"은 *내 관람이 그 사조에 얼마나 닿았나*(노출도)이지 정전 진척이 아니다. 라벨을 분리(진척 ≠ 노출)해 범주 오류를 막는다.
  - 각 축은 *같은 user_films를 다른 분류축으로 재집계*한 것 — 새 데이터가 아니라 같은 사실의 다른 투영. `axis_coverage`에 함께 머티리얼라이즈.

### (e) ★완성(completion) — "거의 다 깸"의 정의 → 엔진⑤ conquer 입력
도장깨기(엔진⑤ conquer)는 *"이 계보를 완성에 가깝게 만들었다"* 는 서사를 판다. 그 입력이 ⑦의 **completion 신호**다: 감독 filmography·정전 리스트가 *얼마나 다 찼나*, 특히 **"거의 다 깸"(near-complete)** 의 정확한 정의.

- **방향 — 완파형 라인에 한해 completion·near-complete를 산출.**
  - **감독 completion:** 분모 = `film_auteur`의 대표작(`rep_type ∈ {defining, both}` 우선, 또는 전체 rep). 분자 = 그중 본 편수. `오즈 1/8`, `브레송 5/6`처럼. **`near_complete = (remaining ≤ τ_rem AND pct ≥ τ_pct)`** — *남은 편수가 1–2편 이내이고 이미 충분히 진행*. **가설:** τ_rem=2, τ_pct=0.75. 브레송 5/6(1편 남음, 83%)·하네케 6/7(86%)·다르덴 5/6 = near-complete. 오즈 1/8(7편 남음, 12.5%)는 아님. 이 near-complete 집합이 *"완파 임박" 알림*(asset-desk 보드)과 엔진⑤의 conquer 추천 시드.
  - **정전 리스트 completion:** 완파형 라인(total ≲ 100)에만 적용. 팔메 21/77은 27%(완파 진행 중), KOFA 52/100은 52%. near-complete 라인 = pct ≥ τ_canon(**가설** 0.85)인 작은 라인. 탐사형(TSPDT)은 completion 대상 아님(§a).
  - **출력 계약:** ⑦은 *"무엇이 얼마나 찼나"의 사실*만 내보낸다(`director_completion`, near-complete 플래그). *"그래서 무엇을 추천하나"*(어느 1편을, 친연·취득가능성 고려해)는 엔진⑤의 일. ⑦은 "브레송 1편 남음"까지, "그 1편은 〈L'Argent〉이고 지금 무료"는 ⑤. 경계를 깨끗이.
  - **감독 등급 정복(G1–G5):** 감독 completion을 group으로 집계 → "G1 18/26 정복률 69%"(목업). G1(거장) 정복률이 시네필 깊이의 1급 지표. **블라인드 거장**(G1인데 0–1편) = 엔진④ 공백의 고가치 시드.

### (f) ★콜드스타트 / 데이터 완전성 — 가짜로 낮은 커버리지
커버리지는 `film_lineage` 적재에 *이중으로* 의존한다: **분자**(내 영화가 어느 라인인지)와 **분모**(라인 전체 크기) 둘 다. 둘 중 하나라도 미적재면 커버리지가 **가짜로 낮다**(거짓 음성) — 엔진②(d)의 "미적재 vs 진짜 낮음" 문제와 *동일*하되, 커버리지는 *분자에서도* 같은 함정이 있어 더 위험하다.

- **방향 — `data_completeness`로 "안 봐서 낮음"과 "데이터가 없어서 낮음"을 분리.**
  - **분자 함정:** 내가 〈마티〉를 봤는데 그 영화의 팔메 멤버십이 `film_lineage`에 미적재거나 TMDB resolve 실패(`in_seed_catalog=false`)면, 내 팔메 커버리지가 21이 아니라 20으로 가짜 하락. → **콜드스타트와 무관하게, 라인 적재율을 검증**(`verify.sql`)하고, 내 본 영화 중 *resolve 안 된 stub 비율*을 추적.
  - **분모 함정:** 라인이 부분 적재(예: 1001 Movies 160/1434)면 분모가 가짜로 작아 커버리지가 *가짜로 높다.* → 분모는 *적재 완료 라인*에서만 신뢰. 라인별 `is_complete` 플래그(handoff의 "완전 열거" 라인 vs 부분).
  - **콜드스타트(신규 사용자):** 5편 본 사용자의 커버리지는 거의 전부 0% — 이건 정상(아직 안 봄)이지 데이터 문제가 아니다. 단 UI는 "형성 중"으로 표시하고 *절대 카운트*("3편 봤어요")를 우선, %는 표본이 쌓인 뒤. 온보딩에서 리니지 불러오기(목업 onboard-v2)로 커버리지를 빠르게 시딩.
  - **표시 규칙:** `data_completeness < 임계`면 해당 라인/축에 "데이터 적재 중" 라벨, 커버리지 게이지는 회색 처리. **"안 봐서 4%"와 "데이터가 없어서 4%"를 절대 같게 보이지 않게** 한다(엔진② (d) 재확인). 이게 신뢰의 핵심.

## 5. 권장 설계 (1차안 — 못박을 공식)

> 모든 상수는 *가설*. 실데이터로 캘리브레이션(§6). 핵심은 *형태*를 고정하는 것.

**라인별 커버리지** (1차 산출, 라인 i):
```
seen_i  = |{ f ∈ user_films(watched) : f ∈ members(line_i) }|     # 평점·해석 무관
total_i = lineage_lists.film_count(i)  or  editions.rank_max(i)    # 적재 완료 라인만 신뢰
pct_i   = seen_i / total_i
type_i  = (total_i ≤ θ_finite) ? "finite" : "deep"                 # θ_finite = 150 (가설)
```
*facet ∈ {award, canon, national, section, auteur} 만 진척 집계. festival 컨테이너·movement·style 제외.*

**가중 정전 커버리지 KPI** (단일 숫자):
```
W_i = authority_weight(i) · size_damp(total_i)
size_damp(t) = 1 / log(min(t, T_cap) + e)        # T_cap = 150 (가설), 거대 분모 댐핑
weighted_coverage = Σ_i W_i·seen_i  /  Σ_i W_i·total_i
components[i] = W_i·seen_i  (기여 보존, 설명가능성 필수)
```

**축별 커버리지** (같은 user_films의 재투영):
```
연대:   cov_decade[d]  = seen_in_decade[d] / canon_universe_in_decade[d]
국가:   cov_country[c] = seen_canon[c]     / canon_lines_size[c]
사조:   exposure_movement[m] = seen_in_movement[m] / movement_size[m]   # 진척 아님 — 닮음/노출 라벨
```

**감독 completion** (완파형):
```
seen_rep(a)  = |본 영화 ∩ film_auteur(a, rep_type∈{defining,both})|
total_rep(a) = |film_auteur(a) 대표작|
pct(a)       = seen_rep / total_rep
near_complete(a) = (total_rep − seen_rep ≤ τ_rem) AND (pct ≥ τ_pct)    # τ_rem=2, τ_pct=0.75 (가설)
group_conquest(g) = Σ_{a∈g} seen_rep / Σ_{a∈g} total_rep              # G1–G5 정복률
```

**데이터 완전성:**
```
data_completeness = (resolve된 본 영화 / 전체 본 영화) · (적재완료 라인 / 집계대상 라인)
라인/축별 is_complete 플래그로 "미적재 가짜 낮음" 차단(§4f).
```

**저장:** `user_coverage(user_id, line_coverage jsonb, weighted_coverage, axis_coverage jsonb, director_completion jsonb, data_completeness, model_version, computed_at)`.

**예시(목업 포트폴리오 wonwoo):** 팔메 21/77(27%, finite) · TSPDT 188/1000(19%, deep) · KOFA 52/100(52%, finite) · 베를린 5/74(7%) · 라틴 4%(국가축) · 브레송 5/6(near-complete) · G1 18/26(69%). 가중합 → **weighted_coverage ≈ 23.4%**(KOFA·S&S 등 고권위·고커버 라인이 끌어올리고, 베를린·실버콘도르 저커버가 끌어내림; TSPDT는 size_damp로 표 비중 제한).

## 6. 콜드스타트 · 캘리브레이션 · 갱신

- **0–10편(콜드스타트):** 거의 모든 라인 0% — *정상*(안 봄). UI "형성 중", **절대 카운트 우선**("3편"), % 보류. 온보딩 리니지 불러오기로 시딩. `data_completeness` 라벨로 "데이터 없음 ≠ 안 봄" 구분.
- **10–50편:** 완파형 라인 커버리지 의미 생김. near-complete 감독 등장. 축별 공백(연대·대륙) 진단 가능.
- **50편+:** 가중 KPI 안정, 도장깨기 서사 풍부.
- **캘리브레이션:** `θ_finite`(150)·`T_cap`(150)·`size_damp` 형태·`τ_rem/τ_pct`(2/0.75)·`τ_canon`(0.85)을 코퍼스로 튜닝("가중 커버리지 중앙값 ≈ 적정 밴드", near-complete가 *실제로 1–2편 남은 것만* 잡히게). 상수는 *가설*, 형태만 고정.
- **갱신:** 본 영화 추가/제거 시 dirty → 증분 갱신(새 영화 1편의 라인 멤버십만 분자에 ±1). 라인 적재/변경 시 *전원* 분모 재계산(사용자 무관 대량 배치). `model_version` 불일치 시 전체 재계산. TTL(예: 홈 캐시 패턴) 또는 트리거.
- **데이터 완전성 선행:** 커버리지 계산 전 `verify.sql`로 라인 적재율·resolve 실패율 점검. 미완 라인은 `is_complete=false`로 마킹해 가짜 분모를 배제.

## 7. 다른 엔진과의 인터페이스 (이 엔진이 *내보내는* 것)

| 소비처 | 쓰는 산출물 |
|---|---|
| **현황(command-center)** | `line_coverage`(매트릭스) · `weighted_coverage`(KPI 23.4%) · `axis_coverage.decade`(연대 커버리지) · `director_completion`(G1–G5 정복) |
| **분석(analysis)** | `axis_coverage.decade/country/movement`(연대·국가·사조) · `line_coverage`(리니지 멤버십) |
| **운용(asset-desk)** | `director_completion.near_complete`(완파 보드 "1편 남음") · 커버리지 요약 피드 |
| **프로필(profile)** | `line_coverage` 셀렉션(리니지 바 4–5개) · 요약 분모("정전 38/250") · 커버리지 뱃지 |
| **⑤ WWI/conquer(도장깨기)** | `director_completion`·near-complete·완파형 라인 진척 = **conquer 이유의 원시 입력**(어느 계보가 완성 임박인가) |
| **④ 공백/희소** | 저커버리지 라인·축 + 블라인드 거장(G1 0–1편) = 공백 시드(권위 가중은 엔진②) |
| **⑧ NAV/레벨** | `weighted_coverage`·G1 정복률·축 폭 = 레벨 밴드의 한 입력(시장 점유 측면) |
| **③ 리니지 관련성** | `line_coverage`(낮은 커버리지 라인 = 관련성 랭킹의 "정복 여지" 입력 — ③이 취향과 곱한다) |

**계약:** 이 엔진은 `{line_coverage[], weighted_coverage, axis_coverage{decade,country,movement}, director_completion[], data_completeness}` 를 항상 제공한다. 입력은 **`user_films` · `film_lineage` · `lineage_lists`**(+ `lineage_editions`·`film_auteur`). **사용자 취향·평점·해석은 입력에 없다**(무취향 사실 레이어).

**엔진 ③과의 관계(명시·재확인):** ③ 리니지 관련성 = *주관 랭킹*("어느 계보가 나에게 맞나"), ⑦ 커버리지 = *객관 측정*("그 계보를 몇 % 봤나"). 둘은 같은 `film_lineage`를 읽지만 **독립**이며, ③은 ⑦의 *커버리지를 입력으로 소비*한다(관련성 = f(친연, *낮은 커버리지의 정복 여지*)). ⑦이 "팔메 27%"라는 사실을 주면, ③이 "당신 취향상 팔메를 완파할 가치가 높다"는 *판단*을 더한다. 측정이 먼저, 판단이 나중.

**엔진 ②와의 관계:** ② 정전가 = *영화 1편의* 객관값, ⑦ 커버리지 = *나의 관람사 × 라인*의 객관값. ⑦의 가중(`authority_weight`)은 ②와 같은 라인 권위를 쓴다 — 두 엔진은 같은 권위 척도 위에 선다. NAV(⑧)에서 ②(보유 자산의 값)와 ⑦(시장 커버 폭)이 보완적으로 합쳐진다.
