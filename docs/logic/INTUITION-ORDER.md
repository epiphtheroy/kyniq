# 직관·예측가능성 기준 — 로직 설계 순서 (INTUITION-ORDER)

> **지배 원칙: 로직은 숨긴다. 결과는 사용자의 기대를 절대 배신하지 않는다(least astonishment).** 짝 문서 `BUILD-ORDER.md`가 *데이터·구현 순서*라면, 이 문서는 *사용자 기대 순서* — 무엇을 먼저 "맞게" 만들어야 신뢰가 서는가. 작성 2026-06-25. 모든 엔진(`0N-*.md`)·불변식이 이 계약을 상속한다.

---

## 1. 왜 이 기준인가

사용자에게 우리 로직을 *보여주지도 설명하지도* 않는다. 그런데도 사용자는 직관적이길 원한다. 직관 = **예측가능성**: "이걸 누르면 이렇게 되겠지"가 맞아떨어지는 것. 

핵심 통찰: **화면에 뜨는 모든 숫자·추천은 사용자와 맺는 암묵적 약속이다.** "정전가"는 *이 영화의 객관적 값*이라는 약속, "추천"은 *내가 안 봤고 나에게 맞는다*는 약속, "보유 142편"은 *어느 화면에서도 142*라는 약속. 약속 하나가 깨지면(명작이 정전가 51, 이미 본 영화를 추천, 페이지마다 다른 카운트) — 로직 전체에 대한 신뢰가 무너진다.

그래서 설계 순서는 *난이도*가 아니라 **기대의 강도 × 어겼을 때의 파괴력** 으로 정한다. 그리고 그 약속을 지키는 건 대개 화려한 추천 알고리즘이 아니라 **작고 지루한 정합 로직**(중복 제거, 본 것 제외, 안정 정렬, 반올림)이다. 그래서 그것들을 *맨 앞*에 둔다.

---

## 2. 직관 계약 (Intuition Contract) — 빠짐없이

사용자가 *말로 하진 않지만 당연히 기대하는* 것들. 각각: 기대 → 보장 로직 → 어기면(astonishment) → 담당.

### A. 정합·일관성 (어디서나 같다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 평점 준 영화는 본 영화 | `watched := seen OR rating NOT NULL` (단일 predicate) | 추천에 평점 준 영화가 뜸 → 즉시 불신 |
| "보유 142편"은 모든 화면에서 142 | *본 영화 집합 = 단일 소스*(같은 predicate·같은 RPC) | 현황 142, 프로필 139 → "버그?" |
| 평균 별점은 *평점 매긴 것만*의 평균 | 분모 = rated only, 미평점 제외 | 안 매긴 영화가 0점으로 끌어내림 |
| 한 영화는 한 리스트에 한 번 | de-dup (film_id 기준) | 같은 영화 두 번 → 조잡함 |
| 평점 주면 워치리스트에서 빠진다 | rated ⟹ watched ⟹ NOT 후보 | 본 영화가 "볼 영화"에 남음 |

### B. 추천 위생 (추천은 깨끗하다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 추천 = 내가 *안 본* 것 | 후보 = `NOT watched(film)` (불변식) | 본 영화 추천 = 신뢰 즉사 |
| 이미 담은 건 다시 권하지 않음(또는 표시) | watchlist dedup | "이미 담았는데" |
| 추천엔 *왜*가 있다 | 모든 후보 ≥1 이유; 0이면 노출 안 함 | 근거 없는 추천 = 랜덤처럼 보임 |
| 상위 5개가 같은 감독뿐이 아님 | 다양성(MMR / 감독·국가 상한) | "브레송만 5개" 피로 |
| 1등은 *한눈에 납득* | 최상위 = 기여도 최강 이유 + 높은 친연도 | 1등이 이상하면 전체 불신 |

### C. 단조성·방향 (입력→출력이 예상대로)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 영화를 더 보면 커버리지·NAV가 *오른다* | 관람은 항상 비감소(engagement 처벌 금지) | 봤는데 레벨 하락 = 충격 |
| 높게 준 영화의 *비슷한 게* 추천에 뜬다 | 평점 가중이 친연도에 직결(①) | "9점 줬는데 왜 무관한 게?" |
| 별점을 바꾸면 추천이 *그 방향으로* 변함 | 평점 변경 → 취향 dirty → 재계산 전파 | 바꿔도 그대로 = 죽은 화면 |
| 실망(저평점)은 *내가 누른 것*만 자산을 깎음 | drawdown은 명시적 저평점에만, 관람 자체는 +  | 그냥 봤는데 자산 하락 |

### D. 콜드스타트·빈 상태 (처음에도 안 깨진다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 0편 유저도 깨진 화면을 안 봄 | 빈 상태 카피 + 정전 우선 추천 + "형성 중" | "정전가 NaN" / 텅 빈 대시보드 = 이탈 |
| 데이터 적으면 *겸손하게* | 신뢰도 라벨·정전 폴백·과적합 경고 | 3편으로 단정적 시그니처 = 헛소리 |
| 계보 없는 영화가 *0점이 아님* | 미평가 표시 or 대중평점 폴백 사전치 | 좋은 무명작이 "정전가 0" |

### E. 표기·포맷 (숫자가 깔끔하다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 점수는 정수, 별점 1자리 | 반올림 규약(정수 / .1 / % 합 100) | `86.9999` / 합이 101% |
| 별점은 ★5, 내부는 0–10 | 스케일 정규화(표시↔내부 분리) | 3.5인데 가중식은 1–10 기준 |
| 명칭이 일관 | 정전가·WWI·NAV 정본(SUITE-AUDIT) | 같은 걸 다르게 부름 |

### F. 시간·신선도 (시간이 말이 된다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| "최근 관람"이 실제로 최근 | `watched_at` 정렬, NULL 처리 | 옛날 게 위 |
| 동행은 *하루 단위*로 바뀜 | 자정 경계 = Asia/Seoul 고정(STATE 패턴) | 새벽에 두 명 / 안 바뀜 |
| "만료 D-5"가 진짜 임박 | provider `fetched_at` 신선도, stale 시 caveat | 만료됐는데 추천 |

### G. 가용성·지역 (지금 볼 수 있다 = 진짜)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| "MUBI에서 지금" = 내 지역에서 진짜 | `film_watch_providers.countries` ∩ 사용자 지역 | 미국만 가능한데 한국 유저에 표시 |
| "지금 볼 수 있는 N편" | 구독 ∩ 지역가용 교집합 | 구독했는데 못 봄 |

### H. 액션 일관성 (누르면 즉시·되돌릴 수 있다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 봤어요/별점 → 모든 화면 즉시 반영 | optimistic UI + 재검증, 단일 predicate | 한 화면만 바뀜 |
| 취소하면 원상복구 | 멱등·역연산(unrate→후보 복귀) | 되돌려도 남음 |

### I. 가치 판정 산술 (뱃지가 숫자와 안 싸운다)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 내 별점 > 정전가 → "저평가 발굴" | 뱃지 = `별점×배율 − 정전가` 그대로 | 별점 9·정전가 60인데 "고평가" = 모순 |

### J. 설명가능성(숨겨도 일치) | 보이는 이유 = 실제 1위 기여 | 이유 정렬 = 기여도 정렬(05 §) | "안전자산"이라며 실제론 정전 때문 |

### K. 신뢰도·재현성 (객관 점수는 정직하게 — 엔진 ⑨ Cinecodex)
| 기대 | 보장 로직 | 어기면 |
|---|---|---|
| 객관 점수엔 *근거*가 보인다 | 13차원 각 근거 1줄(≤12단어) | 블랙박스 점수 = 불신 |
| 비결정 LLM 점수의 *신뢰도*가 보인다 | sd·flagged·재현성 카드 노출 | 과신·은폐 = 배신 |
| 우리 점수 ≠ 외부지표 ≠ 정전가 (안 섞임) | 나란히 분리 칸(SHARED-STANDARD S11) | 합쳐진 한 숫자 = 순환·불투명 |

> **숨김 vs 투명 경계:** *계산(HOW: 가중·SQL·λ)*은 숨긴다 — *근거(WHY: 이 값인 이유)·신뢰도(HOW-RELIABLE)*는 보인다. Cinecodex(⑨)는 후자를 *공개*해 예측가능성을 강화한다(비결정성 정직 공개). 비섞임은 **단방향**: 산출은 순수, 상위 엔진은 출력만 소비.

> 이 표가 *작은 로직*의 전부다. 화려하지 않지만, **이게 깨지면 어떤 추천 알고리즘도 신뢰받지 못한다.**

## 3. 재정렬된 설계 순서 (Phase 0 → 4)

기대의 강도·파괴력 순. 각 Phase = *사용자 한 줄 기대* + 담을 로직(엔진 + small) + **예측가능성 수용 기준**(QA).

### Phase 0 — 정합 척추 (불변식; 화려하지 않지만 *맨 처음*)
사용자 기대: "당연한 게 당연하게 된다."
- 본 영화 predicate(rating⟹seen) · 단일 소스 카운트 · 스케일 정규화(0–10) · 반올림/포맷 규약 · **결정적 안정 정렬 + tie-break** · de-dup · 콜드스타트/빈 상태 규약 · 지역·신선도 가드.
- 수용: 같은 유저를 두 화면에서 봤을 때 카운트 동일 · 새 유저가 깨진 숫자 0개 · 리스트 재로드 시 순서 불변(데이터 동일 시).

### Phase 1 — "내 것이 정확하다" (내 데이터가 진실로 읽힘)
사용자 기대: "내가 본 것·그 값이 맞다."
- 본 영화 집계(②⑦의 watched set) · **정전가 재캘리브레이션**(명작이 ~90, 중앙값 ~50 — astonishment 1순위) · 가치 뱃지 산술 정합(I) · 커버리지(많이 본 게 위, 단조 C).
- 수용: 기생충·도쿄이야기 정전가 ≈ 90 · 내 별점 9 영화가 "저평가 발굴"로 옳게 뜸 · 가장 많이 본 계보가 매트릭스 상단.

### Phase 2 — "추천이 나를 안다" (추천이 직관적으로 맞음)
사용자 기대: "이거… 어떻게 알았지? 그리고 다 안 본 거네."
- 취향 벡터(①) → **안전자산**(of-course-fit) · 추천 위생(B 전부: 안 본 것·dedup·이유·다양성) · 유사/이웃(⑥ — 온보딩 fly-in이 관련 있음) · 평점→추천 반응(C).
- 수용: 브레송 애호가에게 1등이 브레송/금욕 계열 · 본 영화·담은 영화 추천에 0건 · 모든 카드에 납득되는 이유 한 줄 · 9점 준 직후 그 이웃이 떠오름.

### Phase 3 — "내가 성장한다" (진척이 정직)
사용자 기대: "보면 늘고, 다음 한 편의 값이 보인다."
- NAV/레벨(⑧ 단조·콜드스타트) · Δindex(다음 한 편의 가치) · 공백/블라인드(④ — 안 본 곳이 안 본 곳으로).
- 수용: 영화 추가가 NAV를 안 떨어뜨림 · "이 한 편 +N" 이 실제로 커버리지/공백을 메우는 영화에서 큼 · 라틴 0편이면 라틴이 블라인드.

### Phase 4 — 결을 더하는 것 (delight; 비필수)
사용자 기대: "오, 이런 것도." (없어도 신뢰엔 무관)
- 도장깨기 완성 알림 · 저평가 발굴 정렬 · 순위(podium) · **동행**(F 시간 cadence) · 공개 프로필 투영.

## 4. BUILD-ORDER와의 정합

둘은 어긋나지 않는다. `BUILD-ORDER`(데이터/구현)는 *"무엇을 지을 수 있나"*(②⑦ 이미 있음, ① 키스톤), 이 문서는 *"무엇이 먼저 맞아야 하나."* 합치면:

```
Phase 0 정합 척추  ← BUILD §1c 불변식 + small 로직(이 문서가 1급으로 승격)
Phase 1 = W0(정전가 재캘리브레이션) + W2(커버리지) + 가치뱃지
Phase 2 = W1(취향 벡터) + W3(WWI·⑥ 블렌드) + 추천 위생
Phase 3 = W4 일부(NAV·공백·Δindex)
Phase 4 = W4 나머지(완파·동행·프로필)
```

차이 하나: **BUILD-ORDER는 small 정합 로직을 횡단 footnote로 뒀지만, 직관 기준에선 그게 Phase 0 = 최우선이다.** 예측가능성의 바닥이기 때문.

## 5. 한 줄
**사용자는 로직을 보지 않지만 *예측은 한다.* 그 예측을 한 번도 배신하지 않는 것 — 그것이 직관이다. 그래서 화려한 추천보다, 본 것을 본 것으로·안 본 것을 안 본 것으로·같은 수를 같은 수로 만드는 *작은 정합 로직을 맨 앞에* 둔다.**
