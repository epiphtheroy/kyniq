## 2. 엔진 의존 그래프 (무엇이 무엇을 먹나)

```
[L0 토대 — 원시 데이터에서]
  ① 취향 벡터  ←  user_films · takes/figures 임베딩          (주관)
  ② 정전가     ←  film_lineage (계보)                         (객관)

[L1]
  ⑦ 커버리지   ←  user_films · film_lineage · ②(가중)
  ⑥ 유사추천   ←  ① · ② · film_lineage · auteur_edges

[L2]
  ③ 리니지 관련성 ←  ① · ② · ⑦
  ④ 공백/희소     ←  ① · ② · ⑦ · 세계정전크기

[L3 — 상위 종합]
  ⑧ NAV/레벨   ←  ⑦ · ② · user_films(평점·깊이)
  ⑤ WWI        ←  ① · ② · ③ · ④ · ⑥ · ⑦ · 가용성   ← 가장 많은 의존(추천 정점)
                  └ Δindex ↔ ⑧
```

**핵심 축:** ①(주관) × ②(객관)이 모든 것의 두 기둥. ⑤(WWI)가 거의 전부를 빨아들이는 추천 정점. ⑧(NAV)이 헤더 단일 숫자. 동행(페어) 싱크율 = 두 사용자의 ① 코사인.

## 4. 공통 어휘 (전 엔진이 따른다)

정본: `docs/SUITE-AUDIT-personalization.md` §3.

- **점수·레벨:** 영화적 자산 **NAV**(유일 총량, 엔진⑧) · **정전가**(영화 시장가, 엔진②) · **WWI**(후보 적합도, 엔진⑤) · **레벨 밴드**(NAV 백분위).

## 5. 횡단 관심사 (8개 전부에 공통)

- **설명가능성** — 모든 점수는 `components`로 분해 보존. "왜 이 값?"에 한 줄로 답 못하면 출시 금지.
- **콜드스타트** — 표본 적은 사용자(<8~10편)는 거의 모든 엔진이 노이즈 → 정전·인기 폴백 + "형성 중" 라벨 + 신뢰도 감쇠.
- **캘리브레이션** — δ·C·γ·가중치·임계는 *코퍼스로 튜닝*하는 가설. 형태만 고정.
- **갱신/캐싱** — `user_taste_profile`·`film_scores` 머티리얼라이즈. 본 영화 변경 트리거 또는 TTL. `model_version` 불일치 시 재계산.
- **반-게이밍**(엔진⑧) — 무차별 시청·평점 인플레 방어.
- **편향 보정** — 서구·정전 편중 → Discovery·selectivity가 균형추(엔진②④).

## 6. 미정 결정 (각 §8에 상세 — 캘리브레이션·실험 대상)

엔진별 §8에 체크리스트가 있다. 가장 영향 큰 것들:
- ①: 혼합(k-means) 채택 여부, 두 벡터 분리, 내가 쓴 take 가중.
- ②: γ(Discovery 합산), δ·C 캘리브레이션, 시대 보정.
- ③: "맞는 리니지" 주축(4정의 블렌드 비중), 표시 수.
- ④: 절대결핍 vs under-index 결합비, 생산적 공백 판정.
- ⑤: 6이유 가중 default, 슬라이더, MMR 다양성.
- ⑥: 계보형↔임베딩형 결합 ρ, auteur_edges 바닥값.
- ⑦: 분모 정규화, 가중 커버리지 size_damp.
- ⑧: NAV 4축 가중, 레벨 백분위 임계.
