# 코어 엔진 ⑨ — 내재가치 (Intrinsic Value · Cinecodex)

*개인화 로직 명세 9/9. 작성 2026-06-30. 정전가(②)와 나란히 서는 **두 번째 객관 점수**. 출처: `score/Cinecodex_HANDOFF.md` 외 + 통합 검토 `docs/cinecodex/`. 비섞임 단방향이 철칙.*

---

## 1. 우리가 하려는 것 (처음 듣는 사람을 위해)

**한 문장:** 한 영화가 *그 자체로* 무엇을 돌려주고(획득가치 V), 얼마나 진입이 어렵고(진입비용 C), 얼마나 실망·위험한지(위험 R)를, LLM이 13개 미학 차원을 루브릭으로 채점해 *재현 가능하게* 산정하는 엔진.

**왜 ②정전가로 부족한가.** 정전가는 *세상이 인정했나*(정전 등재·수상 = **시장가**)를 잰다. 하지만 그것은 ⓐ *저야망*(배트맨 리턴즈)과 *분열적 실패*(바빌론)를 구분 못 하고, ⓑ 시간 편향(신작·비서구 저평가), ⓒ "왜 위험한지" 설명 불가. **Cinecodex는 영화의 *펀더멘털 등급*** — 인정 여부와 무관하게 작품 자체의 가치·비용·위험을 *분해*한다. 사용자의 질문 "배트맨 낮게·밀양 높게·**망작 거르기**"의 정답은 여기, R/U에 있다.

**비섞임 원칙(철칙).** Cinecodex 산출은 외부지표(IMDb/RT/Metascore)·정전가를 *공식에 절대 안 넣는다*. 그것들은 *나란히* 표시·검증에만. (순환성 회피.) → §4.

## 2. 목표 산출물 (사용자 경험 중심)

영화 한 편당:

| 산출 | 정의 | 사용자가 보는 곳 |
|---|---|---|
| **V 획득가치** | mean(COG 인지·AFF 정서·FORM 형식·MORAL 도덕·DUR 지속). 높을수록 좋음 | 평가 카드·watchlist·collection |
| **C 진입비용** | mean(ITX 영화사·FR 형식급진·ETX 외부지식·CTX 감독오에브르). *난이도, 가치 아님* | 평가 카드(준비 필요도) |
| **R 위험도** | 0.6·mean(BANK 지적파산·INSINCERE 미적불성실·COWARD 예술적비겁)+0.4·POLAR 분열성. 높을수록 위험 | **위험 배지**·추천 경고 |
| **U 영화 순가치** | V − λ·R (λ=위험회피 다이얼). *후보 정렬 기준* | 평가 카드·추천 게이트 |
| **S 샤프** | (V−50)/max(R,1). 위험 대비 효율 | asset-desk(위험조정) |
| **미적 단계** | 10단계 미적 경험 분류(L1 Passive→L10 Transcendental) + 비교작 5 | 평가 카드 상단 |
| 13 서브점수 | 각 차원의 레벨 + 근거 1줄(≤12 영어 단어) + 비교작 3 | 평가 카드 상세(접이) |

> **어휘 정본(개명):** 「**미적 단계**」(Aesthetic Tier) — *사용자* "레벨 밴드"(NAV 백분위)와 구분, 영화엔 "레벨" 미사용. 「**영화 순가치**」(U) ≠ 「내 NAV」. **C 진입비용** = 난이도 단일 소스. **S 샤프** = 후보 효율(매수 전) ≠ P&L(보유 후). **POLAR 분열성** 정본.

## 3. 활용 데이터

- **채점:** LLM(Sonnet 주력 / Opus 감사 / Haiku 금지)이 *8개 앵커*가 박힌 프로덕션 프롬프트로 13차원 채점. 520-앵커 뱅크는 *오프라인* 캘리브레이션·드리프트·공개 방어용(프롬프트엔 8개만).
- **나란히(입력 아님):** `film_ratings`(imdb/meta/rt) + 정전가(②) = *표시·검증* 전용.
- **저장(실 구현):** 격리된 **`cinecodex` 스키마** — `cinecodex.scores`(13 median + `v_value`/`c_cost`/`r_risk` + 신뢰도 `n_samples`/`sd_v`/`sd_r`/`panel_disagree`/`flagged`) · `cinecodex.scoring_runs`(불변 원시) · `prompt_versions` · `review_queue` · `drift_runs` · `anchor_controls` · `human_audit` · `batch_jobs`. 전부 `film_id uuid references public.films(id)`. U/S 미저장(λ 가변 → 앱/뷰에서). RPC: `cinecodex_freeze_prompt`·`cinecodex_targets`·`cinecodex_write_runs`·`cinecodex_aggregate`. 데이터 상세: `docs/cinecodex/02-data-pipeline.md`.

## 4. 본질적 문제 · 설계 (심장)

### (a) 비섞임 = 단방향 (the core invariant)
```
13차원 ─(순수 LLM 채점)→ V/C/R/U/S        ← 외부지표·정전가 입력 절대 금지
V/C/R/U/S ─(출력 소비)→ ⑤WWI · ⑧NAV · 가치뱃지   ← 상위 엔진에서만 블렌드
역류(WWI/NAV/정전가/외부지표 → Cinecodex 입력) = 금지
```
"Cinecodex는 *만들고*, 상위 엔진은 *쓴다*." WWI가 Cinecodex 출력을 한 항으로 소비하는 것은 비섞임 위반 *아님*. NAV/정전가를 Cinecodex *공식*에 넣는 것이 위반.

### (b) 3 철칙
① **난이도는 비용이지 가치 아님** — 어려운 영화가 자동으로 좋은 게 아니다(C는 V와 분리). ② **분열적 ≠ 파산적** — 옹호 진영이 강하면 POLAR↑이지 BANK/INSINCERE/COWARD 아님(분열적 야심을 '실망'으로 오판 금지 — 가치뱃지에 상속). ③ **야망 ≠ 성취** — 과시적 스펙터클은 FORM 상한 ~55.

### (c) 숨김 vs 투명 (INTUITION-ORDER와의 경계)
my_room은 *계산(가중·SQL)*을 숨긴다. Cinecodex는 *근거(1줄)·신뢰도·재현성*을 **공개**한다. 충돌 아님 — **HOW(계산)는 숨기고, WHY(이 값인 이유)·HOW-RELIABLE(신뢰도)는 보인다.** 상용 LLM의 비결정성을 *정직히* 공개(재현성 카드)하는 것이 오히려 예측가능성 윤리를 강화.

### (d) 신뢰도
median(샘플별) · sd_v/sd_r(런 노이즈) · panel_disagree(모델 간) · flagged(임계근처/고SD/파싱실패) → 표시에 노출(저신뢰=흐림/플래그). *단 분열적(고POLAR) ≠ 불신뢰* — 둘 다 흐리게 하지 말 것.

## 5. 권장 공식 (못박음)
```
V = (COG+AFF+FORM+MORAL+DUR)/5
C = (ITX+FR+ETX+CTX)/4
R = 0.6·((BANK+INSINCERE+COWARD)/3) + 0.4·POLAR
U = V − λ·R          (λ 기본 1.0, 범위 −100..+100, 음수 정상, 높을수록 좋음)
S = (V−50)/max(R,1)
집계: 영화별 N 샘플의 *서브점수별 median* → 그 13 median에서 V/C/R 계산.
```

## 6. 콜드스타트·캘리브레이션·갱신
- **콜드스타트:** 점수 *미생성* 영화 → 「Cinecodex 미평가」 빈 상태(흐린 카드 + "분석 대기"). NaN 금지. **(2026-07-01 실측: 6,701편 전부 Pass1 N=1 채점 완료 — 미생성 = 신규 유입작만.)**
- **캘리브레이션:** 앵커 컨트롤셋(~60편) 정기 재채점, ±12 벗어나면 드리프트 게이트 정지.
- **갱신:** 모델/프롬프트 SHA 변경 시 재채점. `prompt_versions` 동결.
- **Pass2 대기:** Pass1은 N=1(단일 샘플)이라 런 노이즈(sd) 미측정 → **4,289편 flagged**. 신뢰도 확보용 Pass2 N=3(플래그분)·Pass3 Opus 감사(고위험 5%)는 미실행(권장).

### 6b. 실측 검증 (2026-07-01 · 6,701편 Pass1)
분포: **V** avg 58·med 60·p90 75 · **C** avg 34 · **R** avg 24·med 23·p90 34. 기준 바스켓이 의도대로 정렬 —
| 영화 | V | C | R | U(λ1) | S |
|---|---|---|---|---|---|
| Tokyo Story | 93.2 | 51 | **7.2** | 86.0 | 6.00 |
| 밀양 Secret Sunshine | 84.6 | 38 | 12.8 | 71.8 | 2.70 |
| Parasite | 67.4 | 33 | 18.0 | 49.4 | 0.97 |
| Babylon | 55.0 | 49 | **50.8** | 4.2 | 0.10 |
| Avengers: Endgame | 36.6 | 40 | 33.0 | 3.6 | −0.41 |
→ **밀양·오즈 상위, 배트맨/어벤져스 하위**(사용자 원 질문 해결). **Babylon R=50.8**(최고 위험) = *분열적 실패*를 R이 포착 = "망작 거르기"의 핵심 증명. C가 접근성(Dark Knight 19) vs 난해(Tree of Life 62)를 변별.

## 7. 다른 엔진과의 인터페이스 (이 엔진이 *내보내는* 것)

| 소비 엔진 | 쓰는 산출 (출력만 — 역류 금지) |
|---|---|
| ⑤ WWI / 추천 | **V = 품질 prior**(콜드스타트 정전가 시간편향 보완) · **R = 위험 multiplier/게이트**(`risk_mult=clamp(1−ρR, floor, 1)`) · **U = 후보 품질 게이트** · **λ = 사용자 위험회피 다이얼**. ※ prior는 **U 아닌 V**(U는 R 차감분이라 R 필터와 이중계산) |
| ⑧ NAV | (선택) V/U를 자산 평가 보조 입력 |
| 가치뱃지 | 2축: (별점 vs ②정전가) + (별점 vs **V**) = 내 평가가 *시장·분석*과 합치/이탈 |
| ④ 공백 | C/R 차원으로 "준비 필요·고위험" 공백 표지 |
| 표시(전 페이지) | ②정전가·외부지표와 *나란히*(안 섞음) + 신뢰도 |

**계약:** Cinecodex는 `{V,C,R,U,S, 미적단계, 13 서브점수, 신뢰도}`를 제공한다. 소비 엔진은 이 출력만 신뢰하고, *어떤 것도 Cinecodex 입력으로 되돌리지 않는다.*

## 8. 못박아야 할 미정 (대부분 결정됨)
1. ⑨ 정식 엔진 승격 — **결정: 예**(정전가와 대등 객관축).
2. WWI 품질 prior = U vs V — **결정: V**(이중계산 회피).
3. λ 다이얼 사용자 노출 — **결정: 예**(선호 다이얼, 내부 로직 노출 아님).
4. 가치뱃지 1축 vs 2축 — **결정: 2축**(V축은 2차 상세).
5. 채점 실행 — **완료**: 2026-07-01 6,701편 Pass1 N=1(`cinecodex.scores`, sonnet-n1, `cinecodex-prod-v2`). 남은 것: Pass2 N=3(flagged 4,289) · UI 활성(STEP B).
6. 메인의 이전 *평단-블렌드* — **결정: 폐기**(정전가=시장가 순수 유지, 내재·망작은 ⑨ 전담).
