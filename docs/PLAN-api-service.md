# PLAN — Metatake API 서비스 사업 기획 (타당성 검토 + 실행안)

*2026-07-03 작성. 근거: 라이브 DB(`jvgarcqrtsmgfimdcwgo`) 실측 + 코드베이스 전수 감사 + 4개 병렬 리서치(경쟁 환경 / 수요 측 / 코드 감사 / 수익화·비용·법률, 총 ~400 웹 조회, 핵심 주장 적대적 검증 완료). 자매 문서: `Metatake_자체LLM_타당성_전략검토.md`(2026-06-17, 수익 표면 ③ "데이터/API 라이선스"의 구체화가 본 문서) · **`docs/PLAN-ai-context-packs.md`(파일 제공형 대안 — 본 API 기획보다 선행 실행 권고, 복사 버튼 수요 데이터로 API 승격 여부 판정)**.*

## 0. 최종 판단 (TL;DR)

1. **"API 서비스가 될 수 있는가" — 예, 그러나 규모에 대한 기대를 정확히 조정할 것.** 메타테이크의 5개 자산군(해석 코퍼스, canon 집계, 촬영지 지오, 다차원 스코어, 임베딩 그래프)은 **전부 상업적 공백지대**로 검증됐다(직접 경쟁자 0). 특히 **촬영지 API는 시장에 단 하나도 존재하지 않는다** — TMDb는 8년째 요청을 방치했고, IMDb는 연 $150k짜리 라이선스 상품에서조차 촬영지를 뺐다.
2. **그러나 경쟁자 부재 ≠ 수요 존재.** 문서화된 실수요는 촬영지·canon·트로프 3개 축뿐이고, 셀프서브 API의 현실적 1년차 기대치는 **P50 $200–800 MRR** (P90 $2–5k MRR)이다. 이것은 단독 사업이 아니라 **부수입 + 전략 자산**이다.
3. **가장 큰 단일 기회는 API 구독이 아니라 관광 쪽 맞춤 딜.** set-jetting이 제도화 중이고(Expedia: 여행자 53%↑, VisitBritain 캠페인 £217M 효과), **한국관광공사가 2026-06-17 스튜디오드래곤과 '한류 올레길' MOU를 체결** — 홈그라운드에 지금 활동 중인 바이어가 있다. 직접 비교 대상 SetJetters(~1만 핀, 동일 규모)도 API가 아닌 관광청 파트너십(네바다, 오리건)으로 수익화한다. 딜 1건 = **연 $5–30k**.
4. **AI 학습데이터 판매 기대는 접을 것.** 순수 AI 생성물은 미국(Thaler 대법원 상고기각 2026-03, 확정)·EU 모두 저작권 없음 → 라이선스할 권리가 약하고, 랩이 ~$3–15k면 유사 코퍼스를 재생성할 수 있다. 27k 해석 코퍼스의 가치는 '팔 자산'이 아니라 **사이트와 API를 차별화하는 제품 층 + RAG 검색 층**이다.
5. **비용은 사소하다.** 증분 인프라 ~$25–50/월, 구축 2–4일(Claude Code), 운영 주 1–3시간. 손익분기점이 낮아 **하방 위험이 거의 없는 실험**이다. 진짜 병목은 배포·발견(현재 사이트 트래픽 주 ~140뷰)이며, API/MCP는 역으로 그 병목을 푸는 마케팅 채널이 될 수 있다.

**한 줄:** 돈을 벌려고 만드는 API가 아니라, **AI 시대의 배포 채널 + 관광 딜의 영업 자료 + 소액 MRR**을 한 번에 얻는 저비용 실험으로 만들어라. 단, 법적 위생(아래 §4)을 먼저 통과할 것.

## 2. 상품 설계 (4개 API 제품 + 2개 비-API 채널)

### 제품 1 — **Metatake Locations API** (스피어헤드)
- 엔드포인트: 기존 `/api/geo`의 RPC(`film_geo`, `geo_bbox_json`, `geo_overview_json`)를 키 게이트 뒤로 복제. 영화별 핀 / bbox 질의 / 국가·도시 집계.
- 필드: lat/lng(nominatim만), precision, country, layer(filmed/setting), scene_role 산문(자체 저작), confidence, film 식별자(slug + imdb_id/wikidata_id).
- 타깃: 여행앱·지도앱 개발자, 영화 사이트 빌더, 관광청 데모.
- 근거: TMDb 커뮤니티 8년 미해결 요청 스레드, wherewasfilmed.com 등 수작업 사이트들 전부 API 없음.

### 제품 2 — **TakeScore & Canon API**
- `cinecodex_for/card/ranked` + `film_lineage_for` + `film_scores` 래핑. "이 영화의 13차원 점수 + canon 등재 이력 + 정전가"를 한 응답으로.
- 타깃: 추천엔진 만드는 개발자, Letterboxd류 앱(당 API가 거부하는 수요), 큐레이션 툴.

### 제품 3 — **Critical Graph API** (해석·트로프·유사도)
- `readings_semantic`(시맨틱 검색), `trope_related`, `film_affinities`, `map_ego` 그래프. 응답에 출처 framework/theorist 메타 포함 — 이것이 범용 LLM 대비 차별점(프로비넌스).
- 타깃: RAG 제품, 영화 에세이/뉴스레터 저자 툴, 교육.

### 제품 4 — **벌크 데이터셋** (원오프 판매)
- 분기별 버전드 덤프(Parquet/SQLite): locations / scores / lineage / takes. Gumroad 또는 Polar로 판매, Hugging Face gated dataset은 발견 채널로 (HF에는 결제 레일 없음 — 게이트만 걸고 오프플랫폼 결제).

### 채널 5 — **MCP 서버** (수익이 아니라 배포)
- 위 3개 API를 감싼 원격 MCP 서버 + Anthropic 커넥터 디렉터리 등록. 니치 데이터 MCP의 유의미한 매출 사례는 아직 0 — 기대치는 '발견·인용·백링크'. Speakeasy 무료 티어로 OpenAPI→SDK+MCP 자동 생성.

### 채널 6 — **관광/기관 맞춤 딜** (최대 단일 기회)
- KTO·지자체 DMO·영상위원회에 촬영지 레이어 + 지도 기술(이미 MapLibre Atlas 보유)을 파트너십으로 피칭. '한류 올레길' 타이밍. 주의: 현재 코퍼스는 아트하우스 정전 중심이라 K-드라마 커버리지가 약함 — 피칭 전 한국 로케이션 데이터 증분 생성(기존 geo 파이프라인 재사용, 비용 소액)이 선행 과제.

## 4. 실행 전 법적·기술 위생 (게이트)

1. **유료 피드에서 제외**: watch_providers, film_ratings, TMDB 파생 필드(포스터 경로 포함), verbatim 인용. *스키마 레벨에서 응답 화이트리스트로 강제.*
2. **지오 필터**: `geo_cache.source='nominatim'`만 + ODbL 출처표기. Google 유래 좌표는 Nominatim 재지오코딩으로 세탁 가능(작업 1일).
3. **anon-key 우회로 봉쇄**: 현재 SECURITY DEFINER RPC + 공개 anon key 구조상 전 콘텐츠가 DB 엣지에서 무료 — 유료 API와 무료 사이트의 경계를 정할 것. 권고: 사이트는 지금처럼 무료 유지, 유료 API의 가치는 "정식 스키마 + 벌크 + 상업 이용권 + 안정성"으로 정의(전면 봉쇄는 SEO·UX 훼손).
4. **기술 부채 3건**: `next.config.ts`의 `/tmp-sql` 와일드카드 CORS 제거 · middleware를 `/api/*`에서 분리(불필요한 auth 왕복) · `/api/films/backfill` 무인증 상태 수정.
5. **Vercel Spend Management 알림 활성화** ($23k DDoS 청구 사례 방지) + API 서브도메인에 Cloudflare 무료 Cache Rule(키는 Authorization 아닌 커스텀 헤더로 — 캐시 가능성 유지).
6. **ToS**: 클릭랩 구독 약관(재배포·재판매·LLM 학습 조건 명시) — AI 생성물의 실질 보호 수단은 저작권이 아니라 **키 게이팅 + 계약**.

## 5. 수익 vs 비용 (실측·검증 수치)

**수익 (연차 1–2, 검증된 비교군 기반 추정):**

| 시나리오 | API 구독 | 관광/기관 딜 | 합계 (연) |
|---|---|---|---|
| P50 | $200–800 MRR | 0건 | **$2.4k–10k** |
| P75 | $1–2k MRR | 1건 ($5–15k) | **$17k–39k** |

비교 앵커: OMDb(솔로 운영 10년, 무료 기본값 지위)가 Patreon ~3,600명 = 추정 $5–30k/월. 70%의 마이크로 SaaS는 $1k MRR을 못 넘김.

**비금전 수익 (실질적으로 더 큼):**
- 개발자 임베드 → 출처표기 백링크 → SEO (현 최대 약점인 트래픽 보완)
- MCP/AI 검색 시대의 인용 가능성 — "영화 해석·촬영지의 구조화 소스"로 자리매김
- 관광·엔리치먼트 벤더(Vionlabs형) 딜의 영업 자료 = 살아있는 API 데모
- Gracenote v. OpenAI(2026-03) 이후 열릴 수 있는 "합법 해석 데이터 공급자" 포지션의 옵션 가치

## 6. 로드맵

- **Phase 0 — 위생 (1주):** §4 게이트 전부. 응답 화이트리스트, 지오 필터, CORS/middleware/backfill 수정, 스펜드 알림.
- **Phase 1 — Locations API 단독 출시 (2주):** api.metatake.net + 키/크레딧/Stripe(or Polar) + 문서 포털 + OpenAPI. 제품 1개로 시작해 수요 신호 검증. 출시 포스트: HN/r-webdev/TMDb 포럼의 바로 그 미해결 스레드.
- **Phase 2 — 확장 (4–6주):** TakeScore·Canon API, Critical Graph API, 벌크 덤프, Speakeasy SDK + MCP 서버 + Anthropic 디렉터리 제출, Apify 리스팅.
- **Phase 3 — 관광 딜 (병행, 영업):** 한국 로케이션 커버리지 증분 → KTO/서울관광재단/부산영상위 피칭 덱(라이브 Atlas 데모 중심). '한류 올레길' 일정 안에.
- **중단 조건:** Phase 1 후 90일간 유료 전환 0 + MCP/무료 티어 사용량도 무의미 → 유지비가 사소하므로 '무료+출처표기' 모드로 강등하고 SEO 채널로만 유지 (매몰 없음).

## 7. 리스크 정직 목록

1. **수요 미검증** — 해석·스코어 데이터를 이름 붙여 찾는 사람은 아직 0 (촬영지·canon만 문서화된 수요). Phase 1을 촬영지로 시작하는 이유.
2. **저작권 부재** — AI 생성물은 법적 소유 불가(확정 판례). 방어선은 게이팅+계약뿐이고, 로그아웃 스크레이퍼에는 약함. 정확도·신선도·구조가 실질 해자.
3. **배포 열위** — 사이트 트래픽 주 ~140뷰. API가 성공하려면 런치 마케팅이 데이터 품질보다 중요.
