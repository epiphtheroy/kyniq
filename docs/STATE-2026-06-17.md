## 3. Entity model
`film → figure → take → meta-take`, plus `trope` as a second hub axis.
- **film** `/film/[slug]` — TMDB metadata, poster/backdrop/stills/trailer, JSON-LD.
- **figure** `/film/[slug]/figure/[figureSlug]` — a recurring element (character/object/location/form/"trope"-kind). Has `description`, `slug`, `embedding`, `kind`.
- **take** — one close reading of a figure (rationale + `register` (10) + `raw_concept` + `theorist_id` + `confidence`); lives on the figure page; embedded.
- **meta-take (reading)** `/take/[slug]` — `kind='reading'`; the cross-film hub a take converges into; has title/laconic/thesis/essay, `tradition`, rankings. The site's protagonist.
- **trope (figure-type)** `/trope/[slug]`, index `/tropes` — `kind='figure_type'`; a screenwriter-level type grouping figures across films via `figure_type_members`.
- Readings index `/meta-takes`.

## 7. Ask (grounded Q&A)
- `/ask` (`app/ask/page.tsx`, client, Suspense, auto-runs `?q`) → `POST /api/ask`.
- `app/api/ask/route.ts` (node runtime): embed query (`text-embedding-3-small`) → `ask_retrieve` RPC (pgvector ivfflat + FTS, RRF) → diversity rerank (≤14, ≤2/film) → grounded synthesis with **`gpt-4o-mini`** (`ASK_MODEL` overridable) → `{answer, citations, readings, meta}`. In-memory cache + light rate-limit. Returns "not in corpus" honestly.
- **Requires `OPENAI_API_KEY` in Vercel env** (embeddings were generated locally, so prod may lack it — if `/ask` says "not configured", add it).
- Eval: `worker/ask-eval.py` (12 questions, cost/citation report).
