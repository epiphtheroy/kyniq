# UX 검토 · 분석 워크벤치 (`mockup-me-analysis-v2.html`)

작성 2026-06-26 · 4 렌즈(경험·눈·클릭·직관) 기준 · page-local 직접 수정.

## 0. 한 줄 진단
이 페이지는 "내 취향이 어떤 모양이고, 어디가 비어 있나"를 약속한다. 그러나 수정 전에는 **차트만 나열**돼 있어 "그래서 뭘 알게 됐나"를 사용자가 직접 합성해야 했고(가장 큰 마찰), 차트·노드·앵커의 상당수가 `cursor:pointer`만 있고 **클릭 핸들러가 없는 죽은 어포던스**였다(두 번째 마찰).

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- 경험 흐름: 히어로(취향 벡터) → KPI → 4개 차트로 곧장 진입. **말로 된 인사이트 요약이 없음.** 가장 중요한 발견(최대 블라인드, 취향 이동, 가장 맞는 계보)이 티커·KPI·활동 패널에 흩어져 있고, 맨 위에 한 문장으로 명시되지 않았다.
- 눈동자: 블라인드(red)는 축 모듈 안에 묻혀 있고, "블라인드 축 3" KPI가 양성 KPI들과 같은 시각 무게였다. 적색이 즉시 눈에 들어오지 않았다.
- 클릭: 리니지/앵커 행은 인스펙터 드릴이 되지만 **연대 막대·국가 막대·감독 행·그래프 노드는 클릭해도 아무 일이 없었다.** ginfo는 "노드를 클릭하세요"라 적었으나 노드에 핸들러가 없었다. KPI도 비클릭.
- 직관성: "앵커(무력한 목격자)"가 무엇인지, "rel/cov" 약어가 무엇인지 클릭/스크롤 없이는 알 수 없었다.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇] → [왜] → [클릭/눈 효과]
- **인사이트 리드 배너 신설(`.lead`, 히어로와 KPI 사이)** → 분석 화면의 핵심은 "그래서 뭘 알게 됐나" → 가장 중요한 3가지(①최대 블라인드: 라틴·아프리카 0%, 60s 이전 9% / ②취향 이동: 이란 뉴웨이브 +6° / ③한 문장 정체성 + 가장 맞는 계보 프랑스 영성영화 0.94·cov 50%)를 **PT Serif 문장**으로 맨 위에 명시. 각 줄은 호버 시 CTA가 뜨고 클릭하면 해당 모듈/인스펙터로 직행 → 사용자가 해석을 떠안지 않는다.
- **블라인드 KPI 강조(`.alertkpi` 적색 테두리·배경) + 모든 KPI 클릭 점프(`.jump`)** → 의미색(red=정복/공백)을 KPI 위계로 끌어올림 → 적색이 즉시 눈에, KPI 클릭으로 해당 섹션·인스펙터로 1클릭 이동.
- **죽은 어포던스 활성화: 연대 막대·국가 막대·감독 행 클릭 → 인스펙터 드릴(`axisDetail`)** → `cursor:pointer`만 있고 핸들러 없던 차트들에 연대/국가/감독별 커버리지 분해 + "다음 행동"(블라인드면 추천 받기) 카드 부착 → 차트가 실제 드릴 입구가 됨. 감독 행에 hover 배경도 추가.
- **그래프 노드 클릭 활성화(`graphNode`)** → ginfo가 "노드를 클릭하세요"라 안내했으나 핸들러 부재 → 노드 클릭 시 ginfo 상단이 해당 노드(보유/미관람 추천)·연결 차수·담기 동선으로 갱신. 히트영역(+10px 투명 원)으로 클릭 쉽게.
- **용어 글로스 툴팁(`.gloss`, 점선 밑줄+호버 설명)** → "앵커"·"rel"·"cov"가 자명하지 않음 → 리니지 헤더의 cov/REL, 렌즈 모듈의 "앵커"에 한국어 평문 툴팁 부착. 렌즈 모듈 상단에 "앵커 = 당신 영화를 가로지르는 반복된 해석 패턴, 장르가 아닌 보는 방식"이라는 **평문 1줄 인트로**도 추가.
- **카피 명료화** → 리니지 하단 안내를 "관련성 높은데 커버리지 낮은 줄 = 가장 채울 가치 큰 계보 / 아무 줄이나 클릭"으로 직설화. 그래프 기본 ginfo에 "노드를 클릭하면 여기 상세" 힌트 추가.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/어휘]** "블라인드(blind) 축"은 이 페이지 핵심 개념인데 6+가용 이유 정본 색에 별도 토큰이 없어 `--red`(conquer)를 재사용 중. 블라인드 vs 정복(conquer)이 둘 다 적색이라 의미 충돌 가능 — 정본 색 체계에서 "블라인드/공백" 의미색 분리 또는 명시적 매핑 정의 필요. 영향: 커맨드센터·워치리스트(추천 사유 색 공유).
- **[⚠ COORD: 셸/별점]** 인스펙터 드릴의 "볼 영화에 담기"·"추천 받기" CTA가 전부 `watchlist.html`로 **페이지 이동**한다. 인라인 담기(그 자리에서)가 분석·계보·앵커·축 어디서나 필요 → 공유 담기 컴포넌트로 묶으면 클릭 대폭 절감. 영향: 전 페이지.
- **[⚠ COORD: 어휘]** "rel / cov / WWI / NAV / 정복도 / 블라인드 / 앵커 가중치(weight)" 약어가 페이지마다 등장. 이번엔 page-local 글로스 툴팁으로 보강했으나, **공유 용어집(hover glossary) 컴포넌트**로 통일하면 일관성↑. 영향: 전 페이지.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- 리드 배너의 3가지 인사이트는 현재 하드코딩. 실제로는 `taste_drift()`·`axis_coverage()`·`lineage_rel()` 결과를 받아 **"가장 큰 갭/가장 빠른 이동/최상위 관련" 규칙으로 자동 선정**하는 RPC가 이상적(예: 블라인드 임계값, drift 각도 임계, rel−cov 갭 최대치).
- 그래프 노드 클릭 시 현재는 ginfo 텍스트만 갱신. 추후 클릭한 노드 기준 **간선 하이라이트(ego-network 강조)** + 인접 추천 N개를 인스펙터로 동기화하면 탐색이 더 직관적. (간선 인덱싱·이웃 질의 필요.)
- 연대/국가 "다음 행동 → 추천 받기"가 정적 링크. 실제로는 **해당 축 필터가 사전 적용된 워치리스트**로 진입해야 동선이 끊기지 않음(쿼리 파라미터/상태 전달 필요).

## 표준 적용 (SHARED-STANDARD)

적용 2026-06-26 · 매트릭스 행 **analysis = S1 · S2 blind색 · S5 용어집** · 백업 `mockup-archive/mockup-me-analysis-v2-std.html` · 검증 div 283/283, `node --check` OK · 셸·콘텐츠·기존 UX(`.lead` 인사이트 배너·`.gloss` 툴팁) 보존.

- **S1 추천 명칭 — 부재로 적합(no-op).** 이 페이지에는 "오늘의 한 편 / Δindex 최상위 1편" **추천 표면이 존재하지 않는다**(분석은 계보 관련성·축 커버리지·앵커를 다룸, 단일 추천편 NAV +N 라벨 없음). S1은 *추천 표면이 나타날 때만* 적용되므로 변경 대상 없음. 향후 이 페이지에 Δindex 최상위 1편 추천이 추가되면 라벨 = 「오늘의 한 편」 + `최대 Δ · → NAV +N`.
- **S2 블라인드 색 = amber 분리.** `:root`에 `--blind:#E8B23A`(+텍스트용 `--blindtx:#edc873`) 토큰 추가, 보조로 `--forming`·`--masque`도 정본화. 블라인드 의미색을 **conquer red에서 앰버로 전면 이전**:
  - 연대 막대(`.decol.blind .stk .mine`), 국가 막대(`.cob.blind .ctk>i`)·국가명(`.nm`), 저커버리지 줄(`.cov-lo` 바·pct), `relColor()`/`relDetail` 저cov 색, 리드 배너 블라인드 줄(신규 `.lic.blind` 앰버 아이콘 + `.gapw`), 활동 패널 "블라인드 경보" 마일스톤 3개, 활동 피드 블라인드 아이콘, 사조 마스터리 저cov 줄(`.mvrow .nm.bl` + 바), 인스펙터 `axisDetail` 연대/국가 드릴(숫자·바·문구) — 전부 `var(--red)`/`#e98a86`/`#f2a39f` → `var(--blind)`/`var(--blindtx)`.
  - **레드 alert ≠ 안 감 재조율.** 블라인드 KPI는 `.alertkpi`(conquer 레드 테두리)에서 **`.blindkpi`(좌측 앰버 alert 액센트 + 앰버 의미색)** 로 교체 → 빨강=정복했다, 앰버=아직 안 갔다 의미 분리 확정. 축 모듈 헤더 카피 "적색 = 블라인드" → "앰버 = 블라인드".
  - **범위 밖(의도적 유지):** 상호추천 그래프(⑥)의 레드 간선·미관람 추천 노드는 **블라인드가 아닌 추천/affinity 표면**이라 S2 대상 아님 → 그대로. 로고·티커·primary 버튼·conquer 칩(`.rsn.conquer`·`.bv-over`)의 레드도 브랜드/정복 의미로 정당.
- **S5 용어집 — 정본 사전 대조 후 누락 첫 등장 보강.** 기존 글로스(cov·REL·앵커) 유지. 추가: **NAV**(앱바 navchip, 상단 clip 방지용 `.gloss.down` 변형 신설) · **정전가**(히어로 `.explain`) · **정복도**(감독 축 헤더) · **aw**(TSPDT 관련성 분해 칩) · **블라인드**(리드 배너 첫 등장). 정본 사전 중 **WWI·Δindex는 이 페이지에 사용자 노출 토큰으로 등장하지 않음**(`.wwi`는 우측열 CSS 클래스명일 뿐, 가시 라벨은 REL/WEIGHT) → 글로스 대상 없음. `rel`은 이 페이지가 `.gloss` 패턴의 레퍼런스로 유지.
