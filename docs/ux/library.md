# UX 검토 · 서재 (`mockup-me-library.html`)

## 0. 한 줄 진단
이 페이지는 "내가 모아둔 *이질적인 것들*(영화·감독·트로프·미스리딩·리니지·형상)을 한 곳에서 분류·공개한다"를 약속한다.
가장 큰 마찰 두 가지: (1) **공개/비공개 토글이 카드에 없어** 인스펙터/모달을 거쳐야 했다 — 주 행동이 2~3클릭. (2) **트로프·미스리딩·형상 같은 추상 항목이 카드만 봐선 무엇인지 자명하지 않았다**(정의가 인스펙터에만 있었음).

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 진입 시 hero+KPI로 "무엇을 얼마나 모았나"는 보이나, *지금 뭘 하면 되는지*(찾기·분류·공개)가 약했다. 빈 컬렉션·빈 검색 결과가 한 줄("항목이 없습니다")로만 끝나 다음 행동이 없었다.
- **눈동자**: 유형 색(좌측 보더+점)은 스캔되나 **공개/비공개가 7px 점 + tooltip뿐**이라 한눈에 안 잡혔다. hero 유형 막대는 6종 중 5개만 보였고(트로프/형상이 한 막대로 합쳐짐) 형상 색이 노출되지 않았다.
- **클릭**: 즐겨찾기는 1클릭이나 **공개 토글·컬렉션 이동은 인스펙터/모달 경유**. 유형 필터는 1클릭이나, 필터를 켠 뒤 *한 번에 초기화*하는 길이 없었다. hero 통계에서 유형으로 바로 진입하는 길도 없었다.
- **직관성**: 추상 항목(트로프/미스리딩/형상) 정의가 카드에 없어 라벨만으로 의미 추정이 어려웠다. 카드가 클릭 가능해 보이는 신호(affordance)가 약했다.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇을] → [왜] → [클릭/눈 효과]
- **공개/비공개 인라인 토글 칩을 카드 우상단에 신설** (`.pubpill`, `data-ipub`) → 작은 점+tooltip은 상태가 안 읽히고 토글하려면 인스펙터를 거쳐야 했다 → 상태가 라벨(🌐 공개 / 🔒 비공개)로 즉시 읽히고, **카드에서 1클릭 토글**(인스펙터/모달 불필요). 인스펙터가 열려 있으면 동기 갱신. *기존 `is_public` 모델·이벤트는 그대로 사용 — 셸/백엔드 변경 없음.*
- **유형 아이콘을 카드 ttag·툴바 칩에 추가** (`TYPES[t].i`) → 색만으론 6종 구분이 빠듯했다 → 영화🎬·감독★·트로프·미스리딩·리니지·형상이 아이콘으로 즉시 변별, 툴바 칩과 카드가 같은 시각 언어.
- **추상 항목 정의 티저를 카드에 노출** (`.deftease`, 트로프·형상의 `def` 2줄 클램프) → "무력한 목격자"가 무엇인지 카드만 봐선 몰랐다 → 정의 일부가 카드에서 바로 읽혀 추상 항목이 자명해짐.
- **카드 affordance 강화**: hover 시 `상세 열기 →` 힌트 + 살짝 떠오르는 transform → 카드가 클릭 가능한 객체임을 신호.
- **hero 유형 막대를 6종으로 분리 + 클릭 진입** (트로프/형상 분리, `data-herotype`) → 형상 색이 안 보였고 통계가 죽은 숫자였다 → 6유형 모두 스캔되고, 막대 클릭 시 해당 유형만 필터(통계→탐색 1클릭 연결).
- **빈 상태를 문맥별로 재작성** (`emptyState()`): 빈 컬렉션 → "「이름」이 비어 있습니다 + 담는 법 + 전체 서재로", 필터 결과 0 → "필터 모두 지우기", 콜드 → "⌘K로 찾아 담기". 컬렉션 행도 0개면 "아직 비어 있음" 안내 + 열린 폴더 아이콘.
- **툴바 정리**: 「유형」 라벨 추가, 필터가 켜져 있을 때만 나타나는 **「지우기」 칩**으로 한 번에 초기화(유형·공개·검색·컬렉션 뷰 전부).

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/백엔드 · `is_public` 인라인 토글]** — 카드에서 공개/비공개를 1클릭 토글하는 패턴은 컬렉션 리스트·평가·프로필 등 *항목 카드가 등장하는 모든 페이지*에 동일하게 필요. 현재는 page-local로 `it.pub`만 뒤집지만, 실제론 `set_visibility(entity, is_public)` 공유 RPC/이벤트와 옵티미스틱 UI가 필요 → 공유 카드 컴포넌트로 승격 권장. 영향: collection-list, onboard-rate, profile.
- **[⚠ COORD: 어휘 · 별점]** — 영화 카드에 평점이 "★ 기록됨 / 미기록"으로만 표기됨. 인라인 0.5–5 별점 입력은 서재·평가·보유영화 공통이라 **공유 별점 컴포넌트** 필요(가이드 §2). 여기선 손대지 않고 기록만.
- **[⚠ COORD: 어휘 · 형상 색 토큰]** — hero에서 형상(figure)을 별도 막대로 노출하며 `--figure` 토큰을 처음 단독 사용. 6+ 유형 색 정본에 `figure` 색(#86b9ec)이 다른 페이지와 충돌 없는지 확인 필요.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- **일괄 분류(bulk)**: 카드 다중 선택 → 한 번에 컬렉션 담기/공개 전환. UI는 page-local로 가능하나 선택 모델·일괄 RPC가 전제 → 지금은 미적용.
- **유형 칩 + 공개 필터의 결과 카운트 배지**: 각 칩에 해당 유형 개수 표기는 집계 호출/사전계산이 깔끔 → 백엔드 조율 시 함께.
- **컬렉션 행에서 공개/비공개 인라인 토글**: 항목과 동일 패턴을 컬렉션에도(현재 컬렉션 공개 전환은 표시만). `is_public` 토글 통일과 함께.

## 표준 적용 (SHARED-STANDARD)
적용 매트릭스 행: **library — S2 figure확인 · S7/S9 공개토글**. 셸·콘텐츠·기존 UX 개선(카드 공개 토글·유형 아이콘·정의 티저)은 보존하고, 비표준 부분만 정본에 맞춰 수정.

- **S9 공개/비공개 토글 (정본 pill)** — 기존 카드 인라인 `.pubpill`을 `collection-list-v2`의 정본 pill과 라벨·동작 정확히 일치시킴:
  - 라벨: `공개` → **`🌐 공개 중`** (ti-world) / **`🔒 비공개`** (ti-lock) — collection과 동일 문자열.
  - 접근성: `role="switch"` · `aria-checked="true|false"` · `tabindex="0"` 추가 (이전엔 없었음).
  - 키보드: 포커스 후 **Enter / Space**로 제자리 토글(`togglePub()` 위임 keydown 핸들러). 클릭도 동일 함수 경유로 단일화(`stopPropagation` → 카드 선택과 분리).
  - 시각: `.pubpill:focus-visible` 포커스 링 추가. 토글은 제자리(in-place) — 인스펙터/모달 불필요, 인스펙터 열려 있으면 동기 갱신.
- **S2 형상(figure) 색 확인** — `--figure:#86b9ec`가 정본 형상 색임을 재확인. 타입 6색(영화 `--film` ink · 감독 violet · 트로프 teal · 미스리딩 amber · 리니지 `#3E8FE0` blue · 형상 `#86b9ec`)이 서로 구별되어 **충돌 없음** (SHARED-STANDARD S2 "figure 색 충돌 없음 — 확정"과 일치).
- **S2 정본 토큰 추가** — suite 일관성을 위해 `:root`에 `--blind:#E8B23A` · `--forming:#C8922B` · `--masque:#9B8CF0` 토큰 정의(이 페이지에서 시각적 사용은 없으나 전 페이지 토큰 통일).

검증: `<div>` open==close (266/266) · 스크립트 `node --check` 통과 · `role="switch"` pill 2상태 · 토큰 4종 존재 확인.
