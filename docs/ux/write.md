# UX 검토 · 노트 · 글쓰기 (`mockup-me-write.html`)

## 0. 한 줄 진단
"내가 쓴 글 = 가장 강한 취향 신호(×1.5)"를 약속하는 비평 컴포저. 가장 큰 마찰 2개:
(1) 진입 시 빈 "쓰기 시작" 상태가 아니라 기존 초안이 열리고, 새 글 버튼이 `+` 아이콘뿐이라 *어디서 쓰기 시작하나*가 즉시 안 보임.
(2) **"저장" 버튼이 공개/비공개와 무관하게 항상 같아서**, "게시"가 무엇이고 *어디에 공개되는지* 결과가 예측되지 않음.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 진입 즉시 작성 가능 여부가 약함 — `+` 아이콘 단독 버튼, 제목 placeholder가 작성 유도를 안 함. 게시(공개) 흐름이 토글 하나에 숨어 있고 별도 결과 신호 없음. 자동저장 표시 부재 → 내 글이 보존되는지 불안.
- **눈동자**: boost 배너가 모든 노트 상단을 항상 점유 → 제목과 첫 시선 경쟁. 공개/비공개·게시 상태가 시각적으로 약함(작은 토글, 빨간 "저장" 버튼이 공개 시에도 동일).
- **클릭**: 첨부(영화/figure/trope/misreading)는 인스펙터에서 인라인(좋음). 공개 토글·저장은 1클릭(좋음). 그러나 게시 버튼이 "어디로 가는지" 미예측. 포맷바·유형 칩은 라벨만으로 의미 불명확.
- **직관성**: "강한 오독", "트로프 기여" 같은 개념이 작성자에게 자명하지 않음 — 유형 선택 *후*에야 힌트가 뜨고, free 유형은 안내 자체가 없음. 본문 placeholder가 모든 유형에 동일.

## 2. 적용한 개선 (HTML 직접 수정)
- **[새 글 버튼 라벨화]** `+` 아이콘 → "+ 새 글" 라벨 버튼(빨강 유지). → *왜*: 주 진입 행동을 자명하게. → *효과*: 진입 3초 내 "여기서 쓰기 시작" 인지, 클릭 망설임 제거. 제목 placeholder도 "…여기서부터 바로 쓰기 시작"으로 작성 유도.
- **[저장→맥락형 게시 버튼]** 비공개일 땐 "초안 저장"(중립), 공개일 땐 초록 "게시 · 「영화/figure/트로프」로 / 내 프로필에 공개"로 **라우팅 목적지를 버튼에 직접 표기**. → *왜*: least-astonishment — 누르면 어디에 공개되나 예측. → *효과*: 게시 결과 예측, 공개 상태가 버튼 색·문구로 한눈에.
- **[자동저장 표시 추가]** 에디터 바에 "자동저장됨" 인디케이터. 입력 시 "저장 중…"→"자동저장됨"으로 깜빡. → *왜*: 작업 보존 불안 제거. → *효과*: 눈으로 보존 확인, 수동 저장 강박 완화.
- **[유형 가이드 상시화 + 본문 placeholder 유형별화]** 힌트 배너가 강한 오독/코멘트/트로프의 *정의*까지 한 줄로 설명, 본문 placeholder도 유형마다 다른 예시 문구로 교체(예: 강한 오독 = "이 figure를 '틀리게' 읽어봅니다 …"). → *왜*: 추상 개념을 작성 순간에 자명하게. → *효과*: 개념을 모르는 작성자도 무엇을 쓸지 즉시 파악, 잘못된 유형 선택 감소.
- **[boost 배너 접기]** ×1.5 boost 배너에 닫기(×) 추가, 닫음 상태 localStorage 기억. → *왜*: 동기 메시지를 한 번 보여주되 매번 제목과 경쟁시키지 않음. → *효과*: 에디터 집중도↑, 잡음↓(접으면 제목이 첫 시선).
- **[유형/토글 affordance]** 유형 세그먼트·공개 토글·포맷바에 설명형 `title` 툴팁 보강(공개 토글 = "공개 시 프로필·영화 페이지에 노출"). → *효과*: 호버 시 결과 예측, 라벨 모호성 완화.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/반응형]** `@media(max-width:1280px)`에서 **인스펙터(첨부·연결 레일)가 강제 접힘** → 좁은 폭에서 영화·figure·트로프 "엮기"가 *불가능*해짐. 이 페이지에선 인스펙터가 핵심 작성 도구이므로, 좁은 폭에서 인스펙터를 접지 말거나(이 페이지 한정 예외) 본문 하단에 인라인 첨부 폴백이 필요. 미디어쿼리는 공유 셸 패턴이라 직접 수정 보류. 영향: write 외 inspector를 핵심으로 쓰는 페이지 공통.
- **[⚠ COORD: 어휘/표기]** "공개 토글 = 게시"라는 의미 묶음을 본 패스에서 버튼 카피로만 명료화함. 전 페이지 공통으로 *공개=게시* 동사를 통일할지(예: 토글 라벨 자체를 "초안/게시"로) 어휘 조율 권장. 영향: 셸 어휘.
- **[⚠ COORD: 백엔드]** boost ×1.5 / 임베딩 직접 가산(taste_vector 파이프라인)·publish() 라우팅·자동저장(현재 프런트 표시만, 실제 영속화 없음)은 백엔드 전제. 표시·카피만 손댐, 로직 미변경.

## 4. 추후 로직·데이터 변경 제안 (지금 미적용)
- 자동저장을 실제 영속화(draft autosave RPC)와 연결 — 현재는 UI 표시만.
- 게시 버튼의 라우팅 목적지가 *엔티티 미연결 시* "내 프로필에 공개"로 폴백 → 유형별 필수 엔티티(코멘트=영화, 강한 오독=figure, 트로프=trope) 미충족 시 게시를 막거나 인라인 경고하는 검증 로직 권장.
- 진입 시 기본 노트 대신 "새 빈 글 + 최근 초안" 선택 화면을 줄지(cold-start) 데이터/세션 정책 결정 필요.

## 표준 적용 (SHARED-STANDARD)

`docs/ux/SHARED-STANDARD.md` 정본 기준을 이 페이지(write)에 적용. 적용 매트릭스 행: **S9 (공개 토글 pill) · S10 (인스펙터 반응형 예외)**. 셸·콘텐츠·이전 UX 패스(맥락형 게시 버튼, 자동저장 인디케이터, 유형별 가이드/placeholder)는 보존하고 비표준 항목만 conform.

- **[S9 공개/비공개 토글 → 정본 pill]** 기존 `.vistoggle` + `.sw` 슬라이드 스위치를 collection의 정본 `.pubpill`로 통일. `🔒 비공개`(off=중립 회색) / `🌐 공개 중`(on=green 지구본), `role="switch"` + `aria-checked` 동기화, `tabindex="0"`로 키보드(Enter·Space) 토글 지원, 제자리 클릭(렌더링 분기 없이 인플레이스 갱신). CSS 토큰(height 24·border-radius 13·`.on` `#0e221c`/`#1d4d40`/`#5fd0b2`)을 collection `.pubpill`과 1:1 일치. 맥락형 "게시 · 「…」로" 저장 버튼 카피는 UX 패스 그대로 유지(토글 컨트롤 자체만 표준화).
- **[S10 인스펙터 반응형 예외]** 이 페이지의 인스펙터는 곧 **첨부·연결 레일**(영화·figure·트로프·강한 오독 엮기) = 핵심 작성 도구. 공유 셸의 `@media(max-width:1280px)` 강제 접힘이 좁은 폭에서 첨부를 불가능하게 하므로, `body.keep-inspector` 클래스로 ≤1280px에서 인스펙터를 재노출(`.inspector:not(.collapsed)` — 사용자가 직접 접은 상태는 존중). 인라인 첨부 폴백 대신 레일 유지 방식 채택. 이전 UX 패스의 [⚠ COORD: 셸/반응형] 보류 항목을 본 표준 패스에서 해소.
- **[S2 토큰 suite 일관성]** `:root`에 `--blind:#E8B23A` · `--forming:#C8922B` · `--masque:#9B8CF0` 추가(전 다크 페이지 토큰 통일용). 본 페이지에서 직접 소비하는 색은 아니나 suite 일관성을 위해 정의.

**검증**: `<div>` open==close (141==141) · `<script>` → `node --check` 통과 · 잔여 `.vistoggle`/`.sw` 참조 0. 백업: `mockup-archive/mockup-me-write-std.html`.
