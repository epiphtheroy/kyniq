## 1. 왜 "운영시스템 셸"인가 (★★★ 최중요 — 전체를 지배하는 의도)

**자산 메타포를 *시각화*한 것.** 영화를 지적·미학적 *자산*으로 다루는 개인 OS이므로, 화면은 소비앱이 아니라 **Bloomberg 터미널/트레이딩 데스크**의 밀도·헤드리스를 가진다. 이건 취향이 아니라 *의미*다 — 사용자가 "정말 나를 위한 운영 시스템이 있구나" 느끼게 하는 것이 목표.

**4단 접이식(왜 4단인가).** 운영자는 네 가지를 *동시에* 본다: ①어디로 갈지(**좌 레일**) ②무엇을 보는지(**중앙 워크스페이스**) ③선택한 것의 상세·왜(**우 인스펙터**) ④지금 일어나는 일(**극우 라이브 피드**). 각 접이식(localStorage 공유) — Claude 인터페이스처럼 집중 시 사이드를 접는다. **이 4단 구조는 전 페이지 불변**(공개 프로필 제외). 페이지가 달라지는 건 *중앙·인스펙터·피드의 콘텐츠*뿐.

**인스펙터-스왑(★★★ 설명가능성의 UI 구현).** 무엇을 클릭하든(추천/영화/계보) 우측 인스펙터가 *그것의 상세와 "왜 이 값인지"*로 바뀐다. 이것이 "로직은 숨기되(계산) 근거는 보인다(WHY)"의 화면 구현. 인스펙터가 비면 그 페이지의 *분석 요약*을 기본 표시.

**색은 의미다(★★★).** 색은 장식이 아니라 코드다: 6이유(safe teal·frontier blue·canon gold·gap amber·conquer red·reading violet)·블라인드 amber(≠완파 red)·형성중 골드·**위험 `--risk`(≠완파 red)**. 같은 빨강이 "정복"과 "위험"을 동시에 뜻하면 오독 → 반드시 토큰 분리.

## 4. Cinecodex 표시 통합 — 이번 업데이트의 핵심 (★★★)

**정체.** 정전가(②, 시장가) 옆 *두 번째 객관 점수* = 펀더멘털 등급. **V 획득가치·C 진입비용·R 위험·U 영화순가치(=V−λR)·S 샤프 + 미적 단계(L1–L10).** 6,701편 실측 완료.

**철칙 — 나란히·안 섞음(★★★).** 우리 점수(V/R/U) · 외부지표(imdb/rt/meta) · 정전가를 **분리된 칸**으로. *절대 한 숫자로 합치지 않는다.* 위험 = **`--risk` 신토큰**(완파 red와 구분). 신뢰도 낮으면 흐림 — 단 **분열적(고 R)≠불신뢰**(La La Land R39는 분열이지 오류 아님). 미평가 영화 = 「Cinecodex 미평가」 흐린 카드. 13서브·prompt_sha는 공개 프로필 노출 금지.

**어디에 무엇 (강약):**
- **watchlist ★★★** — 이 페이지의 *새 존재 이유*가 "**실망 거르기**". 각 후보에 **위험 배지(R, `--risk`)** + **U 컬럼** + **위험 필터**("고위험 숨기기") + **λ 다이얼**(보수↔모험). 고위험작 자동 강등 표시.
- **collection ★★★** — 정전가 옆에 **V·U 나란히**(별도 칸) + **가치뱃지 2축**: (별점 vs 정전가)=시장 합치 + (별점 vs V)=분석 합치. 즉 "내 평가가 시장과·분석과 어떻게 다른가" 두 축.
- **analysis ★★** — **μ–σ 위험평면**(V 세로 × R 가로): 한 영화의 위치 + 내 포트폴리오 분포(저위험 고가치 = 좌상 이상향). Cinecodex 렌즈 추가.
- **command-center ★★** — KPI/헤더에 **U·R 경량 요약** + 라이브 피드 "고위험 경보". 추천 행에 위험 점.
- **asset-desk ★★** — **S(샤프) 위험조정 정렬** + **λ 다이얼** + P&L에 위험(고위험 매수 경고).
- **inspector(전 페이지) ★★★** — 영화 선택 시 **Cinecodex 요약 카드**: 3축 미니(V/C/R) + U/S + 미적 단계 배지 + 나란히(우리/외부/정전) + 신뢰도. 이게 설명가능성의 완성.
- **신규 `mockup-me-film-cinecodex.html` ★★** — 풀 평가 카드(§5 하단).

## 5. 페이지별 해부 (구성 위치·의미·연동·Cinecodex 추가)

### 현황 Command Center ★★★
- **존재 이유:** 하루를 여는 대시보드 — "내 자산이 얼마고, 오늘 뭘 하면 되나".
- **주 행동:** "오늘의 한 편" 담기(히어로 배너, 0스크롤).
- **섹션(위·의미·연동):** ①NAV 히어로(=⑧, 축별 breadth/prestige/depth/disc 분해 = *설명가능*) → ②KPI(보유·계보·커버리지·Discovery·블라인드) → ③커버리지 매트릭스(=⑦, 라인별 % 단조) → ④WWI 추천 데스크(=⑤, 6이유 색·Δindex) → ⑤별자리(=⑥ affinity SVG). 인스펙터=클릭 상세. 피드=완파/블라인드/Δ/동행/시스템.
- **Cinecodex 추가:** 히어로/KPI에 **U·R 요약** · 추천 행에 위험 점 · 피드 "고위험 경보" · 인스펙터에 Cinecodex 카드.
- **강약:** NAV 단조·설명 분해 ★★★ / 별자리 ★.

### 보유 Collection ★★★
- **존재 이유:** 내 영화 *자산 거래소* — 각 보유작이 *가격(정전가)*을 갖고, 내 평가와의 차익이 *가치뱃지*.
- **주 행동:** 발굴(저평가) 보기 · 인라인 별점.
- **섹션:** 툴바(정렬 정전가/별점/발굴·facet 필터·검색) → 자산 데이터테이블(포스터·제목/감독·계보 배지·**정전가 가격**·내 ★·**가치뱃지**). 인스펙터=자산 카드(정전가 분해·뱃지 산술·가용성).
- **Cinecodex 추가 ★★★:** 각 행/인스펙터에 **정전가 | V | U 나란히**(분리 칸) + **가치뱃지 2축**(별점 vs 정전가 / 별점 vs V). 예: La La Land 정전가 85·V 57·R 39 → "시장은 정전, 분석은 위험 경고" 대비가 한 눈에.
- **강약:** 나란히 비섞임·2축 뱃지 ★★★.

### 볼 영화 Watchlist ★★★ (이번 업데이트의 최대 변화)
- **존재 이유(갱신):** 매수 후보 데스크 + **실망 거르기**. 예전엔 "나에게 맞나(WWI)"만, 이제 "**얼마나 위험한가(R)·순가치(U)**"까지.
- **주 행동:** 담기/봤어요/관심없음 인라인 · 위험 필터 · λ 다이얼.
- **섹션:** 툴바(전략 필터·정렬 WWI/Δ/**위험**/만료·**λ 다이얼**·검색) → 후보 랭킹(랭크·제목·6이유 색칩·**WWI**·**Δindex**·**위험 배지 R**·가용성·만료). 인스펙터=WWI 분해 + **Cinecodex 카드**(왜 안전/위험) + 담기.
- **Cinecodex 추가 ★★★:** 위험 배지(R, `--risk`)·U 컬럼·"고위험 숨기기" 토글·λ 다이얼. 고위험(Babylon R51·La La Land R39) 자동 강등 + 경고.
- **강약:** 위험 거르기·λ 다이얼 ★★★ / 만료 D-N ★★.

### 운용 Asset Desk ★★
- **존재 이유:** 트레이딩 데스크 — 5전략 추천 + P&L + 위험조정.
- **섹션:** 5전략 보드(안전자산/모험/도장깨기/공백/정전, 각 후보+이유칩+WWI+Δ) → P&L(자산곡선 단조·적중률·regret 목록). 
- **Cinecodex 추가:** **S(샤프) 위험조정 정렬** 옵션 · **λ 다이얼** · P&L에 "고위험 매수 경고".
- **강약:** P&L 단조(관람 안 깎음)·저평점만 regret ★★★.

### 분석 Analysis ★★
- **존재 이유:** 분석 워크벤치 — "그래서 뭘 알게 됐나"(인사이트 리드) + 축 커버리지 + 상호추천 그래프.
