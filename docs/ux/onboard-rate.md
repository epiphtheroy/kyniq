# UX 검토 · 기록 · 평가 워크스테이션 (`mockup-me-onboard-rate-v2.html`)

## 0. 한 줄 진단
이 페이지의 약속: "영화에 별 하나만 누르면 평가가 끝나고(=봤어요), 사랑한 작품이 쌓이면 취향 벡터가 형성된다." 가장 큰 마찰 2개 — (1) 진입 시 *주 행동(별 누르기)*이 hero·KPI 아래에 묻혀 "지금 뭘 하면 되는지"가 즉시 자명하지 않다, (2) 이웃 fly-in 패널이 평가 전에도 *항상 펼쳐진 빈 상자*로 떠 있어 "어떻게 알았지" 놀라움이 죽는다(상시 노출 = 서프라이즈 없음).

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 진입 → hero(취향 게이지) → KPI 5칸 → 검색 → 평가 모듈 순. 동기부여(8 loved 게이지)는 좋으나 *첫 평가까지의 시선 경로*가 길다. 평가 모듈이 다른 일반 모듈과 동일한 위계라 "여기가 메인"이 안 보였다.
- **눈동자**: 이웃 fly-in 패널이 idle 상태에서도 일반 패널과 똑같이 펼쳐져 있어, 실제로 이웃이 날아왔을 때의 *상태 변화*가 시각적으로 약했다. 도착 개수·도착 신호(글로우/펄스)가 없었다.
- **클릭**: 인라인 half-star는 이미 1클릭 입력(좋음). 단 카드마다 별 + "평점⟹봤어요" 줄이 반복돼 군더더기. 평가 직후 이웃 패널로 *시선 유도*가 없어 fly-in을 놓치기 쉬웠다.
- **직관성**: 인라인 별 옆에 0.5–5 스케일 단서가 없어 half-star 범위가 한눈에 안 들어왔다. 이웃 카드의 "왜 떴는지"는 `aff 0.94 · 강박…` 형태라 *수치가 먼저*라 이유 라인이 덜 읽혔다.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇을] → [왜] → [클릭/눈 효과]
- **평가 모듈을 primary로 격상** (`.mod.primary` 골드 헤더 + 헤더 라벨 "여기서 평가") → 페이지에 진입한 눈이 "여기가 메인 행동"임을 즉시 인지 → 시선 위계 최상단을 주 행동에 부여(눈).
- **주 행동 큐 배너 추가** (`.ratecue` "본 영화의 별을 누르세요 — 0.5–5★ … 자동 '봤어요' … ★4↑이면 닮은 영화가 날아옵니다") → 첫 평가 방법·결과·연쇄(fly-in)를 *한 줄로 예고* → 첫 평가까지 마찰↓, 예측 가능성↑(경험·직관).
- **카드/이웃 별 옆 인라인 스케일 단서** (`.starwrap` + `.scalehint` "0.5–5★ · 봤어요") + 카드별 중복 "평점⟹봤어요" 줄 제거 → half-star 범위가 별 바로 옆에서 자명 + 같은 문구 반복 군더더기 정리(직관·눈).
- **이웃 fly-in을 idle/armed 2-상태로** — 평가 전엔 접힌 *초대 문구*만(`.nbidle`), 실제 도착 시에만 패널이 *armed*(보라 글로우)되며 헤더에 "N편 도착" 배지 표시 → 빈 상자 상시 노출 제거, *상태 변화 자체가 서프라이즈*가 됨(눈·경험).
- **fly-in 도착 펄스 + 자동 스크롤** (`flashNb()` 1.1s 펄스 + `scrollIntoView`) — ★4↑ 평가가 실제 이웃을 생성할 때만 발동 → "어떻게 알았지" 순간에 시선을 패널로 유도(눈·경험).
- **이웃 "왜 떴나" 라인 재배치** — `왜 떴나 → 강박·관음의 전이 (aff 0.94)`로 *이유를 앞, 수치를 괄호 보조*로 → 공유 라인/해석이 먼저 읽힘(직관).
- **콜드/빈 상태 카피 강화** — 평가 전 relchips "위 카드의 별을 눌러 시작 …", 계보 소진 시 `✓ 다 평가하셨습니다 → 리니지 불러오기에서 계속` → 0편/소진 상태에서 *다음 행동*이 자명(경험).
- **일괄 평가 행에 스케일/기본값 단서** — bulk 별 wrap에 `title="별을 누르면 그 점수로, 안 누르면 ★3 기본"` → 일괄 평가의 기본 동작이 예측 가능(직관). (기본 ★3 = 기존 `val||6` 로직과 일치, 변경 없음.)

검증: `<div>` open==close (198/198) · `node --check` 통과 · 신규 ID/클래스 전부 HTML·CSS에 존재.

## 3. 조율 필요 (cross-page) — [⚠ COORD: 대상] 항목만
- **[⚠ COORD: 셸/별점]** 인라인 half-star(0.5–5) + "별 누르면 자동 봤어요"는 보유영화·서재·추천 등 여러 페이지에서 공유될 가능성이 높음. 이번에 추가한 `.starwrap`/`.scalehint`("0.5–5★ · 봤어요") 스케일 단서를 *공유 별점 컴포넌트*로 끌어올려 전 페이지 표기를 통일할 것을 제안(현재는 이 페이지에만 적용).
- **[⚠ COORD: 어휘]** "평점 ⟹ 봤어요" 문구가 hero·ticker·cue·카드·인스펙터 여러 곳에 반복. 표준 마이크로카피 1종으로 합의 후 공유(이 페이지는 카드 레벨 중복만 제거, 셸/티커는 보존).
- **[⚠ COORD: 어휘/표기]** 이웃 도착 "N편 도착" 배지·armed 글로우 패턴은 다른 페이지의 추천/fly-in에도 쓸 만한 *상태-변화 시그널* — 공유 알림 패턴으로 승격 검토.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- **이웃 fly-in 트리거 임계값(★4=8)**: 현재 코드(`val>=8`)에 하드코딩. 사용자별 민감도/희소 취향을 위해 임계값을 백엔드 파라미터화하면 더 정확. **[백엔드/로직]**
- **일괄 평가 기본 ★3**: 정전 리스트를 "다 봤다고 가정"하는 기본값이 과대 평가를 만들 수 있음 — "확실/추정" 신뢰도에 따라 기본 별점을 차등하거나, 미입력은 "봤음(무점수)"로 남기는 옵션 고려. **[로직/데이터]**
- **취향 시그니처 앵커칩**(무력한 목격자 등)이 인스펙터에 정적 하드코딩 — 실제 v_loved 코사인 상위에서 동적 생성되도록. **[백엔드/집계]**

## 표준 적용 (SHARED-STANDARD)

`docs/ux/SHARED-STANDARD.md` 적용 매트릭스 행 — **onboard-rate = S6 별점 · 형성중색(S2)**. 셸·콘텐츠·기존 UX 개선(반별점 컨트롤·이웃 fly-in armed/idle·리니지 불러오기) 전부 보존, 비표준 항목만 교정.

### S6 별점 (컴포넌트 표준) — 확인·정합
- 인라인 `.starwrap`(반별점 0.5–5, hover 프리뷰, 클릭=확정)는 **이미 표준 준수**. 추가 변경 없이 유지.
- **스케일 단서 표기 통일**: 카드 `.scalehint`를 `0.5–5★ · 봤어요` → **`0.5–5★ · 평점⟹봤어요`**로 정정 — S6의 "0.5–5 스케일 단서 + '평점 ⟹ 봤어요' 마이크로카피"를 별 옆에서 함께 노출. 이웃 카드 `.scalehint`("0.5–5★")·일괄 행 `title`(스케일 단서)·인스펙터 평가 카드("별을 누르면 자동으로 '봤어요'") 모두 표준 라벨링과 일치 — 변경 불필요.

### 형성중색 (S2) — red 금지·골드 토큰화
- `:root`에 **S2 색 토큰 정본 3종 추가**: `--blind:#E8B23A` · `--forming:#C8922B` · `--masque:#9B8CF0` (suite 일관성용 — 이 페이지는 `--forming`만 사용, `--blind`/`--masque`는 미사용이나 표준대로 등록).
- 모든 **"형성 중" / 형성 게이지**를 `--gold`(#E8B23A, 앰버=blind 계열) → **`--forming`(#C8922B, 중립 골드)**로 전환:
  - hero FORMING 링 stroke · `● 형성 중 (FORMING)` 라벨 · "사랑한 작품" 게이지(`barLoved`) · "형성중" KPI 값 · 활동 피드 "취향 형성 게이지" 바(`msLovedBar`)·카운트(`msLoved`) · "취향 벡터 · 형성 중" 시스템 상태 텍스트 · 인스펙터 온보딩 LOVED 카운트(`inspLoved`)·"사랑함" 진행 바.
- red(`--red`/`--conquer`)는 형성 표현에 **일절 미사용**(오독 방지) — 확인 완료.
- **별점 골드는 유지**: `.star.lit`/`.istar.lit` 등 별 글리프와 accent 아이콘(`.mod.primary`·`.ratecue`·`.nadd:hover`)·피드 별 아이콘은 별점/강조 색이므로 `--gold` 유지(형성 게이지 아님).
