# UX 검토 · 운용 데스크 (`mockup-me-asset-desk.html`)

## 0. 한 줄 진단
이 페이지는 사용자에게 *"다음 한 편을 고르면 NAV가 오른다"*를 약속한다. 가장 큰 마찰:
(1) **주/부 위계 부재** — 히어로(NAV)·KPI 스트립·5전략 보드·P&L이 거의 같은 무게로 경쟁해, 진입 시 *주 작업이 5전략 선택인지 P&L 확인인지* 3초 안에 안 잡힌다.
(2) **주 행동까지의 클릭 비용** — "전략 카드 클릭 → 인스펙터 열림 → 담기" 3스텝이라야 볼 영화에 담기며, 카드 자체에 액션 어포던스가 없었다.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름:** 진입 시 무엇이 *주*인지 신호가 없었다. 5전략 보드가 사실상 주 작업("다음 한 편")이지만, 헤더가 수동적 설명문("…다음 한 편의 알파")이라 *행동 지시*로 읽히지 않았다.
- **눈동자:** "관람은 NAV 안 깎음 · 저평점만 regret" 메시지가 티커·히어로·자산곡선·regret카드·인스펙터 등 **6회 이상 거의 동일 문장으로 반복** → 핵심이지만 과반복으로 오히려 둔해짐. KPI 스트립의 첫 칸(NAV 1,284)·둘째 칸(78%)이 히어로와 **완전 중복**이라 상단 스캔을 낭비. 5전략 칼럼이 시각적으로 균일해 *오늘 어느 후보가 최선*인지 눈이 안 잡힘.
- **클릭:** 담기 = 3클릭(카드→인스펙터→버튼). 인스펙터 담기 버튼은 페이지를 *이탈*(`location.href`)해 데스크 흐름을 끊음. 전략 전환은 5칼럼 동시노출이라 OK, regret 드릴은 1클릭이라 OK.
- **직관성:** 빈 빨강 ○(저평점=곡선 안 떨어뜨림)는 옆 navguard 범례가 받쳐 OK. 카드의 "→ NAV +5"는 좋으나, *담을 수 있다*는 어포던스가 없어 카드가 정보 표시로만 보였다.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇을] → [왜] → [클릭/눈 효과]
- **5전략 보드를 "주 모듈"로 격상** (`.mod.prime` 붉은 글로우 테두리 + 헤더 그라데이션 + `prime-hint` 안내줄). 헤더 카피를 "5전략 추천 데스크 · 다음 한 편의 알파" → **"다음 한 편을 고르세요 · 5 전략 추천"** 행동 지시문으로. → *왜*: 진입 시 주 작업을 한눈에 가르기 위해. → *눈/경험*: 시선이 보드로 먼저 떨어지고, "이 데스크가 오늘의 주 작업" 한 줄이 다음 행동을 명시.
- **전 카드에 인라인 `+ 담기` (hover-reveal) 버튼 + 토스트 피드백** (`addPick`). → *왜*: 인스펙터 경유 없이 그 자리에서 담기. → *클릭*: 담기 **3클릭 → 1클릭**. 카드가 "누를 수 있는 것"으로 보임(어포던스).
- **인스펙터 담기 버튼을 이탈 대신 인라인 추가로** (`addPickInsp`, `location.href` 제거 → 토스트 + 버튼 상태 변경 "✓ 담김"). → *왜*: "담기"가 *추가*해야지 *이동*하면 안 됨(least astonishment). → *경험*: 분석→담기→계속 고르기 흐름이 안 끊김.
- **"오늘의 최대 알파" 단일 강조** (Touki Bouki 카드 `.alpha` + `alphatag`, 티커의 "Δindex 최대 기회"와 일치). → *왜*: 균일한 10후보 중 눈이 *한 곳*에 먼저 닿게. → *눈*: 우선순위 진입점 1개 확보.
- **KPI 스트립 첫 칸을 중복(NAV) → 행동 칸으로 교체** (`.kpi-go` 클릭 시 보드로 점프: "다음 한 편 · 최대 알파 +6 → 담기"). → *왜*: 히어로가 이미 NAV 정본 표시 → 상단 중복 제거하고 주 행동 진입점 추가. → *눈/클릭*: 상단 스캔이 주 작업을 가리키고, 클릭 시 보드로 스크롤.
- **과반복 NAV-guard 카피 정리.** 히어로 explain·regret 카드 navguard를 *짧은 핵심 한 줄*로 축약하고, 자산곡선 옆 navguard(빨간 ○가 실제로 보이는 자리)를 **정본 전체 문장**으로 유지. → *왜*: 같은 문장 6회 반복은 신호를 죽임 — "한 번 명료하게". → *눈*: P&L 영역이 덜 시끄럽고 메시지가 또렷.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/별점·담기 컴포넌트]** 인라인 `담기` 버튼·토스트를 이 페이지에 로컬 구현했다. 추천/볼영화/콜렉션 등 여러 페이지에 *동일한 인라인 담기·평가* 패턴이 필요 → 공유 컴포넌트로 승격 권장(현재는 페이지 로컬 `.padd`/`toast`/`addPick`). 영향: watchlist, collection-list, command-center, analysis.
- **[⚠ COORD: 어휘/표기]** "오늘의 최대 알파(top Δindex)" 라벨을 신설했다. 동일 개념이 watchlist·command-center의 "Δindex 최상위 기회"와 중복 — *단일 명칭*(예: "최대 알파" 또는 "Top Δindex")으로 통일 필요. 영향: 모든 추천 노출 페이지.
- **[⚠ COORD: 백엔드/로직]** 인라인 담기는 현재 프론트 토스트만(데모). 실제로는 watchlist 추가 RPC + 담긴 상태 영속(이미 담긴 후보 표시)이 필요. 영향: 전 추천 페이지 공통.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- 5전략 칼럼에 *접기/펼치기* 또는 "오늘 추천만 3개" 모드를 두어 밀도 추가 완화(현재 10후보 상시 노출). 로직/상태 필요.
- "오늘의 최대 알파" 플래그를 하드코딩(Touki Bouki)이 아니라 후보 중 max(Δindex) 자동 산출로. 집계 로직 필요.
- 담긴 후보를 카드에서 영속적으로 "담김"으로 표시(새로고침 후에도). 상태/데이터 필요.

## 표준 적용 (SHARED-STANDARD)

`docs/ux/SHARED-STANDARD.md` 적용 매트릭스의 asset-desk 행 = **S1 · S4 · S5 · S7/S8(담기 의미)**. 셸·콘텐츠·기존 UX 개선(5전략 보드 `.mod.prime`, 인라인 `+담기`, P&L 분리)은 보존하고 비-준수 항목만 교정. 백업: `mockup-archive/mockup-me-asset-desk-std.html`.

- **S1 추천 명칭 — 「오늘의 한 편」으로 통일.** Touki Bouki 알파 카드의 헤드라인 라벨 `오늘의 최대 알파` → **`오늘의 한 편 · 최대 Δ → NAV +6`**(부제 = `최대 Δ · → NAV +N` 정본 포맷). KPI `kpi-go` 칸 라벨도 `다음 한 편 · 최대 알파` → **`오늘의 한 편`**(알파 표현은 본문 `d` 줄로 강등). 활동 레일의 리스트 헤더 `Δindex 최상위 기회`(폐기 표현) → `Δindex 상위 후보 · 오늘의 한 편 외`. 본문·툴팁의 "알파" 설명은 허용 범위로 유지.
- **S4 완파 4-state.** 완파 진행 4개 bar에 `잠금<50 / 진행50–74 / 근접75–99 / 완파100` 라벨 pill(`.cqstate`) + 색 상태 클래스(`.cq-locked` 회색 / `.cq-prog`·`.cq-near` 골드 / `.cq-done` 빨강) 부착. 현 데이터 매핑: S&S 2022 41%→**잠금**, KOFA 52%→**진행**, 브레송 83%→**근접**, Palme 27%→**잠금**. Phase 4 `fire_lineage_milestones`(50/75/100 임계)와 정확히 일치. 임의 하드코딩 색(`background:var(--safe)` / `var(--red)`)은 상태 클래스로 대체.
- **S5 용어집 hover.** analysis/command-center의 `.gloss`(점선 밑줄 + hover 한국어 정의) CSS 패턴 재사용. 정본 6용어 *첫 등장*(애니메이션 티커·스크립트 제외, 안정적 정적 위치)에 부착: **NAV**(appbar navchip) · **P&L**(crumb) · **WWI**·**Δindex**(5전략 modh meta) · **완파**(KPI 칸) · **정전가**(시스템 상태 행). 정의문은 SHARED-STANDARD §S5 정본 사전 사용.
- **S7/S8 담기 의미 — 제자리 동작 확인·보강.** 인라인 카드 `addPick`(toast + `stopPropagation`, 이동 없음) · 인스펙터 `addPickInsp`(toast + 버튼 `✓ 담김`, `location.href` 없음) 모두 **이미 워치리스트 제자리 추가**로 정합 — 변경 불필요. 인스펙터 `봤어요` 데드버튼에 **`markWatched`(보유로 이동 + "평점을 주면 자동으로 「봤어요」" 마이크로카피 toast, 이동 없음)** 핸들러 신설해 S8 "봤어요 = 보유로 이동" 의미 부여. 페이지 내 `location.href`는 전부 정당한 내비(레일·프로필·커맨드팔레트)이며 담기 경로엔 없음.
