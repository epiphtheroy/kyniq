# UX 검토 · 보유 영화 · 자산 거래소 (`mockup-me-collection-list-v2.html`)

작성 2026-06-26 · 4렌즈(경험·눈·클릭·직관) 패스

## 0. 한 줄 진단
이 페이지는 "내 보유 영화 = 자산"을 정전가(가격)·내 별점·가치뱃지로 한눈에 보여주는 거래소다.
가장 큰 마찰 두 가지: (1) **주 행동인 "발굴 보기"가 좌측 레일 깊숙이** 숨어 진입 시 즉시 닿지 않았고, (2) **별점이 표시 전용**이라 재평가하려면 별도 페이지로 이탈해야 했다 — 이 화면이 "거래소"라면 그 자리에서 값을 매기는 행동이 핵심이다.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 진입 시 NAV 링·KPI·표는 보이나, 사용자가 *지금 할 일*(발굴 확인·재평가)이 한 클릭 거리에 없었다. KPI 카드는 `cursor:default`로 죽은 숫자였다. "발굴만 보기" 토글은 툴바에 없고 레일 "이 화면" 섹션에만 존재.
- **눈동자**: 정전가(25px mono)는 위계 최상단 OK. 그러나 **발굴(find) 행이 스캔에서 튀지 않음** — 모든 행이 동일 무게라 "내 컬렉션의 알파"가 눈에 안 들어옴. gap 숫자는 9px 회색으로 묻혔고, 가치뱃지에 색점이 없어 라벨 의존도가 높았다.
- **클릭**: 별점 인라인 수정 불가(가이드 §1·3 명시 요구). 행 hover 시 빠른 액션(노트/공개) 없음. 정렬·facet은 1클릭 OK. 레일/KPI/토글이 *같은 필터 상태*를 공유하지 않아 어디가 켜졌는지 알기 어려움.
- **직관성**: 가치뱃지 색(find=청록/over=적/fit=중립)은 6이유 정본과 정합 — 양호. "정전가"가 *가격*임을 헤더가 명시하지 않아 초심자에겐 모호. 별점이 편집 가능하다는 affordance 부재.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇] → [왜] → [클릭/눈 효과]
- **툴바 "발굴만 보기" 토글 추가** (`#findToggle`, 청록 캡슐 + 카운트 배지) → 주 행동을 진입 즉시 1클릭 거리로 → 클릭 N→1, 시선이 곧장 발굴로.
- **KPI 카드 5장 → 1클릭 필터화** (find/fit/over/전체) + "필터 적용 중" 활성 상태 표식 → 죽은 숫자를 액션으로 → 클릭 1회로 해당 가치군만 격리, 어디가 켜졌는지 눈에 보임.
- **발굴(find) 행 좌측 청록 액센트 + 미세 그라데이션**, 고평가(over) 행 좌측 적색 액센트 → "컬렉션의 알파/리스크"가 스캔 즉시 분별 → F패턴 스캔에서 발굴 행이 먼저 잡힘.
- **별점 행 인라인 수정** (`.xstars .st` 1~5칸 hover 미리보기 + 클릭 확정 → `setRating()`이 가치뱃지·gap·정렬·KPI·인스펙터를 즉시 재계산) → 재평가 위해 페이지 이탈 불필요 → 거래소에서 그 자리 호가. **수식(gap=rating_pct−prestige)·find≥+12/over≤−9 임계·0.5–5 스케일 표시 규칙은 그대로 보존**(데모 입력은 정수칸).
- **행 hover 빠른 액션** (노트 ✒ · 공개 노출 토글 👁, `.xquick`) → 인스펙터 없이도 핵심 액션 → 마우스 한 번에 노트/공개 결정.
- **시각·라벨 직관 보강**: 가치뱃지에 색점(`::before`) 추가, gap 숫자에 부호색(+청록/−적) + 굵기 강화, 헤더를 `정전가 (가격)` / `내 ★ ✎(연필)`로 명시, 인라인 "클릭해 평가" 힌트 → 정전가가 가격임·별점이 편집 가능임이 자명.
- 레일·KPI·툴바 토글이 **단일 `st.navFilter` 상태**를 공유하도록 `setFilter`를 토글식으로 통합 + `syncFilterUI()`로 세 표면 동기화 → "지금 무슨 필터인지" 항상 일관 표시.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/별점]** 행 인라인 별점 위젯은 보유·추천·기록·서재 등 다수 페이지에 동일하게 필요. 지금은 이 페이지에 로컬 구현(정수칸·즉시 재계산)했으나, **공유 별점 컴포넌트(0.5단계 입력 포함, 0.5–5 스케일 정본)**로 승격해 모든 페이지가 같은 affordance·키보드·접근성을 쓰게 해야 함. 영향: 거의 모든 my_room 페이지.
- **[⚠ COORD: 셸/별점]** 인라인 평가가 실제 저장되려면 `rate_film` 류 RPC가 필요. 현재는 프런트 상태만 변경(데모). 백엔드 연결 시 별점 변경 → 가치뱃지/NAV 재계산 파이프라인 일괄 정의 필요.
- **[⚠ COORD: 셸/공개]** 행 "공개 노출 토글(👁)"은 공개 프로필 노출 여부를 바꾸는 글로벌 개념 — 프로필·서재와 공유되는 `is_public` 모델·토글 패턴으로 통일 필요. 지금은 프런트 `pubState`만.
- **[⚠ COORD: 어휘]** "정전가 (가격)" 보조 라벨을 이 페이지에 넣었으나, 다른 페이지의 정전가 표기와 일관되게 *가격 메타포 노출 여부*를 정본에서 결정할 것(전 페이지 동일해야 least-astonishment).

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- 인라인 별점은 0.5단계가 정본 — 현재 데모는 정수 1~5칸. 공유 컴포넌트화 시 반쪽 클릭(좌/우반) 입력 지원.
- "노트 쓰기" 빠른 액션이 현재 `write.html`로 전체 이동 — 추후 해당 영화 컨텍스트를 쿼리로 전달(딥링크)하면 클릭 후 작성 마찰 감소.
- 정렬 "발굴순"과 KPI/토글 "발굴 필터"를 동시 사용하는 흐름이 자연스러우므로, 발굴 토글 ON 시 정렬도 gap 내림차순으로 자동 제안하는 스마트 기본값 검토(지금은 독립).

## 표준 적용 (SHARED-STANDARD)

적용 2026-06-26 · 정본 `docs/ux/SHARED-STANDARD.md` 매트릭스 행 **collection = S3 · S6(별점) · S7/S8/S9(공개 토글)** 대조. 셸·콘텐츠·이전 UX 개선(인라인 별점·가치뱃지·"발굴만 보기" 토글·행 hover 액션)은 보존하고, 비정합 항목만 정렬. 백업 `mockup-archive/mockup-me-collection-list-v2-std.html`.

- **S6 별점 (정합화)** — 행 인라인 별점 컨트롤(`.xstars`)에 항상 보이는 **"0.5–5" 스케일 단서**(`.scalehint`)와 표준 마이크로카피 **"평점을 주면 자동 '봤어요'"**(`.edithint`)를 부착. 기존 "클릭해 평가" 힌트를 정본 문구로 교체. **가치뱃지 수식·임계(gap = rating_pct − 정전가 · find ≥ +12 · over ≤ −9)와 `setRating` 즉시 재계산은 그대로 보존** — 데모 입력칸은 정수, 라벨만 0.5–5 정본으로 정렬(반쪽 클릭 입력은 공유 컴포넌트 승격 시 [⚠ COORD: 셸/별점]).
- **S9 공개/비공개 토글 (정합화)** — 행의 공개 노출 토글을 아이콘 버튼(`ti-eye`)에서 정본 **pill(`🌐 공개 중` / `🔒 비공개`)**로 교체. 제자리 클릭 토글, `role="switch"` + `aria-checked` + `tabindex`/Enter·Space 키 조작 지원. 토글 시 아이콘(`ti-world`/`ti-lock`)·라벨·`aria-checked` 동기 갱신. `stopPropagation`으로 행 선택과 분리 유지(`.xquick` 가드). 노트(✒) 빠른 액션은 `.xqbtn` 아이콘으로 분리 유지(S7).
- **S3 가용성 (정합화)** — 인스펙터 "지금 볼 수 있나"를 3-상태로 정렬: **가능** = solid green dot(`--avail`) + 제공자명·지역 · **미확인** = hollow ring(`.dot-unk`) + "가용성 미확인"("정보 없음 ≠ 안 됨" 툴팁) · **만료 임박** = `만료 D-N` pill(`.exppill`). 데이터를 의미 코드(`unk`/`exp`/색)로 정리하고 `filmDetail` 렌더를 분기화. (예: Citizen Kane → 미확인 hollow ring, Stalker → 만료 D-7 pill.)
- **S8 담기/봤어요 (정합 확인)** — collection은 보유(소유) 페이지이므로 항목은 본질적으로 **봤어요(보유) 상태**. 인스펙터 액션은 "노트 쓰기"/"재평가"로, 표준에 어긋나는 `담기`(워치리스트) 라벨이나 `location.href→collection` 이동이 없음 → 변경 불필요.
