# UX 검토 · 동행 (가면무도회) (`mockup-me-pair.html`)

## 0. 한 줄 진단
이 페이지는 "오늘 누구와 통했나"를 가면 쓴 한 장의 카드로 약속한다. 가장 큰 마찰 두 가지: (1) 가면무도회의 *보임/가림 규칙*이 설명 텍스트를 읽어야만 이해됐고(말 안 해도 느껴지지 않음), (2) 주 행동(가면 벗기)이 다른 두 버튼과 동등한 무게라 위계가 없어 "지금 뭘 하면 되는지"가 한 박자 늦었다.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 진입 시 싱크율 87%는 보이지만 "이 한 사람과 *지금* 무엇을 할 수 있나"가 즉답되지 않음. 회전 카운트다운이 만료/소멸의 뉘앙스("새 한 명으로 교체")라 기다림이 기대감보다 답답함에 가까웠다.
- **눈동자**: 싱크율 숫자는 중심에 잘 있으나, 보임/가림 규칙은 hero explain·인스펙터에만 텍스트로 존재 → 카드 자체에서 안 보임. KPI "형성 중 1명"이 `dn`(빨강/하락)으로 칠해져 *문제 상태*처럼 오독됨(실제론 중립/골드 상태).
- **클릭**: 세 액션이 1클릭이긴 하나 동일 폭·동일 색조라 주 행동이 즉시 안 잡힘. "가면 벗기 → 공개 프로필" 라벨이 길어 줄바꿈 위험.
- **직관성**: "DM 아님 · 공개 아님"이 작은 회색 보조텍스트로 묻혀 DM이 아님이 자명하지 않음. "가면 벗기"가 *공개 프로필로만* 연결된다는 신뢰 보장이 카드에서 안 느껴짐.

## 2. 적용한 개선 (HTML 직접 수정)
- **보임/가림 규칙 칩(`.veil`) 신설** [무엇을] 카드 안에 눈(👁) 3개=공개(싱크율·교집합 앵커·공통 계보) / 눈가림(👁⃠) 3개=비공개(실명·사진·개별 평점·전체 취향)를 시각 칩으로 → [왜] 가면무도회 핵심 규칙을 *말 안 해도* 보게 → [효과] 읽지 않아도 "뭐가 보이고 뭐가 가려지는지" 3초 안에 스캔.
- **주 행동 위계 재구성** [무엇을] `가면 벗기`를 `.pri`(flex:2, 보라 글로우)로, 나머지 둘을 `.sec`(flex:1, 뮤트 색)로 격하 + 라벨을 "가면 벗기"로 단축 + 각 버튼 `title` 힌트 → [왜] primary action 하나가 즉시 보이게 → [효과] 시선·클릭이 주 행동으로 먼저 흐름, 줄바꿈 제거.
- **신뢰 보장 한 줄 추가** [무엇을] 액션 아래 자물쇠 아이콘 + "가면 벗기는 공개 프로필로만 — 공개 투영 이상은 결코 보이지 않습니다" → [왜] 가면 벗기의 두려움/오해 제거 → [효과] 클릭 전 결과가 예측됨(least astonishment).
- **리드 카피 재작성** [무엇을] "오늘 누구와 통했나" → "오늘, **87%** 통하는 한 사람" + "DM 아님 · 공개 아님"을 회색 텍스트에서 *테두리 칩*으로 승격 → [왜] 진입 즉시 싱크율+성격(슬로우 SNS)이 와닿게 → [효과] 첫 시선에서 가치+규칙 동시 전달.
- **회전 카운트다운 카피를 기대감으로** [무엇을] "회전까지 … → 새 한 명으로 교체"를 "이 한 사람과 함께할 시간 … 자정(KST)이면 새 한 명으로 회전"으로 → [왜] *기다림*이 답답함이 아니라 한정성·기대감으로 읽히게 → [효과] 슬로우 SNS의 정서 강화(가면무도회 캐릭터 보존).
- **색 의미 정정 + 오늘 셀 표식** [무엇을] KPI "형성 중 1명" `dn`(빨강)→골드 중립, history 오늘 셀에 `.today`(보라 테두리)+「오늘 ●」 표식 → [왜] 색은 의미만(빨강=하락 아님), 라이브 셀이 어느 것인지 즉시 보이게 → [효과] 오독 제거, 지난 동행 스캔 시 "지금"이 한눈에.

## 3. 조율 필요 (cross-page) — [⚠ COORD]
- **[⚠ COORD: 어휘]** `taste_forming(loved<8)` → 한국어 「형성 중」 표기가 이 페이지(KPI·history·인스펙터·피드)에 4번 등장. 다른 페이지(평가/분석)에서도 같은 임계·라벨을 쓰는지 일괄 정의 권장. 색 토큰은 골드(`--gold`)로 통일 제안.
- **[⚠ COORD: 셸/색토큰]** 가면무도회 보라 계열(`#9B8CF0`/`#bda1f0`/`#4a3f86`)이 토큰화되지 않고 하드코드. "교류·부분 노출" 의미색으로 `:root`에 `--masque`/`--violet`(이미 있음) 계열 정식화하면 다른 교류 페이지와 일관. *이 페이지에선 미변경, 제안만.*
- **[⚠ COORD: 셸/별점·인라인]** 인스펙터 "공통 영화"의 개별 평점이 의도적으로 `masked(·)`. 공유 별점 컴포넌트가 들어오면 *여기서는 항상 가림* 규칙을 컴포넌트 레벨에서 강제해야 함(가면무도회 불변식). 백엔드 노출 정책과 함께 조율.
- **[⚠ COORD: 백엔드]** 싱크율 = `v_loved 코사인`, 회전 = `rotate_midnight`(Asia/Seoul), `pair_today()`/`shared_lineage()` 가정. 부분 노출 필드 화이트리스트(싱크율·앵커·계보 only)는 RPC 레벨에서 강제 필요 — 프런트 가림은 보조일 뿐.

## 4. 추후 로직·데이터 변경 제안 (지금은 미적용)
- "교집합 간직" 시 보관함이 어디에 쌓이는지(서재? 별도 동행 아카이브?) 행선지 정의 필요 — 현재는 status 텍스트만.
- 회전 카운트다운 `frac`(activity 바 74%)이 실제 자정 진행률과 연동돼 있으나, hero/KPI/카드 4곳 중복 노출. 추후 단일 소스로 줄이고 카드+activity 2곳으로 정리 검토(이번엔 의미 보존 위해 유지).
