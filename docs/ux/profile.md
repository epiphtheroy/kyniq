# UX 검토 · 공개 프로필 · 라이트 쇼케이스 (`mockup-me-profile.html`)

작성 2026-06-26. **라이트 "Living Paper" 쇼케이스 스킨 유지 — 다크 운영 셸로 전환하지 않음.**

## 0. 한 줄 진단
이 페이지는 두 사용자에게 동시에 약속한다 — (방문자) "이 사람이 어떤 시네필인지 3초에" / (오너) "무엇이 공개·비공개인지 한눈에 통제". 라이트 쇼케이스의 우아함은 좋았으나 마찰 두 가지: (1) **가장 자랑할 업적(완파·근접 정복)이 뱃지 모듈 안에 묻혀** 위계 최상단에 없었고 — 방문자가 NAV 숫자만 보고 "어떤 정전을 깬 사람인지"는 스크롤해야 알았다. (2) 오너의 섹션별 공개/비공개 토글이 **작은 눈 아이콘 한 개**라 클릭 가능한 컨트롤로 안 보였고, "지금 몇 개가 공개 중인지" 전체 상태가 어디에도 없었다.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: (방문자) 정체성→NAV 카드까지는 좋으나 "대표 업적"이 즉시 안 보임 — 완파/근접 정복이 #2 모듈 안. (오너) 공개 통제는 가능하나 "전체적으로 무엇이 공개됐나"를 모듈을 일일이 보고 세야 함.
- **눈동자(시각 위계)**: 레벨이 핸들·NAV카드·밴드에 3중 반복. 정작 가장 자랑거리인 **완파 뱃지가 위계 상단에 없음**. 뱃지들은 정복(완료)/근접/잠금이 색만 다르고 **상태 라벨이 없어** 어느 게 "깬 것"인지 한눈에 안 들어옴.
- **클릭 최소화**: 섹션 공개 토글은 이미 1클릭이나, **타깃이 17px 아이콘 하나**라 누르기 좁고 affordance 약함. 미리보기 토글은 1클릭으로 좋음.
- **직관성**: "공개 항목 vs 비공개 보호됨"은 카피로 설명되나, 토글 자체가 버튼처럼 안 생겨 *결과 예측*이 약함("이 눈을 누르면 꺼지나?"). 미리보기 라벨 "공개 미리보기"가 "방문자 시점으로 본다"는 뜻임이 100% 자명하진 않음.

## 2. 적용한 개선 (HTML 직접 수정) — [무엇을] → [왜] → [클릭/눈 효과]
- **대표 업적 하이라이트 스트립 추가** (`.conq`, NAV 카드 바로 아래) → 가장 자랑할 완파·근접 정복 3개를 위계 최상단으로 끌어올림. 데이터는 `BADGES`에서 *파생*(정복/근접만 필터, 하드코딩 중복 없음)하고 뱃지 모듈의 공개 상태·미리보기를 그대로 따름 → 방문자가 스크롤 전에 "브레송 근접 정복·S&S 진척·KOFA 정전" 같은 정체성을 3초에 포착. 라이트 골드 톤(`#f7f0df`)으로 쇼케이스 우아함 유지.
- **뱃지 상태 라벨 추가** (`.stag` = 정복/근접/잠금) → 색만으로 구분되던 완료·근접·잠금을 텍스트 배지로 명시 → 눈이 "깬 것(정복)"을 즉시 스캔, 업적 위계가 status로 정렬됨. `BADGES` 배열에 명시적 status 6번째 필드 추가.
- **섹션 공개 토글을 진짜 버튼으로** (아이콘 1개 → `.vbtn` 알약: "공개 중"/"비공개" 라벨 + 눈/눈-슬래시 아이콘, role="switch", title="클릭해서 …전환") → 좁은 아이콘 타깃·약한 affordance 해소 → 클릭 영역↑, 누르기 전에 결과 예측 가능(혼동 0). 공개=그린, 비공개=뉴트럴로 명료.
- **오너 공개/비공개 라이브 카운터 추가** (`.ctrl` 안 `#visCount`: "공개 N · 비공개 M") → "지금 무엇이 공개됐나" 전체 상태가 한눈에 → 오너가 모듈을 세지 않고도 통제 상태 파악, 토글할 때마다 즉시 갱신.
- **미리보기 토글 자명화** (라벨 "공개 미리보기" → "방문자 시점 미리보기", `ti-eye-check`↔`ti-arrow-back-up` 아이콘, 알약 버튼화) → "남이 보는 화면으로 전환"이라는 뜻이 라벨+아이콘으로 자명 → 오너가 안심하고 방문자 시점 확인, on 상태가 액센트 색으로 분명.
- **공개 설정 스트립 카피 정리** (`.ctrl` 첫 줄: 눈/눈-슬래시 아이콘으로 공개·비공개를 "섹션마다 직접 켜고 끈다"고 명시) → 통제 모델이 한 문장+아이콘으로 직관 → 방문자에게 비공개 데이터가 새지 않음이 분명.

라이트 스킨(`--paper:#FAF8F3` 등)·레이아웃·공유 어휘(정전가/NAV/레벨/완파)는 **그대로 보존**. 다크 운영 셸로 전환하지 않음.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 백엔드/공개 모델 `portfolio_public`]** 섹션별 공개/비공개 토글(`mods[].pub`)과 이메일/사진 공개 플래그는 현재 프런트 상태일 뿐. 실제로는 `portfolio_public` 화이트리스트 모델(섹션 단위 공개 권한 + PUBLIC 투영 집계)이 백엔드에 있어야 함 — 토글 저장·방문자 게이팅·"개별 평점/트로프/실명/이메일 절대 미노출" 보장이 RPC/뷰 수준에서 강제돼야. 영향: profile, command-center(자산 공개 상태), collection-list(리스트 공개 여부).
- **[⚠ COORD: 어휘/레벨 밴드]** 레벨 밴드 5단계(SEEDLING→…→MASTER)와 "코퍼스 백분위 상위 N%"는 공유 어휘. 이 페이지는 표기만 차용했고 변경 없음 — 밴드 명칭·백분위 산식은 정본과 동기화 필요. 영향: NAV/레벨을 노출하는 모든 페이지.
- **[⚠ COORD: 어휘/완파(conquer) 상태]** 뱃지 status를 *정복(done)/근접(near)/잠금(lock)* 3-상태로 명시했는데, 이를 완파 정본의 표준 상태 어휘로 승격 제안(예: 75%/100% 완파 임계와 매핑). 영향: 완파 뱃지를 쓰는 command-center, analysis.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- "대표 업적" 스트립의 선정 로직(현재: BADGES 중 done/near 앞 3개)을 백엔드의 "가장 권위 높은 완파/근접 정복" 랭킹과 연동 — 지금은 프런트 슬라이스.
- 라이브 카운터를 섹션뿐 아니라 이메일·사진 공개 상태까지 포함한 "공개 표면 N개" 종합 지표로 확장 가능(현재는 모듈 7개만 집계).
- 미리보기 시 "방문자에게 이 데이터는 안 보임"을 비공개 섹션 자리에 placeholder로 보여주는 옵션(현재는 단순 제거) — 오너 학습성↑.

### 적용 매트릭스 행 (이 페이지)
- **S4 완파(도장깨기) 4-state** · **S9 공개/비공개 토글 비주얼** — 둘 다 **라이트 스킨으로 렌더**. 다크 토큰(`--blind/--forming/--masque`) **미도입**(다크 운영 셸 전용).

### S4 — 완파 4-state (잠금<50 / 진행50–74 / 근접75–99 / 완파100)
- 직전 UX 패스의 3-상태(정복/근접/잠금)를 정본 **4-state**로 정렬: **잠금**(<50%, 회색) · **진행**(50–74%, canon gold 옅음) · **근접**(75–99%, canon gold 강조) · **완파**(100%, conquer red 축포). Phase 4 `fire_lineage_milestones`(50/75/100 임계)와 일치.
- `BADGES` 6번째 status 필드를 4-state 키(`lock`/`prog`/`near`/`done`)로 재매핑하고 각 뱃지의 실제 % 를 밴드에 맞춤(예: KOFA 52% → 진행, 미조구치 6/6 100% → 완파, S&S 41% → 잠금).
- `.stag` CSS에 **진행(`prog`) 밴드** 추가, 완파(`done`)는 **conquer red(라이트 톤 `#fcecec`/`--accent`)** 축포로 격상(이전엔 green). STAG 라벨 맵 = `{done:'완파',near:'근접',prog:'진행',lock:'잠금'}`.
- "대표 업적" 하이라이트 스트립 필터를 **완파→근접→진행** 우선순위 정렬로 갱신(이전 `done||near` 단순 필터 → 4-state rank 정렬). 라이트 골드 칩 비주얼 유지.
- 어휘를 정본과 통일: **완파**(conquer=100% 도장깨기)로 통일(이전 "정복"). 공유 어휘 정전가/NAV/레벨/완파 일관.

### S9 — 공개/비공개 토글 (pill role=switch, 라이트 팔레트)
- 섹션별 `.vbtn` 알약 라벨/아이콘을 정본 pill 시맨틱으로 정렬: **`🌐 공개 중`**(globe `ti-world`) / **`🔒 비공개`**(lock `ti-lock`), `role="switch"` + `aria-checked` 유지. 이전엔 eye/eye-off 아이콘이었음.
- 라이트 스타일 보존: 공개=그린 토큰(`--good`/`#e6f4ee`), 비공개=뉴트럴(`--mut`/`--s2`). 다크 토큰 미사용.
- 일관성 차원에서 공개 설정 스트립 범례·라이브 카운터·공개 글·공개 리스트 라벨도 globe/lock + "공개 중"으로 통일(섹션 토글과 동일 어휘).
