# UX 검토 · 볼 영화 · 추천 데스크 (`mockup-me-watchlist.html`)

작성 2026-06-26.

## 0. 한 줄 진단
이 페이지는 "미관람 후보 중 *오늘 볼 한 편*과 그 다음 알파"를 약속한다.
가장 큰 마찰 두 가지: (1) 진입 시 "오늘의 한 편"이 보여도 **주 행동(담기/상세)이 화면에 없어** 스크롤→행 선택→인스펙터 담기까지 2~3클릭을 강제했고, (2) **담기/봤어요/관심없음이 인스펙터 전용**이라 모든 후보 처리에 인스펙터를 경유해야 했다. 게다가 행이 clickable처럼 보였지만 실제 클릭 핸들러가 없어(affordance 거짓), 가장 급한 만료 임박 후보가 1위와 시각적으로 동급이었다.

## 1. 렌즈별 발견 (경험·눈·클릭·직관)
- **경험 흐름**: 히어로 "오늘의 한 편"에 CTA가 전혀 없음 → 주 행동이 즉시 보이지 않음. 후보 행을 봐도 그 자리에서 할 수 있는 게 없어 흐름이 끊김.
- **눈동자(시각 위계)**: WWI·이유 색·Δindex는 위계가 잘 잡혀 있으나, **가장 시간-임계(만료 D-5/D-9)인 행이 1위와 동일한 무게**로 보였다. exppill만으로는 급박함이 약함.
- **클릭 최소화**: 후보 1건 처리 = 행 클릭 → 인스펙터 열림 → 담기 클릭(최소 2클릭, 인스펙터 접혀 있으면 더). "지금 볼 수 있는 것만"·"만료 임박순"이 1클릭 토글로 없었음(만료 정렬은 `<select>` 안에 묻힘).
- **직관성**: Δindex "+N→NAV"와 6이유 색은 자명. 단 "정보 없음" **회색 솔리드 점**이 "지금 볼 수 없음(off)"으로 오독될 소지. 행 전체가 cursor:pointer지만 클릭해도 아무 일도 없었음(least-astonishment 위반).

## 2. 적용한 개선 (HTML 직접 수정) — [무엇을] → [왜] → [클릭/눈 효과]
- **히어로 주 행동 클러스터 추가** (`.herocta`: 담기 / 왜1위·상세 / MUBI KR 가용 배지) → 진입 즉시 "오늘 볼 1편"에 대한 primary action이 보이도록 → 스크롤·인스펙터 경유 없이 **0~1클릭으로 담기/상세 진입**, 주 행동이 한눈에.
- **행 인라인 액션 추가** (각 후보 행에 담기/봤어요/관심없음 아이콘 버튼 `.rowact`, hover·선택 시 노출) → 인스펙터 detour 제거 → 후보 1건 처리가 **2~3클릭 → 1클릭**. 봤어요/관심없음은 행을 페이드 후 데스크에서 제거, 담기는 ✓ 표시로 즉시 피드백.
- **만료 임박 행 시각 강조** (`.rrow.urgent`: 좌측 노란 액센트 바 + 경고 배경) → 가장 시간-임계인 후보가 위계 상단에서 즉시 식별 → 눈이 "지금 안 보면 사라지는 것"으로 먼저 향함(ABSD D-5, Wind D-9).
- **툴바 원클릭 빠른 보기 2종** ("지금 볼 수 있는 것만" 토글 `q-avail` · "만료 임박순" 1클릭 정렬 토글 `q-expiry`) → 가장 흔한 두 의도를 select 펼침 없이 즉시 → **N클릭 → 1클릭**, 토글 on 상태가 색으로 자명.
- **"정보 없음" 점 → 속 빈 링 + "가용성 미확인" 라벨** (`.dot-unk`, title="≠ 안 됨") → 회색 솔리드 점이 "안 됨(off)"으로 오독되던 것을 *미확인*으로 명확화 → "정보 없음 ≠ 안 됨" 정책이 점 모양만으로 직관됨.
- **행 클릭 → 인스펙터 열림 핸들러 추가** (`#reclist` 위임 클릭; 인라인 액션은 stopPropagation) → cursor:pointer인데 동작 없던 거짓 affordance 수정 → 행 어디를 눌러도 WWI 분해가 열려 예측 가능.

## 3. 조율 필요 (cross-page) — [⚠ COORD] 항목만
- **[⚠ COORD: 셸/인스펙터 담기 동작]** 인스펙터 하단 "담기" 버튼은 현재 `mockup-me-collection-list-v2.html`로 location.href 이동. 이번에 행 인라인 담기는 *그 자리에서* 상태만 바꾼다(페이지 로컬). 두 담기 경로의 최종 동작(보유로 이동 vs. 단순 마킹)을 통일해야 함 — 보유/추천 공통 "담기" 동작 정의 필요. 영향: watchlist, collection-list-v2, command-center.
- **[⚠ COORD: 어휘/가용성 표기]** "가용성 미확인 / 정보 없음 ≠ 안 됨"을 점 모양(속 빈 링)으로 구분하는 표기를 6+가용 정본 옆에 *가용성 3-상태(가능·미확인·만료)* 표준으로 승격 제안. 영향: 가용성 점을 쓰는 모든 페이지.
- **[⚠ COORD: 백엔드/로직]** "봤어요/관심없음"은 지금 행을 프런트에서 숨길 뿐. 실제로는 `watched_log` 기록·`film_affinities ∖ 본 영화` 재계산·"관심없음" 음성 신호 반영이 필요 → 새 RPC(`mark_watched`, `dismiss_candidate`). 영향: watchlist 후보 풀, onboard-rate, analysis.

## 4. 추후 로직·데이터 변경 제안 (필요 시, 지금은 미적용)
- "지금 볼 수 있는 것만" 토글이 켜졌을 때 KPI 스트립("지금 볼 수 있음 19/28")과 연동해 활성 표시하면 일관성↑ (현재 KPI는 정적).
- 만료 임박 강조 임계(D-N)와 정렬 가중을 백엔드 `expiry_watch()` 신선도와 동기화 — 현재 urgent 클래스는 정적(D-5/D-9 하드코딩).
- 인라인 "봤어요" 직후 별점 0.5–5 입력을 그 자리에서 받는 마이크로-인터랙션(공유 별점 컴포넌트 필요 → `[⚠ COORD: 셸/별점]`).

## 표준 적용 (SHARED-STANDARD)

적용 2026-06-26. 매트릭스 행 `watchlist = S1 · S2 · S3 · S5`(S6/7/8 인라인은 UX 패스에서 완료 → 명칭만 재확인). 셸·콘텐츠·이전 UX 개선(가용성 3-상태·인라인 액션) 보존, **부적합 항목만 변경**.

- **S1 추천 명칭** — 히어로는 이미 「오늘의 한 편」 라벨 사용 중. 부제를 표준 형식 `최대 Δ · → NAV +N`으로 정렬: `Mambéty · 세네갈 · 최대 Δ · Δindex → NAV +6`. 라이브 티커·인스펙터 `오늘의 한 편`도 명칭 일치 확인.
- **S2 블라인드 색** — `:root`에 `--blind:#E8B23A`(+ `--forming:#C8922B`) 토큰 추가. 본문 첫 "블라인드" 멘션을 `color:var(--blind)` 앰버로 명시(이전 muted). 6이유 `gap` 칩은 이미 앰버(`--gap`) — conquer red 재사용 없음 전수 확인(블라인드/공백 마커에 red 0건).
- **S3 가용성 3-상태** — watchlist가 정본 보유 페이지. 라벨 표준 일치 확인: 가능 = solid green dot(`--avail`) + 제공자명(MUBI/Criterion KR) · 미확인 = hollow ring(`.dot-unk`) + "가용성 미확인"(≠ 안 됨) · 만료 = `.exppill` "만료 D-N"(노란 좌액센트는 `.rrow.urgent::before` 바로 보강). 변경 없음(이미 적합).
- **S5 용어집 hover** — analysis/command-center의 `.gloss` 패턴(점선 밑줄 + 한국어 hover 정의) 재사용. 첫 등장 5개 용어에 부착: **WWI**(explain) · **Δindex**(히어로 부제) · **정전가**(explain) · **블라인드**(touki rsub) · **커버리지**(bgwd rsub). 정의문은 SHARED-STANDARD §S5 정본 사전 인용.
- **S8 담기 동작(명칭 재확인 중 발견)** — 인스펙터 액션바 "담기"가 `location.href→collection`으로 이동하던 것을 표준 위반으로 판정, **제자리 마킹 + toast(페이지 이동 없음)**로 수정. 행 인라인 액션과 동일 의미로 위임(`keepFromInsp`/`seenFromInsp`/`skipFromInsp`). 행 인라인 담기/봤어요/관심없음 명칭은 이미 표준과 일치.
