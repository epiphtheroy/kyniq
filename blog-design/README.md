# metatake — Blog 디자인 세트 (시안 · 미리 만들어 둠)

**Blog은 현재 metatake.net에 없는, 추가되어야 하는 새 최상단 카테고리다.**
거의 매일 쓰는 일일 칼럼 **"Between Film and the World"**(그날의 뉴스를 영화·메타테이크 리딩으로 잇는 칼럼)를
위해, 사이트에 붙기 전에 디자인을 미리 만들어 두었다. **핵심 = 이메일 구독 확보.** (Ghost 등 미사용 — 직접 개발,
이메일만 서드파티.)

| 파일 | 라우트 | 핵심 |
|---|---|---|
| `07-blog-index.html` | `/blog` | 일일 칼럼 아카이브 · 칼럼 정체성 + **구독 카드(스티키)** · 오늘 에디션 피처(5운율=영화 썸네일+event→film+별점) · 최근 에디션 리스트 · 하단 구독 밴드 |
| `08-blog-post.html` | `/blog/[slug]` | 읽기 페이지 · 번호 랭크 엔트리(event→film·★별점·뉴스문단·**빨강 좌선 리딩문단**·"In Metatake" 디포짓·영화 스틸) · cutting-room floor · "Retrieved, not remembered" · 중간/끝 구독 |
| `09-blog-subscribe.html` | `/blog/subscribe` | 전용 구독 랜딩 · 큰 폼 + **더블 옵트인 성공 상태** · "받은 편지함 3가지" · 최근 에디션 미리보기 |

## 핵심 원칙
- metatake v6 디자인 시스템과 동일: 흰 종이 · PT Serif+Inter · **빨강 하나 #E3120B** · 헤어라인 · 사각 모서리 · 컬러 이미지.
- 마스트헤드에 **Blog** 추가(끝에). 내부 metatake 링크=빨강, 외부 출처 링크=↗ 로 구분.
- **이메일 구독 = 균형 배치**: 인덱스 히어로 + 글 중간 인라인 + 글 끝 박스 + 전용 페이지.
- **이메일 폼은 프로바이더 무관** — 코드 주석에 Buttondown / ConvertKit(Kit) / Substack 임베드 방법. 빌드 시 한 줄 연결.
- v6 홈 "안 어울리는 두 영화 연결"과 같은 동작: 사건 ⟷ 영화, figure로 연결, 운율=별점, "DB 검증 후 링크 = 생성 아닌 검색".

## 진짜 vs 자리표시자
- 오늘 에디션(샘플 본문)·영화·리딩·라우트·백드롭은 **실제**(사용자 글 + Supabase `films`에서 확보).
- 과거 에디션 행·구독자 수 문구는 시안용 자리표시자. 실연동 시 실제 글·서드파티 구독 수로 교체.
