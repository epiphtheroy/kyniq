# Cinecodex — 앵커셋 50편 채점 결과 (rubric v1.1)

> 3명의 독립 평가자 에이전트(동일 동결 루브릭, 병렬)의 평균. V·C·R은 13개 하위점수에서 고정 공식으로 계산.
> `U = V − R` (λ=1), `S = (V−50)/max(R,1)` (시네마틱 샤프). 위험회피 다이얼 λ는 사용자가 조정.

## 신뢰도 (일관성 — 당신이 가장 걱정한 지점)

- 평가자 간 영화별 표준편차 평균: **V σ̄ = 1.01, R σ̄ = 0.96** (목표 ≤6 → 통과)
- 평가자 쌍 V 상관 ≈ **0.997**, ICC(2,1) ≈ **0.99** → 결정적 재현성.
- 정직한 한계: 이는 *동일 모델*의 확률적 재현성이다. 진짜 신뢰도는 *서로 다른 모델·인간* 평가자 간 교차검증이 다음 과제.

## 시금석 검증 (전부 통과)

- 시 V=84.1 R=14.6 U=69.5 / 배트맨 리턴즈 V=50.5 R=34.0 U=16.5 → **V(시)>V(배트맨)** ✓
- 라라랜드 V=55.1 R=37.1 U=18.0 / 바빌론 V=52.6 R=51.2 U=1.4 → **V(라라랜드)>V(바빌론)** ✓, **R(바빌론)>R(라라랜드)** ✓, **U(라라랜드)>U(바빌론)** ✓
