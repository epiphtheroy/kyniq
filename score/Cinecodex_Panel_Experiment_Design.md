# Cinecodex 패널 실험 — 사전등록 설계 (run3)

> 결과를 보기 전에 동결한 설계(pre-registration). 사후 조작 방지.

## 목적
"AI 점수가 운이나 특정 모델 특이성이 아니라 루브릭에서 나온다"를 증명한다. 동시에 당신의 실질 질문에 답한다: **최상위 모델이 꼭 필요한가, 아니면 더 싼 모델도 일관적인가?**

## 인프라 한계 (정직 고지)
이 샌드박스의 egress 프록시는 외부 LLM 벤더 API(OpenAI·Gemini)를 차단하며, 사용자 키를 쓴 직접 Anthropic API 호출도 401로 막는다(프록시가 TLS를 가로채 차단). 따라서 **진짜 교차-회사(cross-company) 패널은 이 환경에서 실행 불가.** 대신:
- **여기서 실행:** Claude 3개 티어(Opus·Sonnet·Haiku) 패널 — 모델 *크기/등급* 효과를 측정(당신의 핵심 질문).
- **당신 환경에서 실행:** 벤더 무관 하니스(`cinecodex_panel_harness.py`)를 제공 — OpenAI·Gemini·Anthropic 키로 교차-회사 팔을 직접 돌린다(프록시 없는 환경).

## 설계
- **요인:** 모델 티어 {Opus, Sonnet, Haiku} × 반복 {run1, run2, run3} = 9개 셀.
- **고정:** 동일한 동결 프롬프트 `PROMPT_v1.1.txt`(루브릭 + 5 기준작 + 50편 + 스키마)를 모든 셀이 디스크에서 읽어 적용. 웹/도구 사용 금지.
- **산출:** 셀마다 50편 × 13 하위점수 JSON.
- **집계:** 패널 점수 = 9개 런의 하위점수별 **중앙값(median)**. V·C·R은 고정 공식.

## 측정 지표
1. **자기일관성(티어 내):** 같은 티어 런 간 영화별 V·R 표준편차 평균.
2. **교차티어 일치:** 티어 평균 간 ICC(2,k)·크리펜도르프 α·피어슨/스피어만 상관.
3. **타당도(티어별):** 4개 시금석 제약 — V(시)>V(배트맨), V(라라랜드)>V(바빌론), R(바빌론)>R(라라랜드), U(라라랜드)>U(바빌론).
4. **괴리 핫스팟:** 티어 간 가장 갈리는 영화 → 정직한 인식론적 위험 신호.

## 사전 명시 판정 규칙 (decision rule)
한 티어가 **합격**하려면: (i) 50편 모두 유효 JSON, (ii) 4개 시금석 제약 모두 충족, (iii) 패널과 V 상관 ≥ 0.85.
- 합격한 티어 중 **가장 싼 것을 운영 모델로 권고**(비용 효율), 최상위는 정기 감사용.
- 어떤 티어가 탈락하면 그 자체가 결론("그 등급은 쓰지 말 것").
- 교차티어 α < 0.80 이면 프롬프트/앵커를 보강해 **루프 재실행**.
