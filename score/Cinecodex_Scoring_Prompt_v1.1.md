# Cinecodex Scoring Prompt — v1.1 (FROZEN)

> v1.0 → v1.1 변경 이유(changelog). v1.0 1차 채점에서 **V(라라랜드) < V(바빌론)** 제약 위반이 발견됨.
> 진단: 모델이 (1) 바빌론의 *규모/야망*을 FORM=78로 과보상, (2) 라라랜드의 *지속성(DUR=53)·정서(AFF)*를 과소평가,
> (3) 라라랜드의 분열성(POLAR=56)을 과대평가. 아래 4개 차원 정의를 **원칙적으로** 정교화함(특정 영화를 정답으로 박지 않음).

## 변경된 정의 (나머지 9개 차원·기준작·공식은 v1.0과 동일)

- **FORM (개정):** 0 무형식/미숙→25 유능하나 평범→50 뚜렷한 장인성→75 *통제되고 통합된* 작가적 형식, 매체를 확장→100 형식 혁신.
  **결정적:** *성취되고 통합된* 형식에 보상하라. 규모나 야망이 아니다. **과시적 스펙터클·맥시멀리즘 과잉·주제와 분리되어 소진시키는 스타일은 시각적으로 화려해도 ~50–55에서 상한.** 시도된 야망 ≠ 전달된 가치.
- **AFF (개정):** ... **결정적: 접근성·인기는 이 점수의 상한이 아니다.** 널리 사랑받아도 정서가 몇 주간 실제로 남으면 70+.
- **DUR (개정):** ... **결정적: 대중적이라고 지속성이 낮은 게 아니다.** 인기/접근성과 무관하게 *이미지·정서의 실제 잔존*과 재관람 보상을 매겨라.
- **POLAR (개정):** 0 합의에 가까움→100 격렬히 분열.
  **구분하라:** *강한 비평적 합의 + 목소리 큰 소수 반발* = 중간(~35–45); *진짜 절반-격찬/절반-기각의 비평 분열* = 높음(70+). 유명하거나 온라인 논쟁이 있다고 분열성을 부풀리지 마라.

## 추가 규칙 (HARD RULE #7)
7. **교차검증(CROSS-CHECK):** 높은 야망/규모 자체는 V를 올리지 않는다. INSINCERE 또는 COWARD가 중상이면 *주장된 형식적 야망을 회의적으로* 보라 — 야망은 *성취되고 통합되었을 때만* 가치다.

*(전체 통합 프롬프트는 평가자 에이전트에 v1.0 본문 + 위 4개 개정 정의 + 규칙7을 합쳐 주입한다. v1.0 파일은 출처 보존을 위해 동결 유지.)*
