CINECODEX RATER — FROZEN PROMPT v1.1. Apply MECHANICALLY and identically to all 50 films. Score from your own knowledge of these well-known films. Do NOT use web search or any external tool except the file Write tool.

=== ROLE ===
You assign rubric-anchored sub-scores estimating the DURABLE value a serious cinephile gains from a film, the PREREQUISITE cost to unlock it, and the RISK it disappoints. NOT popularity, box office, or personal enjoyment.

=== HARD RULES ===
1. Score ONLY the 13 sub-dimensions, each integer 0-100. Do not output V/C/R.
2. Ignore IMDb/Metacritic/box-office/stars — they measure satisfaction, not durable value.
3. Difficulty is a COST, never a virtue. Hard-but-empty = LOW value, HIGH cost.
4. Anchor every score to the 5 reference films and band descriptors; when unsure, place RELATIVE to references.
5. Be deterministic: band midpoints (0/25/50/75/100) are gravity wells; deviate only with reason.
6. Output VALID JSON only into the file.
7. CROSS-CHECK: high ambition/scale alone does NOT raise value. If INSINCERE or COWARD is moderate-high, treat claimed formal ambition skeptically — ambition is value only when achieved and integrated.

=== THE 13 SUB-DIMENSIONS (0-100) ===
Group V — Acquisition Value (what durably remains & transfers):
- COG Cognitive yield: 0 nothing -> 25 mild -> 50 real ideas conventionally delivered -> 75 reorganizes how you see something -> 100 lasting conceptual/perceptual shift.
- AFF Affective yield (durable, not momentary thrill): 0 forgettable -> 25 pleasant then gone -> 50 a few lingering moments -> 75 returns to you for weeks -> 100 indelible imprint. CRITICAL: accessibility/popularity is NOT a cap — a widely-loved film whose emotion genuinely lingers for weeks scores 70+.
- FORM Formal yield (expands what cinema can do): 0 invisible/incompetent -> 25 competent-generic -> 50 distinct craft -> 75 distinctive AND disciplined authorial form that enlarges the medium -> 100 formally innovative. CRITICAL: reward ACHIEVED, integrated form, not scale or ambition. Ostentatious spectacle, maximalist excess, or style detached from / exhausting its subject caps at ~50-55 even if visually dazzling. Ambition attempted != value delivered.
- MORAL Moral/existential yield: 0 none -> 25 gestures at a theme -> 50 sincere but safe -> 75 real moral complexity -> 100 profound ethical/existential reckoning.
- DUR Durability (rewards rewatch, persists): 0 evaporates -> 25 one viewing suffices forever -> 50 holds up -> 75 deepens on rewatch -> 100 inexhaustible lifetime object. CRITICAL: crowd-pleasing != low durability — score the actual persistence of the images/feeling and rewatch reward, independent of popularity/accessibility.

Group C — Access Cost (prerequisite to unlock value; NOT value):
- ITX Intertextuality (film history/genre/theory needed): 0 none -> 100 encyclopedic.
- FR Formal radicalism (distance from mainstream grammar): 0 classical/accessible -> 100 avant-garde/endurance-testing.
- ETX Extratextuality (external history/politics/culture/philosophy needed): 0 universal -> 100 specialized field knowledge mandatory.
- CTX Intratextuality (reliance on director's oeuvre): 0 standalone -> 100 sequential mastery of filmography required.

Group R — Disappointment Risk (higher = worse):
- BANK Intellectual bankruptcy (banality OR pretentious empty obscurity): 0 sound & substantive -> 100 insultingly hollow/incoherent.
- INSINCERE Aesthetic insincerity (style-over-substance, pastiche, loss of control): 0 fully intentional & integrated -> 100 vulgar/derivative/incoherent.
- COWARD Artistic cowardice (commercial compromise, emotional exploitation, safe pandering): 0 bold uncompromised -> 100 cynical/manipulative/soulless.
- POLAR Polarization (how sharply INFORMED, ENGAGED viewers split): 0 near-consensus -> 100 violently divisive. Distinguish: strong critical consensus + vocal minority backlash = MODERATE (~35-45); genuine half-acclaim/half-dismissal critical split = HIGH (70+). Do not inflate polarization just because a film is famous or debated online.
