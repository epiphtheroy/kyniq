# 사상의 지도 (Theory Atlas) — 기술설계 문서
## 임베딩으로 그리는 "약속되지 않은 지도"

작성일: 2026-06-28

---

## 0. 핵심 통찰: 가능한가? — 그렇다, 그리고 이게 바로 그 방법이다

지명 지도에는 **약속된 좌표**(위경도)가 있습니다. 이론·이론가에는 그런 게 없습니다. 하지만 여러분의 직관은 정확합니다 — **임베딩(embedding)이 그 "약속되지 않은 좌표"를 만들어 줍니다.**

임베딩 모델은 단어·문장·개념을 수백~수천 차원의 벡터로 바꾸는데, 이때 **의미가 비슷하면 벡터도 가깝습니다.** 즉 "Du Bois의 이중의식"과 "Fanon의 흑인됨의 경험"은 벡터공간에서 자연스럽게 이웃이 됩니다 — 아무도 좌표를 정해주지 않았는데도. 이 고차원 공간을 사람이 볼 수 있는 2D로 **투영(projection)**하면, 의미의 인접성이 곧 지도 위 거리로 바뀝니다. 이것이 **의미 카토그래피(semantic cartography)**이고, Google의 Embedding Projector, Nomic Atlas, Apple의 Embedding Atlas가 모두 이 원리로 만들어졌습니다.

결론: **벡터 = 가상의 위경도. 투영 = 지도 제작. 군집 = 대륙/권역.** 여러분 프로젝트는 이 검증된 파이프라인으로 충분히 구현됩니다. 실제로 9개 개념으로 작동하는 지도를 함께 만들었습니다.

## 1. 전체 아키텍처

```
[ 영화이론 브리핑 .md 문서들 ]
            │
            ▼
 ① 개념 추출 (Gemini structured output)
    글마다 (이론명·이론가·전통·해설) 엔티티 뽑기
            │
            ▼
 ② 벡터화 (Gemini Embedding 001)
    "개념명+이론가+전통+해설" → 고차원 벡터
            │
            ▼
 ③ 2D 투영 (UMAP / 소규모는 MDS)
    고차원 → 평면 좌표(x,y) = 가상의 지명
            │
            ▼
 ④ 군집 + 라벨 (HDBSCAN + LLM)
    가까운 점 묶어 '사상 권역' + 권역 이름 생성
            │
            ▼
 ⑤ 시각화 (deck.gl, WebGL)
    줌/팬 네비게이션 · 권역 영역 · 클릭하면 전문 읽기
```

①~④는 1회성 데이터 가공(에이전트가 자동 수행), ⑤만 상시 서비스입니다.

---

## 2. 단계별 설계

### ② 벡터화 — 무엇을 임베딩할 것인가
선택지가 셋입니다. **(a) 개념 엔티티**(이론명+이론가+전통+해설 한 덩어리), **(b) 문서 전체**, **(c) 이론가**. 여러분 목적("이론가·이론을 추출해 배치")에는 **(a) 개념 단위가 정답**입니다 — 같은 영화 안의 서로 다른 개념이 각자 제 위치를 갖고, 다른 영화의 유사 개념과 이웃이 되기 때문입니다. 해설 문단까지 포함해 임베딩하면 의미가 풍부해져 군집이 또렷해집니다.

모델은 **Gemini Embedding 001**(2025년 MTEB 1위)을 권장합니다. 오픈소스 무키 대안으로 Qwen3-Embedding, NVIDIA NV-Embed가 있습니다.

### ③ 2D 투영 — 고차원을 누르기
- **UMAP**: 국소·전역 구조를 함께 보존, 군집이 잘 드러남. 수십~수백만 점의 사실상 표준.
- **t-SNE**: 국소 군집은 예쁘나 전역 거리 왜곡이 큼.
- **MDS/PCA**: 거리 보존엔 충실하나 대규모엔 부적합.
- **이 PoC**: 9점이라 UMAP이 불안정 → **MDS + SMACOF**로 stress≈0.15(양호) 달성. 50개 이상이 되면 파이프라인이 자동으로 UMAP으로 전환합니다.

### ④ 군집 + 라벨 — 대륙에 이름 붙이기
**HDBSCAN**(밀도기반)으로 군집 수를 자동으로 찾고, 각 군집의 개념들을 LLM에게 보여 **권역 이름**을 짓게 합니다(예: "시선과 인종화된 자아 · The Look & the Racialized Self"). 라벨링은 지도를 항해 가능하게 만드는 핵심 — 연구에서도 "투영의 해석에는 라벨이 결정적"이라고 강조합니다.

### ⑤ 시각화 — 항해 가능한 지도
**deck.gl OrthographicView**(WebGL)로 비(非)지리 2D 평면을 구글맵처럼 드래그·줌 네비게이션하게 만들었습니다. 점(개념), 권역 폴리곤(territory), 의미 이웃 선(edge), 라벨을 레이어로 쌓고, 클릭하면 전문(EN+KO) 패널이 열립니다. 우측 목록은 **화면 안 개념**으로 자동 갱신 — 지명 지도에서 쓰던 "이 지역의 글" UX를 그대로 의미공간에 옮겼습니다.

## 3. 미리 짚는 난제와 해결책

| 난제 | 해결책 |
|---|---|
| 투영 왜곡(2D로 누르면 거리가 일부 어긋남) | UMAP+적합도(stress) 점검, 권역은 군집으로 보정, "축은 의미 없음" 명시 |
| 같은 이론가/개념이 여러 문서에 중복 등장 | 엔티티 해소(이름+저작 정규화)로 병합, mention_count 집계 |
| 군집이 매번 달라짐(불안정) | random_state 고정, 신규 데이터는 기존 투영에 transform로 끼워넣기 |
| 권역 이름의 품질 | LLM 라벨 + 사람 검수 1패스, 전통(tradition) 메타데이터 병기 |
| 다국어(EN/KO 혼재) | 다국어 임베딩 모델 사용, 해설은 EN/KO 동시 저장·토글 |
| 소규모에서 UMAP 불안정 | 자동으로 MDS+SMACOF 대체(이 PoC가 채택) |
| 수만 점 렌더링 | deck.gl WebGL(수백만 점), 줌별 라벨 LOD |

## 4. 더 나아가기 (고급 옵션)

- **계보 엣지**: 의미 유사도뿐 아니라 "영향 관계"(Shklovsky→Eisenstein 등)를 화살표로 그려 사상사 흐름을 시각화.
- **다중 렌즈(projection switching)**: 같은 데이터를 "전통별", "시대별", "감각(시각/청각/신체)별" 등 여러 임베딩 축으로 다시 투영해 토글.
- **시간축**: 연도(1863~1982)를 색/높이에 매핑해 사상의 시대 분포를 표현.
- **검색·교차필터**: 자연어로 "신체와 지각에 관한 개념" 검색 → 해당 점들만 강조(임베딩 검색).
- **3D / 지구본 메타포**: 권역을 대륙처럼 렌더링.

## 5. 단계별 로드맵

1. **PoC(완료)**: 3문서 9개념 → 작동하는 사상의 지도.
2. **파이프라인 가동**: 실제 수십~수백 문서에 Gemini 임베딩 파이프라인 1회 실행, 군집·라벨 검수.
3. **프론트 고도화**: 검색, 계보 엣지, 다중 렌즈, 줌별 라벨.
4. **배포**: Vercel/Firebase 정적 호스팅.
5. **자율화**: 새 문서 투입 시 자동 재투영(스케줄 작업).
