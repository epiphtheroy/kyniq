- 일부 `address`가 도로명만(번지 없음) → 건물 단위 정밀화 시 **Google Geocoding API 재처리** 권장.

## 6. 개선 제안 (우선순위)

1. **주소 보강**: 누락 21건 + 도로명만 있는 항목을 Google Geocoding/Places로 좌표·번지 정밀화.
2. **weak 3건 재검증**: 신뢰도 낮은 단일출처를 Tier-A 출처로 교체 또는 보류.
3. **광역 항목 폴리곤화**: area/region 45건은 점→영역으로 전환해 정확도·표현력 향상.
4. **스키마 확장**: `lat`,`lng`,`precision`,`geocode_basis` 필드를 원본 DB에 영구 저장(이번 산출물에 포함).
5. **표본 균형**: 영화당 위치 수 편차 완화(핵심작 우선 보강).
